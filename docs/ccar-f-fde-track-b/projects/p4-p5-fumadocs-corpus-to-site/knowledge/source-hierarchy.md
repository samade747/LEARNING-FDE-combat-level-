# The Source Hierarchy

When two sources disagree, the Worker must know which one wins. A typical hierarchy, highest authority
first: current law and regulation, binding professional standards, official regulator interpretations,
approved domain policy, the expert's authored procedures, customer-specific policy, historical examples.

Relevance is not enough — the source must also be applicable: right rung, right jurisdiction, right
version.
