# Outcome Contracts

An outcome contract defines the completed professional result before any workflow is designed: the
outcome, the trigger, required inputs, evidence, acceptance criteria, the main number and its
guardrails, forbidden actions, final authority, and the record kept after completion.

Write the outcome contract before studying the old workflow. It is the yardstick every later design
decision is measured against.
