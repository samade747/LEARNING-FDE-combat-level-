# The Three-Bin Sort

Every element of an old workflow gets sorted by asking "why does this exist?"

- **Bin 1 — law and trust require it.** Keep it. Write it down as an invariant.
- **Bin 2 — human limits require it.** Redesign it as a Worker capability plus a checker.
- **Bin 3 — old technology required it.** Delete it.

A control's purpose is usually Bin 1; its mechanism is usually Bin 2. Separate the two before sorting.
