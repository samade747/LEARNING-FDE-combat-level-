## Yeh Course Kis Baare Mein Hai

**18 Concepts, 4 Parts.** Aap ne poori book mein aisi machines banayin jo **kaam karti hain**: general
agents, Digital FTEs, workforces jo apne colleagues khud hire karti hain. Yeh course us **patli,
decisive layer** ke baare mein hai jahan ek insan us machine se milta hai aur decide karta hai trust
karna hai ya nahi.

Yeh layer ab screen nahi hai. Jab software sirf commands ka jawab deta tha, design ka matlab tha
buttons arrange karna. Jab software **khud act karta hai**, insan ab drive nahi kar raha — **delegate**
kar raha hai. **Aur delegation ek relationship hai, transaction nahi.**

> **One-line thesis:** Ek agentic product ke ek waqt mein 2 users hote hain (ek **insan jise trust
> karna hai** aur **doosre agents jinhe parse karna hai**), aur aapka kaam ek aisi surface design karna
> hai jo dono ki khidmat kare bina kisi ko dhoka diye.

## Kya Banega

Ek **Agent Experience Brief** ek Digital FTE ke liye: uska human-facing trust surface, agent-facing
machine surface, autonomy ladder, aur recovery plan. Naya code nahi — aap apne agent ko brief produce
karne ka direct karte ho. Hands-On Lab mein aapka pehla **MCP App** bhi banega — refund Worker ke liye
ek working approval widget.

*Yeh summary poore course (The Shift + Human Surface + Machine Surface + New Craft + Worked Example +
Hands-On Lab) ka overview hai.*
