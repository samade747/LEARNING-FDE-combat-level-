## Ek Line Mein Poori Cheez

> **Software fundamentals AI ke daur mein pehle se zyada matter karti hain, kam nahi.** Wajah mechanical
> hai, sentimental nahi: jo interface aap design karte ho, wahi interface agent seekhta hai; jo names
> aap choose karte ho, wahi names agent reuse karta hai; jo boundaries aap khainchte ho, unhi
> boundaries ko agent respect karta hai. Ek clean, well-tested codebase mein wahi agent kai quality
> tiers behtar code deta hai, usi agent ke tangled codebase wale output se. Architecture ab sirf code ki
> property nahi — ab wo agent ke liye **input** hai. **Bad code bad agents deta hai. Good code aise
> agents deta hai jo hairatangez taur par competent lagte hain.**
