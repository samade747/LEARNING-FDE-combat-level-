# 09 — Practical Drills (3 Drills)

Teen exercises, **order mein karo.** Har ek 30 minute se 2 ghante leta hai. Real, runnable scaffolds
[`projects/`](projects/README.md) mein hain.

1. [**Drill 1 — Install aur run `grill-me`**](projects/drill-1-grill-me/README.md) — real idea par
   grilling karo, questions count karo.
2. [**Drill 2 — Vertical Slice as Tracer Bullet**](projects/drill-2-vertical-slice/README.md) — ek
   user story, smallest end-to-end path, `tdd` Skill ke sath implement.
3. [**Drill 3 — Deepen a Module**](projects/drill-3-deepen-module/README.md) — `improve-codebase-architecture`
   chalao, highest-value candidate pick karo, interface sketch karo (implement nahi).

## Daily Work Checklist

- [ ] Aaj ki session shuru karne se pehle `/clear` kiya?
- [ ] Koi non-trivial change ke liye `grill-me` use kiya?
- [ ] Issues vertical slices hain, horizontal phases nahi?
- [ ] Har implementation slice `tdd` se guzar rahi hai?
- [ ] AFK runs sandbox mein hain?
- [ ] Reviewer implementer se **alag** session hai?
- [ ] Diff parha, summary nahi?
