## Yeh Course Kis Baare Mein Hai

**17 Concepts · Read Before You Write.** Aap already [Agentic Coding](../agentic-coding/README.md) mein
seekh chuke ho AI coding agent chalana. To sawal: **agar agent Python likhta hai, to aapko Python
seekhne ki zaroorat hi kya hai?**

Jawab: kyunki koi to isay **parhega**. Agent seconds mein sainkron lines "working-looking" code de deta
hai. **"Working-looking" hi trap hai** — AI *plausible* ke liye optimize karta hai, *correct* ke liye
nahi. Jo code chupke se ghalat number return kare, ek record drop kare, ya API key leak kare — woh
dikhta bilkul waisa hi hai jaisa sahi code. **Sirf woh insaan farq bata sakta hai jo parh sake aur prove
kar sake.**

Purane world mein Python **likh kar** seekhte the. Yahan Python **parh kar** seekhte hain — predict
karo code kya karega, chalao, investigate karo kyun, phir badlo, aakhir mein khud banao.

## 10-80-10 Rule (Programming Par Apply)

Aap **pehle 10%** own karte ho (decide karna kya banana hai, "correct" ka matlab kya hai) aur **aakhri
10%** (verify karna). Agent **beech ke 80%** own karta hai (code generate karna). Fluent reading hi aapko
dono ends pakarne deti hai.
