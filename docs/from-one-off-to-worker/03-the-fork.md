# 03 — Part 4: The Fork — Do Tareeqe Permanent Banane Ke

Ek dafa cross karne ka faisla ho jaye, "durable worker banao" do alag rasto mein fork hota hai. Dono
same 4 promotions use karte hain, lekin alag logo ke liye bane hote hain, aur farq matter karta hai.

## Own It — Personal Harness

Agar worker **aap** ke liye hai — aapka inbox, code, errands — to halka rasta hai ek **personal
harness** (software jo aap khud chalate aur own karte ho jo worker ko aapke liye zinda rakhti hai). Aap
4 promotions karte ho, lekin halke se: spec aapki apni notes hai, eval aapki khud ki muthi bhar examples
hai, escalation worker ka **aapko** message karna hai. Ho sakta hai aapko poori Mode 2 track ki
zaroorat hi na pade. Yeh rasta [Personal Agent Harnesses](../openclaw/README.md) (OpenClaw aur
[Hermes](../hermes/README.md)) sikhata hai.

## Manufacture It — Digital FTE

Agar worker ek **organization** ke liye hai — kuch jispe dusre log rely karenge, jo reliably chalna
chahiye, governed hona chahiye, scale karna chahiye (shayad bikega bhi) — to yeh ek **Digital FTE** hai
("digital full-time employee"), aur aap 4 promotions **rigorously** karte ho: spec shared aur reviewed
hai, eval poori team ka trust kiya hua gate hai, escalation ek named human/team ko jati hai, runtime real
production infrastructure hai. Yeh poora **Mode 2 — Manufacturing** track hai.

## Faisla Karne Wala Sawal

**Worker kiske liye hai, aur kaun rely karta hai?** Sirf aap ke liye → personal harness. Organization ke
liye → Digital FTE. Same crossing, do depths of rigour.

## Kya Banate Ho (2026)

| Rasta | Kya Se Banate Ho (2026) | Kahan Seekho |
| --- | --- | --- |
| **Own it — Personal harness** | OpenClaw ya Hermes — open-source harnesses jo aap khud chalate/own karte ho | Personal Agent Harnesses |
| **Manufacture it — Digital FTE** | OpenAI Agents SDK, ya managed Claude agent setup | Mode 2 track |

General agent jo aap Mode 1 mein drive kar rahe the (Claude Code, OpenCode, Cowork, OpenWork) yahan
gayab nahi hota — dono rasto par yeh woh tool hai jisse aap worker **banate aur install karte** ho. Yeh
bas task har baar khud karna band kar deta hai, aur us cheez mein badal jata hai jo task karne wali
cheez banata hai.

> **Ek running cost cross karne par ati hai:** Ek durable worker **API** par chalta hai, jahan har
> model call **metered** hai aur pay karna parta hai — aur yeh **dono** rasto par sach hai: personal
> harness (OpenClaw, Hermes) bhi API par chalta hai jitna manufactured Digital FTE. Yeh alag hai claude.ai
> web app use karne se, jahan plugin calls aapki subscription ya free tier se aate hain bina separate
> per-call bill ke. To crossing "thinking" ko bundled-in-your-plan se ek real per-call cost mein badal
> deta hai. Yehi ek aur wajah hai "worth it?" signal matter karta hai — worker ko sirf build time nahi,
> har baar chalne wala model bill bhi wapis karna hai.

> **Yeh teesra mode nahi hai:** Personal harness own karna Mode 1 aur Mode 2 ke beech ek naya mode nahi
> hai — yeh wahi "durable worker banao" activity hai, ek insaan ke liye scaled down. **Mode** poochta
> hai: ek dafa solve karo ya lasting banao? **Ownership** poochta hai: worker aapka hai ya organization
> ka? Do alag sawal. Aap koi bhi mode chala sakte ho ek harness par jo aap own karte ho.
