## Ek Line Mein Poori Cheez

> **4-Layer Architecture: L1 CLAUDE.md (persistent context) → L2 Skills (auto-invoked knowledge) →
> L3 Hooks (deterministic safety gates) → L4 Agents (subagents with their own context).** Har layer
> pichle wali par build hoti hai — L1 se shuru karo, zaroorat ke hisaab se layers add karo.

## Pure Reference Chapter — No Projects Folder

Yeh chapter ek quick-reference card hai (16 panels, Claude Code setup/usage), koi numbered course
nahi — isliye `projects/` folder nahi hai. Agar inmein se kisi feature (Skills, Hooks, Agent Teams) ko
hands-on explore karna ho, [`docs/agentic-coding`](../agentic-coding/README.md) aur
[`docs/plugins-crash-course`](../plugins-crash-course/README.md) dekho jahan yeh features action mein
hain.
