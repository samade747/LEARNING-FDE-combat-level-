# 00 — Char Products, Ek System of Record Par Khare

Ecosystem ka poora page ek line se shuru hota hai: **"One System of Record. Products that teach and
build on it."** Yani sab se pehle ek shared foundation banayi gayi — book khud ko ek System of Record
mein tabdeel kar chuki hai — phir uske upar char cheezein khadi ki gayi hain. Sab **read over MCP**
hain aur **stay in sync** — yani jab book update hoti hai, sab products bhi apne aap us update ko
reflect karte hain, kyunke woh sab wahi ek source parh rahe hain, apni alag copy nahi rakhte.

## 1. Agent Factory System of Record (Beta 1) — Source, Shared Foundation

Yeh book ka content hai — System of Record ki shakal mein, MCP ke zariye serve hota hai. Koi bhi AI
agent ya worker (Claude, ChatGPT, Claude Code, Cowork, ya apka apna) is se connect ho sakta hai aur
book mein "grounded" ho sakta hai — matlab woh guess nahi karta, book ke actual verified sections se
jawab deta hai.

## 2. Zia Tutor AI (Beta 1) — Teaching Lane, Claude Ke Andar

Ek personal learning agent — [Zia Khan](https://www.linkedin.com/in/ziaukhan/) ka **digital twin**, jo
Agent Factory sikhata hai, aapki progress yaad rakhta hai, aur jahan aap ne chhoda tha wahin se continue
karta hai. (Iska poora chapter [Zia Tutor AI](../ecosystem-zia-tutor-ai/README.md) mein hai.)

## 3. Zia Developer AI (In development) — Construction Lane, Aapka Coding Agent

Aapka AI build partner — Claude Code aur OpenCode ke andar. Business problem describe karo; yeh book se
sahi architecture chunta hai, spec likhta hai, aur agent banata hai. (Poora chapter
[Zia Developer AI](../ecosystem-zia-developer-ai/README.md) mein hai.)

## 4. The FDE AF Model (Published) — Blueprint, Sab Kaise Stack Hota Hai

Paanch-layer blueprint jo in products ko ek platform aur ek business model mein arrange karta hai:
foundation, SoR kernel, yeh ecosystem, vertical ecosystems, customer deployments. Foundation ke upar
har layer wahan hai jahan graduates kama sakte hain. (Poora chapter
[The FDE AF Model](../ecosystem-fde-af-model/README.md) mein hai.)

---

Chaaron products ek doosre ko support karte hain: System of Record dono AI products (Tutor aur
Developer) ko content deta hai; FDE AF Model batata hai yeh sab kaise ek business ban jata hai; aur
agar aap khud ka vertical banana chahte ho, to yehi teeno cheezein — SoR, Tutor pattern, Developer
pattern — apni profession ke liye dobara banani hain.
