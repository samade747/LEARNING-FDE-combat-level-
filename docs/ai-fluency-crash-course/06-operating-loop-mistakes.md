# 06 — Part 3: 4Ds Ek Loop Ki Tarah + 4 Beginner Mistakes (Concepts 7-8)

## Concept 7 — The 4Ds As a Practical Operating Loop

Real work chaar competencies mix karta hai:

**Delegate → Describe → Discern → Be diligent → Repeat as needed**

### Example: Bookkeeping Digital FTE

Ayesha, Lahore mein Forward Deployed Engineer, Karachi ki small accounting practice ke liye
bookkeeping Digital FTE build kar rahi hai. Pehla job: monthly bank reconciliation (firm ke records
vs bank statement check karna).

**Step 1 — Delegation:** Ayesha seedha "build me a reconciliation agent" nahi bolti. Accounting
partners ke sath map karti hai: agent match kar sakta, unmatched flag kar sakta, draft report
likh sakta — par **har journal adjustment human approve kare, har write-off decision human rakhe,
tax-position wala kuch accountant ke pas rahe, high-value unmatched items named person tak
escalate ho.**

**Step 2 — Description:** chart of accounts, matching rules, past reconciliation examples, partners
ka report format, escalation rules, duplicate-payment/stale-cheque definitions, aur 2 hard rules:
**agent kabhi journal entry khud post na kare, kabhi client se directly contact na kare.**

**Step 3 — Discernment:** Ayesha demo dekh kar assume nahi karti ke kaam karega — past
reconciliations (jo firm trust karta hai) ke against test karti hai: kitne matches correct,
kitne incorrect slip through, right cases escalate hoti ya nahi, bohot zyada escalate to nahi,
performance time ke sath change hoti ya nahi. **Accountant successful-looking matches bhi review
karta hai, sirf failures nahi** — system silently fail kar ke safe lag sakta hai.

**Step 4 — Diligence:** client financial data approved infrastructure ke andar rehta, agent actions
logged hote, jahan appropriate wahan clients ko bataya jata reconciliation AI-assisted hai, human
partner reconciliation sign karta aur accountable rehta hai.

**Personal skill ab system property ban gayi hai.**

| Competency | Chat Mein | Agent Factory Mein |
|---|---|---|
| Delegation | Decide karo AI se kya puchna | Digital FTE scope + human/AI boundary |
| Description | Instructions + context dena | System prompts, skills, context engineering, SoR |
| Discernment | Answer review karna | Evals, monitoring, sampling, trusting the checker |
| Diligence | Data protect, result own karna | Governance, permissions, audit, disclosure |

### 10-80-10 Rule Se Connection

Book ke Four Survival Skills: direction set karna, AI orchestrate karna, truth judge karna, logon se
connect karna. Pehle teen 10-80-10 Rule banate hain:

- Pehle 10% — direction set karte ho → Delegation+Description strongest
- Middle 80% — AI orchestrate karte ho → Description+Discernment repeat
- Last 10% — truth judge karte ho → Discernment critical
- Across 100% — responsibly act karte ho → **Diligence final checkbox nahi, poore workflow ko
  surround karta hai**

## Concept 8 — 4 Common Beginner Mistakes

| Mistake | Missing Skill | Fix |
|---|---|---|
| Problem define karne se pehle prompt karna | Delegation | Goal, audience, constraints, human/AI split pehle decide karo |
| Pehla answer final samajhna | Description+Discernment loop | Result inspect karo, specific feedback do, dobara try karo |
| Polished answer ko professional lagne ki wajah se trust karna | Discernment | Important facts/assumptions/calculations/sources verify karo |
| Privacy/accountability sirf tab sochna jab kuch galat ho jaye | Diligence | Deploy se pehle data/disclosure/approval/accountability rules decide karo |

## Beginner Checklist — Har Din Use Karne Wala

| Stage | Khud Se Pucho |
|---|---|
| Delegate | Goal kya hai? AI kya kare? Mere pas kya rahe? |
| Describe | Output, context, method, behavior — AI ko kya chahiye? |
| Discern | Answer correct/complete/useful hai, kaise pata chalega? |
| Be diligent | Data safe hai? AI ka role disclose karna hai? Kaun approve/own karta hai? |

Yeh har chhote task ke liye paperwork nahi hai — point yeh hai ke 4 sawal **automatic** ban jayein.
