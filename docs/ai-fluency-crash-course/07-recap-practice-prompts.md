# 07 — Short Recap + 6 Practice Prompts + Self-Check

## Short Recap

AI fluency prompts memorize karna nahi — AI ke sath effectively, efficiently, ethically, aur
safely kaam karna hai.

3 modes: **Automation** (defined task), **Augmentation** (thinking together), **Agency** (goal ki
taraf acting, aksar doosron ke liye).

4 competencies (har mode mein same): **Delegation** (human/AI split decide), **Description** (AI
ko jo chahiye wo do), **Discernment** (jo aaye judge karo), **Diligence** (responsibly use karo,
outcome own karo).

**Ek line yaad karni ho to:** _Decide what AI should do. Describe the work clearly. Check what
comes back. Own what happens next._

## Try This Now — 6 Prompts

Runnable versions `projects/` folder mein hain. Yahan sirf summary + "what to notice":

1. **4D plan for a real task** — AI se ek-ek question lo (delegation/description/discernment/
   diligence), end mein table. _Notice:_ plan mostly tumhare answers hain, AI ka nahi — Delegation
   aur Diligence sirf tum decide kar sakte ho.
2. **Discernment on a known topic** — jo subject tumhe aata ho uspar discuss karo, 3 cheezein
   watch karo (improve/correct/reject). _Notice:_ discernment kitni cheap hai jab tumhe subject
   aata ho.
3. **Feel like a non-expert** — jo subject nahi aata uspar explanation lo, end mein claims verify
   karne wali list maango. _Notice:_ kuch bhi galat nahi laga — kyunke check karne ka kuch tha hi
   nahi. Har Digital FTE user yeh feel karega, isliye evals chahiye hoti hain, trust nahi.
4. **Performance description** — session shuru mein rules set karo (challenge weak assumptions,
   flag uncertainty, politely agree na karo). _Notice:_ farq kitni jaldi fade hota naye chat mein
   agar dobara set na karo — isliye deployed agent system prompt mein rakhta hai, kisi ki memory
   mein nahi.
5. **Inspect justification before accepting** — recommendation se pehle assumptions/evidence/
   criteria/uncertainties maango. _Notice:_ list mein jo assumption tum bina notice kiye accept kar
   lete, wohi sabse zaroori hai check karna.
6. **Full 4D loop on a small project** — ~1 ghante ka project, har AI-owned task se pehle product/
   process/performance pucho, har output ke baad stop karo, end mein diligence check karo.

End mein pucho: **"Which D required the most effort from me?"** — wohi competency sabse zyada
practice chahti hai.

## Quick Self-Check

1. AI fluency ki 4 qualities kya hain?
2. Automation, augmentation, aur agency mein farq kya hai?
3. Delegation ke 3 parts kya hain?
4. Description ke 3 parts kya hain?
5. Confident AI answer ko bhi verification kyun chahiye?
6. Discernment ke 3 parts kya hain?
7. Diligence ke 3 parts kya hain?
8. Shipping se pehle kya sawal puch sakte ho?
9. Ek line mein, 4D loop kya hai?
10. Agent Factory mein Discernment engineering practice kaise ban jata hai?

<details>
<summary>Answers</summary>

1. Effective, efficient, ethical, safe.
2. Automation defined task run karta, augmentation thinking partner hota, agency goal ki taraf
   zyada freedom ke sath acting karta.
3. Problem awareness, platform awareness, task delegation.
4. Product description, process description, performance description.
5. Kyunke sounding right ≠ being correct — fluent wording facts/assumptions/reasoning verify nahi
   karti.
6. Product discernment, process discernment, performance discernment.
7. Creation diligence, transparency diligence, deployment diligence.
8. "Would I confidently put my name on this?"
9. Decide karo AI kya kare, kaam describe karo, jo aaye evaluate karo, poore process ki
   responsibility lo.
10. Eval suites, monitoring, sampling, aur review gates ban jaata hai jo test karte hain AI system
    kaafi achha perform kar raha ya nahi.
