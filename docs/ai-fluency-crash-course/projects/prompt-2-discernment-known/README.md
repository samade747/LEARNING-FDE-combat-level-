# Prompt 2 — Use Discernment on a Topic You Already Know

**Time:** ~10 min · **Tool:** any free AI assistant

## Steps

1. Ek subject choose karo jisme tumhe real experience hai.
2. Yeh prompt run karo:

   ```text
   Let's discuss [topic I know well].

   Talk to me like a knowledgeable colleague, not a lecturer.
   As we go, I will watch for three things:
   - where you improve my thinking,
   - where I need to correct you,
   - where my own experience makes me reject your suggestion.

   Start by asking which part of the topic I want to discuss.
   ```

3. **Notice:** discernment kitni cheap hoti hai jab subject aata ho — wrong claim bina effort ke
   pakad lete ho. Yeh ease tumhari expertise hai, jo exercise 3 mein nahi hogi.

## Done

- [ ] Discussion complete, kam se kam 1 cheez catch ki (improve/correct/reject)
