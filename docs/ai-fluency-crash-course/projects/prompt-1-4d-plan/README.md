# Prompt 1 — Build a 4D Plan for a Real Task

**Time:** ~10 min · **Tool:** any free AI assistant

## Steps

1. Ek real task choose karo jo tumhe is week karna hai.
2. Yeh prompt run karo:

   ```text
   I need to do this: [describe the task].

   Before we start, walk me through the four Ds of AI fluency for it:
   delegation, description, discernment, diligence. Ask me one question
   at a time, skip any that obviously does not apply, and give me the
   plan as a short table at the end.
   ```

3. **Notice:** plan mostly tumhare answers honge, AI ke nahi. Delegation aur Diligence sirf tum
   decide kar sakte ho — AI sirf pucchna yaad rakhta hai.

## Done

- [ ] 4-row plan table mil gayi (delegation/description/discernment/diligence)
- [ ] Pehchana kon se answers sirf tum de sakte the
