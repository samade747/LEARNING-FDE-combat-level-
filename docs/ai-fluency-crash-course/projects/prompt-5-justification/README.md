# Prompt 5 — Inspect the Justification Before Accepting a Recommendation

**Time:** ~10 min · **Tool:** any free AI assistant

## Steps

1. Ek real decision do jo tum weigh kar rahe ho.
2. Yeh add karo:

   ```text
   Before making a recommendation, list:
   1. the important assumptions,
   2. the evidence supporting them,
   3. the criteria you are using to compare the options,
   4. the major uncertainties.

   Then make the recommendation.
   I want a justification I can review, not just a conclusion.
   ```

3. **Notice:** list mein jo assumption tum bina notice kiye accept kar lete — wohi check karne ke
   liye sabse zaroori hai, aur sirf conclusion milne par invisible hoti.

## Done

- [ ] Assumptions/evidence/criteria/uncertainties list mil gayi
- [ ] Kam az kam 1 assumption identify ki jo bina check accept hoti
