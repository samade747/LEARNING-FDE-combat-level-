# 05 — Launch Ke Baad: Ek Source, Do Readers — Aur Ayesha Ki Poori Kahani

## Ek Source, Do Readers

Yeh hissa beginners aksar miss karte hain, to dobara parho. Rule khud kisi technology par depend nahi
karta: ek governed source ko dono human readers aur agent readers serve karna hai, ek owner, versions,
review, permissions, aur citable retrieval ke saath. Agent Factory ke reference implementation mein yeh
aisa dikhta hai:

- **Insaan isay website ki tarah parhte hain.** Corpus Markdown mein likha jata hai aur Docusaurus se
  publish hota hai. Aapke expert ke students, aapke customers ke reviewers, aur khud profession isay
  browser mein parhte hain — bilkul jaise aap yeh book parh rahe ho.
- **Agents wahi content MCP ke zariye parhte hain.** Wahi Markdown pgvector se index hoti hai, to agents
  meaning se search karte hain, aur MCP tools ke zariye serve hoti hai, to agents exact sections fetch
  aur cite karte hain.

Content do baar nahi likhi jati. Ek governed source dono readers ko serve karta hai, kyunke
[Layer 1 kernel](../ecosystem-fde-af-model/README.md#layer-1-the-content-system-of-record-component-the-sor-kernel)
isi tarah bani hai: Markdown andar, website bahar insaano ke liye, MCP bahar agents ke liye.

Aur yaad rakho model ki warning: [akela search System of Record nahi hai](../ecosystem-fde-af-model/README.md).
Content ko ek named owner, review aur approval, versions, aur access control bhi chahiye. Content load
karte hi usi hafte governance set up karo, baad mein nahi. Slice bhi day one se governed asset hai, baad
mein tidy karne wala draft nahi.

Growth ke baare mein ek aakhri baat: ek move jo growth jaisa lagta hai lekin nahi hai — **ek country add
karna.** Ek jurisdiction ke rules ke liye bana trio aur doosre ke liye bana trio, ek governed ghar ke
andar do alag builds hain, sirf expert ki apni methodology share karte hue. Har ek dobara thin shuru
hota hai.

## Ayesha Poora Checklist Chalati Hai

Poora page ek chhoti kahani ban jata hai.

Ayesha, [model page](../ecosystem-fde-af-model/README.md) wali graduate, teen candidates consider karti
hai.

**Customer support** screen par sabse high score karta hai. Har company isay kharidti hai. Contract of
success likhna aasan hai. Lekin yeh Test 3 fail karta hai — knowledge zyada tar har client ki apni
documents hoti hai, aur woh koi support expert nahi janti jiske paas written material ho. To yeh uska
**service domain** ban jata hai. Woh client Systems of Record banati hai aur Layer 4 engagements chalati
hai. Yeh kamata hai jab tak woh search karti rehti hai, aur isay koi slice nahi chahiye, kyunke yeh koi
vertical nahi bechta.

**E-commerce operations** Test 4 fail karta hai. "Rules" marketplace policies hain jo bina notice ke
badalti hain. Yeh corpus govern nahi ho sakta. **Parked.**

**Accounting** screen aur aath mein se 7.5 tests pass karta hai. Test 3 hi jeet hai — uski **aunty,
bees saal ki practice, apni written material ke saath.** Expert decide karta hai. Audit working papers,
apne written standards aur checkable output ke saath, beachhead hain.

Phir window order mein chalti hai. Aunty sign karti hai, aur corpus ka har source ek licensing answer
paata hai: do gates, koi code abhi nahi. Ab woh ek slice banati hai, apni aunty ki files par. Outcome:
ek complete working paper, evidence-backed, reviewer approval ke liye ready. Aunty ke saath paanch real
files, jismein ek woh bhi jo review mein fail hui thi. Invariants jo aunty kabhi nahi todegi, going-
concern judgment samet jo sirf ek partner sign kar sakta hai. Ek derived procedure, ek checker, aur ek
evaluation set jismein missing-evidence case bhi hai. Docusaurus website ki tarah publish, jo uski aunty
ke students parh sakte hain, aur wahi content jise uske Workers MCP se cite karenge.

Yehi slice usay teesra gate deta hai. Ek mid-size firm ka partner working papers wala ek page parhta hai,
apni khud ki firm se behtar likha hua, aur poochta hai yeh uske juniors ke har file par lagne wale char
ghanton ke liye kya karega. Wahi baseline hai, uske paas se aayi, Ayesha se nahi. Ek drafted contract of
success follow karta hai: char ghante se chalees minute, uske apne reviewers acceptance criteria ki
tarah. Real quoted costs uski guesses ki jagah lete hain. Chaar gates. Launch. Uska pehla engagement
wahi working-paper file hai, chalees minute mein deliver hui — bilkul wahin jahan
[model page](../ecosystem-fde-af-model/README.md#layer-4-customer-instances) uski kahani uthata hai.
