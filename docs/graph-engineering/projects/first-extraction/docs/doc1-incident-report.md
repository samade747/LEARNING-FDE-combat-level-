# Incident Report INC-2091

On 2026-06-03, the checkout service experienced a 40-minute outage. Root cause: a defective batch of
the rate-limiter module, Component Z9, which had been supplied by **Aria Components Ltd** under
contract AC-2024-11. The vendor was notified the same day. Aria Components Ltd confirmed the batch
defect on 2026-06-05 and issued a recall notice for all Z9 units shipped after 2026-05-01.

The on-call engineer, Priya Nair, escalated the incident to the platform team lead once the recall
notice was confirmed.
