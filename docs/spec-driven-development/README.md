## Ek Line Mein Poori Cheez

> **"Agree on the what before you generate the how."** Vibe coding mein aap AI ke banate waqt sochte
> ho. **Spec-Driven Development (SDD)** mein aap **pehle** sochte ho aur likhte ho — code shuru hone se
> pehle aap aur AI dono "done" pe agree karte hain. **Spec source of truth hai, code build output hai.**

## Zaroori Data Point

Anthropic ke ~400,000 agentic coding sessions ke analysis mein: log **planning** decisions ka 70% khud
karte hain (kya banana hai), agent **execution** ka 80% (kaise banana hai). Success ka sab se bara
predictor coding skill nahi tha — **domain expertise** thi. **Spec wahi jagah hai jahan aapki expertise
jati hai.**
