# 05 — Practice (6 Projects)

SDD parhna seekhna nahi hai. Discipline tab aapki banti hai jab aap poori loop real cheez pe chalao aur
mehsoos karo Clarify phase ne ek galti pakri jo warna ship ho jati. **Har project ke liye 4 artifacts
banao:** constitution, `spec.md`, `plan.md`, `tasks.md`, + working result.

**Success test:** *"Kya ek ajnabi sirf spec se sahi cheez bana sakta hai, koi sawal poochhe bagair?"*

---

### Warm-up: Interview Mehsoos Karo (claude.ai, ~30 min)
Sab se chhoti real cheez chuno (study planner, CSV-to-summary tool). Project banao, 3-line constitution
paste karo, 4 phases chalao. **Ek rule: Concept 7 skip mat karo.** Claude se interview karwao code se
pehle. Count karo kitne decisions ate hain jo aap ne kabhi sochay nahi thay.

### Project 1: Real Rules Wali Feature (claude.ai, ~1 hr)
"Tag and filter" feature Smart Notes ke liye spec + build karo. Edge cases pin karo: koi tags nahi? Duplicate
tags? Filter jo kuch match na kare? **Done jab:** spec in 5 ka jawab de code se pehle.

### Project 2: Repo Mein Move Karo (Claude Code/OpenCode, ~2 hrs)
Project 1 ko chat window se nikal kar coding agent mein wahi loop chalao. Constitution `CLAUDE.md`/
`AGENTS.md` mein, `spec.md`/`plan.md`/`tasks.md` repo files ki tarah. **Ek task ek waqt, har ek ke baad
commit.** **Done jab:** `git log` ek clean commit per task dikhaye.

### Project 3: Spec Ko Zinda Rakho (Sab Se Mushkil, ~1 hr)
Ab apna mind badlo. Naya requirement add karo (tags color-coded ho sakte hain). **Pehle `spec.md` edit
karo**, changed section pe Clarify dobara chalao, plan/tasks update karo, phir implement karo. **Done
jab:** `spec.md` ka diff aur code ka diff same story batayein. Phir code parho, ek jagah naam do jahan
shape ab bura hai — usay bhi fix karo.

### Project 4: Aisi Code Ke Andar Kaam Karo Jo Aap Ne Nahi Likhi (~2 hrs)
Koi chhota open-source project clone karo jo pehle kabhi nahi dekha. Is dafa **Phase 1 sab se zyada
zaroori hai** — agent se research karwao existing code kaise structured hai, subagents ek ek area ke
liye. Spec mein "fits the existing system" section ho. **Done jab:** feature aisi lage jaise wo hamesha
codebase ka hissa thi.

### Project 5: Bina Code Ke SDD (claude.ai, ~45 min)
Prove karo ye thinking discipline hai, coding nahi. Koi repeatable **process** chuno, app nahi — weekly
status report, content-repurposing pipeline, inbox-triage routine. Wahi loop chalao jahan "build"
**process aur uske prompts** produce kare, source code nahi. **Done jab:** koi bhi spec se process chala
kar consistent result pa sake.

### Project 6: Stranger Test, Asal Mein (Capstone, ~1.5 hrs)
Ab tak aap khud check kar rahe thay — sab se kamzor reviewer, aapko pata hai kya matlab tha. **Khud ko
hatao.** Ek feature ki spec likho, phir usay ek **fresh, empty AI session** ya kisi peer ko do, **zero
sawal** ki ijazat ke sath. Jahan bhi wo galat cheez banayein, ye **spec ki ghalti hai**, unki nahi —
spec fix karo, code nahi, dobara try karo. **Done jab:** cold reader pehli dafa mein wo bana de jo aap
ne asal mein mana tha.
