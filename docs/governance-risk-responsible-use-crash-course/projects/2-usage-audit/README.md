# Project 2 — Run a Usage Audit

**Time:** ~30 min · **Tool:** any free AI assistant (ya hand se)

Apni team (ya khud) ki pichle mahine ki AI use review karo.

## Steps

1. **5 sawal pucho** (Concept 8.1): Kaunse AI workflows actually use mein hain? Kya data unse
   guzar raha? Kya defined human gates really chali? Kaunse naye tools/Skills/connectors add
   hue? Model/feature/route/data/audience mein kya change hua?
2. **3 gaps dhoondo** jaisa worked example mein (unapproved entry point, no-source-check Skill,
   skipped review gate) — apne real mahine se.
3. **Process audit karo, person nahi** — har gap ke liye pucho: kya rule confusing thi, kya
   friction thi, kya gate weak place par thi? Blame individual par mat daalo.
4. **Friction rule apply karo** — jo bhi workaround mila, pucho: _"Approved tareeqa unsafe
   tareeqe se harder kyun hai?"_
5. **Har gap ke liye habit-level fix likho** (reminder, built-in vetting step, non-negotiable
   gate) — disciplinary action nahi, policy-relax nahi.

## Done

- [ ] Kam az kam 2 real gaps mile (ya confirm kiya koi nahi mila)
- [ ] Har gap ka habit-level fix hai, blame nahi
- [ ] Kam az kam 1 friction identify ki jo unapproved path ko easier banati
