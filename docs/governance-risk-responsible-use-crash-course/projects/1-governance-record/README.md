# Project 1 — Build a Governance Record

**Time:** ~45-60 min · **Tool:** any free AI assistant

Ek real workflow pick karo jo tum own/influence karte, jahan AI already help karti ya soon
karegi. Made-up/synthetic example use karo agar data sensitive hai.

## Steps

1. **The Case** (Chapter 01) — AI kya karta, human kya karta likho. Classification +deciding
   factor+gate likho.
2. **The Data** (Chapter 02) — kya data enters, uski tier. Identifiers chahiye ya nahi. Approved
   route.
3. **The Capability** (Chapter 03) — har Skill/connector/tool ke liye source+reach+fit+outside-
   content+actions. Outcome: enable/escalate/decline.
4. **The People** (Chapter 04) — kaun affected (jo nahi dekhte including). Fairness check.
   Disclosure decision. Escalation (agar koi).
5. **The Evidence** — success measure, failure threshold, monitor+cadence, residual risk.
6. **Share karo** — jo workflow/policy/risk owns karta usko bhejo: _"Yeh hai jaise main workflow
   chalane ka propose karta hoon. Koi assumption correct karo."_
