# How to Think in the AI Era — Summary

Fifth Foundations course — AI gravity ke khilaf 6 thinking disciplines. Fetched: Zia Tutor AI, 3
windows (complete), 2026-10-23.

## 00 — Overview
- Person A vs Person B, AI gravity (3 forces), cognitive capital, "deliverable = documented
  evidence of thinking" rule, 5-of-6 essentials, 6-discipline map (3 Parts: Foundations/
  Detection/Origination).

## 01 — Prediction Lock (Discipline 1)
- 4 lines (real decision/settling fact/position/confidence+flip). Only Lines 1-2 go in the AI
  prompt. Maya + bank-manager worked examples. Research: premortem, forecasting calibration,
  anchoring.

## 02 — Reasoning Receipt (Discipline 2)
- 3-column rows, 5 labels (ACCEPT/REJECT/MODIFY/SURFACED/MISSED). "Nobody audits, why bother"
  objection answered. All-ACCEPT warning. Research: reflection-in-action, double-loop learning,
  generation effect.

## 03 — Error Taxonomy (Discipline 3)
- 6 named error types (factual/logical gap/false confidence/missing context/fabricated source/
  stale fact). Used-car worked example (5/6 caught). Research: processing fluency, cognitive
  ease, confidence≠accuracy, Gigerenzer.

## 04 — Thinking in Systems (Discipline 4)
- Cascade Map 5-step build (5 groups, 3 layers, find the loop). Tutoring-chatbot + loan-officers +
  sports-day worked examples. Research: bullwhip effect, Beer Game, leverage points (Meadows).

## 05 — First Principles (Discipline 5)
- Named threshold vs vague complaint. Coding-club-fees worked example (3 boundaries). Research:
  ecological rationality, recognition-primed decisions, falsifiability (Popper).

## 06 — Working WITH AI (Discipline 6)
- Three-path comparison (Solo/AI-only/Collaborative). Deadline-extension-email worked example.
  Research: centaur chess, AI-lifts-the-least-skilled, AI-compresses-toward-middle.

## 07 — Capstone + Recap
- Student-council $10,000 decision run through all 6 disciplines. Decision-importance table (when
  to use how many disciplines). 8-point recap.

## 08 — Terms + Where to Go
- 19-term glossary. Mode-based next steps (Claude Code/Cowork/Build AI Agents).

## 09 — Test Your Understanding
- Book's own 31-question scenario-based `<Quiz>` block (English, verbatim, answers+sources
  inlined).

Practice projects (4) scaffolded in `projects/`: call-it-before-it-happens (premortem),
audit-the-confident-answer (receipt+error-scan), question-that-unlocked-it (reframe), and the
decision-dossier capstone — each run on a real decision from the learner's own week.
