# Project 3 — The Question That Unlocked It

**Time:** ~20 min · **Tool:** any free AI assistant

Poora page argue karta ke power **sawal** mein hai, answer mein nahi. Yeh prove karo kisi cheez
par jahan tum stuck ho.

## Steps

1. Real problem pick karo jo normally AI ko "mujhe kya karna chahiye?" bol kar dump kar dete.
2. Woh sawal likho jo normally poochte — **ek line mein**. Phir **wo mat pucho.** Behtar sawal
   maango:

   ```text
   I'm stuck on [your problem]. Don't solve it yet. Instead, ask me the
   five questions I should answer before I even try to solve this,
   ordered from the one most likely to change my whole approach down
   to the least. Then tell me which one I'm probably avoiding.
   ```

3. List ko apne original sawal ke against parho. Usually ek sawal (jisay "avoid kar rahe" AI
   bolta) poora problem reframe kar deta — galat cheez solve karne ki koshish kar rahe the.
4. Woh ek sawal khud answer karo, 1-2 sentence mein, dekho original problem shape kaise change
   hota.

## Done

- [ ] Reframed question naam ki jo problem dekhne ka tareeqa change kiya
- [ ] Ek sentence mein bataya kyun shuru ka sawal galat tha
- [ ] Dono Decision Dossier mein add kiye
