## Ek Line Mein Poori Cheez

> **OpenClaw** aapka **Personal AI Employee** hai — open-source assistant jo aapke apne laptop pe
> chalta hai aur WhatsApp/Telegram/Discord jaisi messaging apps ke zariye reply karta hai. Aap ise
> apne **general agent** (Claude Code/OpenCode/Cowork) ke zariye install/configure karte ho — agent
> sab kaam karta hai, aap sirf wo faislay lete ho jo sirf aap le sakte ho (QR scan, API key, OAuth).

## Collaboration Pattern

1. Aap ek sentence paste karte ho apne general agent mein
2. Agent `AGENTS.md` brief consult karta hai, plan proposes karta hai
3. Aap approve karte ho aur dekhte ho
4. Agent **seam** pe rukta hai — jahan sirf aap kar sakte ho
5. Aap "done" ho jate ho jab ek observable cheez hoti hai
