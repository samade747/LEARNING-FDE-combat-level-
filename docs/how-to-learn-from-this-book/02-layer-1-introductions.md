# 02 — Layer 1: The Introductions

Yeh woh pages hain jo sidebar mein Crash Courses ke upar baithi hain. Inhein isi order mein parho —
sirf orientation ke liye, sirf itne notes lo jitni vocabulary hold karne ke liye chahiye:

1. About: What Is This Thing I'm Holding?
2. **How to Learn from This Book** — yehi page jo aap abhi parh rahe ho
3. The Roles This Book Trains
4. The Ecosystem
5. Preface: Why Now, What's at Stake
6. AI Is Non-Negotiable: Answering the Objections
7. Thesis: The Architectural Argument
8. The Operating Layer: The Interface Argument
9. What You Carry In: The Ownership Argument
10. Getting Paid as a Vertical FDE

Inka kaam koi skill sikhana nahi. Inka kaam hai woh vocabulary install karna jo baad ka har page
assume karta hai: Digital FTE, AI Worker, general agent, AI-Native Company, Two-Layer Model,
10-80-10 Rule, invariants, Forward Deployed Engineer, aur vertical System of Record. Yaad rakhna
zaroori nahi — pehchan lena zaroori hai jab koi course bina explain kiye yeh term use kare.

Item 10 ek alag kaam karta hai. Baqi nau explain karte hain ke book kya sikhati hai. Yeh explain
karta hai ke uski **qeemat** kya hai — aur yeh woh page hai jo us din parhna chahiye jab courses
zyada mehnat, kam visible return jaisa lagne lagein.

[Thesis](../thesis/README.md) woh page hai jise log sabse zyada skip karte hain, aur yeh book ka
sabse mehenga skip hai. Agar Layer 1 ke sirf teen pages parhne hain, to About page, Thesis, aur
Getting Paid as a Vertical FDE parho: yeh kya hai, yeh kaise kaam karta hai, aur iska kya milta hai.
