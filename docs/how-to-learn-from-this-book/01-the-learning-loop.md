# 01 — The Learning Loop

Paanch layers **material** describe karti hain. Yeh loop batata hai us material ke sath **aap kya
karte ho**. Har major topic par isay chalao:

> **Orient, Learn, Practice, Recall, Apply, Unblock, Discuss, Verify, Continue.**

| Stage | Aap Kya Karte Ho | Layer |
| --- | --- | --- |
| **1. Orient** | Topic ko place karo: yeh kis liye hai, aur kis se connect hota hai | 1, course ka opening promise |
| **2. Learn** | Essential concepts ek baar study karo | 2 |
| **3. Practice** | Prompts run karo, project banao, commands type karo | 2 |
| **4. Recall** | Page band kar ke khud ko test karo | 2 (quiz aur flashcards) |
| **5. Apply** | Idea ko apne real task par use karo | Aapki job, startup, coursework |
| **6. Unblock** | Woh specific gap bharo jo real kaam ne dikhaya | 3 aur 4 |
| **7. Discuss** | Poocho, jawab do, aur usi passage ki alag readings compare karo | 5 |
| **8. Verify** | Result, sources, aur apni khud ki understanding check karo | Aap |
| **9. Continue** | Agla task lo, jo agla gap dikhayega | Loop dobara |

Yeh loop ek chhote topic ke liye ek ghanta le sakta hai ya ek bare project ke liye kai hafte —
lekin sequence nahi badalti. Jo reader kabhi stage 5 tak nahi pohanchta, woh table of contents ne
chune huay material ko parhta hai, kisi real problem ne nahi.

## Stage 5 — Jahan Loop Sabse Zyada Tootta Hai

Table mein stage 5 ke liye jo source diya gaya hai woh dekho: **aapki job, aapki startup, ya aapki
coursework.** Ek student ke paas coursework hai. Ek employed developer ke paas job hai. Jobs ke
darmiyan phansa developer — uske paas dono nahi, aur kitna bhi parh lo, woh input khud paida nahi
hoti.

Yeh motivation ka masla nahi — yeh **missing input** ka masla hai.
[Getting Paid as a Vertical FDE](../how-to-get-paid-agentic-ai-era) yehi input supply karta hai:
abhi client ko kya bana kar bech sakte ho, aur baad mein kya own karo. Agar aapka loop hamesha
Apply par ruk jata hai, to naya course shuru karne ki bajaye woh page parho.
