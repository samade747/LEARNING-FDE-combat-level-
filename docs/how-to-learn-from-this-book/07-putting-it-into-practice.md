# 07 — Putting It Into Practice

## How to Spend the Time

Ek single sitting mein, saat-step routine chalao aur aakhri paanch minute ek sawal ke liye rakho:
is hafte main kaunsa real task try karoonga? Lambe horizons ke liye, woh plan chuno jo aapke asal
waqt se match kare.

| Plan | Waqt | Aap Kya Karte Ho | Kahan Pohanchte Ho |
| --- | --- | --- | --- |
| **The weekend** | ~8 ghante | About page aur Thesis, phir chhe Foundations courses, quizzes aur flashcards ke sath | Apne kaam par AI se productive, mode choose karne ke liye ready |
| **The month of evenings** | Hafte mein 4 shaamein, kul 15-20 ghante | Week 1 mein Layer 1, phir Foundations, phir general agent course, phir apna mode, ek course per sitting | Pehla Digital FTE ship, aur ek portfolio artifact jo client ko dikha sako |
| **The cohort** | Ek term | Wohi sequence, slide decks se taught, private annotation group aur weekly checkpoint quizzes ke sath | Ek poori room jinhon ne sab kuch banaya ho |

Learning tab durable banti hai jab aap idea **use** karte ho, sirf uske baare mein parhna khatam
karne se nahi.

## A Classroom Pattern

Teachers, trainers, aur study-group leaders yehi material ek structured lesson ki tarah chala
sakte hain:

1. Topic ko presentation se introduce karo.
2. Crash Course assign karo, aur har learner ko class group mein do passages annotate karne ko
   kaho: ek jo important laga, ek jo confusing laga.
3. Session confusing wale se shuru karo. Annotations batati hain kya sikhana hai, baat shuru karne
   se pehle.
4. Practical exercise sath mein karo, phir quiz ko checkpoint ki tarah use karo aur flashcards
   baad ki review ke liye assign karo.
5. Class ko ek real problem do jo concept maange, aur unhein references aur Zia Tutor AI ki taraf
   point karo jab gap dikhe.
6. Har learner se woh decisions explain aur defend karwao jo unhone liye.

Steps 2 aur 3 asal kaam karte hain. Baqi sab ordinary achi teaching hai.

## Your Responsibility as a Learner

AI explain, summarize, quiz, guide, aur personalize kar sakta hai. Yeh aapki understanding ki
zimmedari nahi le sakta. Yeh zimmedari aapki hi rehti hai: critically sochna, claims test karna,
sources check karna, apni uncertainty naam lena, skills practice karna, AI ka output evaluate
karna, aur zaroorat par human help maangna.

Chhe habits isay practice mein le aati hain:

1. **Sab kuch verify karo, is book ko bhi.** Tools badalte hain, prices move karte hain. Jab kuch
   stale mile, `correction` tag ke sath annotate karo.
2. **Glossary khula rakho.** Ek tab, permanently.
3. **Ek waqt mein ek course.** Naya shuru karne se pehle purana khatam karo.
4. **Kuch chhota jaldi ship karo.** Ek tiny working cheez, ek bade planned cheez se zyada sikhati hai.
5. **Wapis sikhao.** Deck use karo, dost, ya khali kamra. Explanation woh test hai jo fake nahi ho
   sakta.
6. **Akele mat parho.** Ek taraf tutor hai, doosri taraf margin.

In chhe ke neeche wohi rhythm hai jo yeh book AI workers banane ke liye sikhati hai — apni khud ki
learning par apply ki gayi. Aap pehle 10% mein intent set karte ho: decide karte ho kya seekh rahe
ho aur kyun. Layers 80% execution carry karti hain. Aap outcome verify karte ho, aakhri 10%: apne
aap ko sabit karte ho ke samjha aur dobara kar sakte ho.

**Yeh do hisse aap kisi ko nahi de sakte. Isi liye practice karne layak hain.**

## The Exit Check

Poora system use ho chuka jab paanchon tick ho sakein, ek per layer:

- [ ] Main Digital FTE bina dekhe define kar sakta hoon **(Layer 1)**
- [ ] Maine ek Crash Course project ship kar diya **(Layer 2)**
- [ ] Maine ek reference isliye khola kyunke real kaam ne wahan bheja, syllabus ne nahi **(Layer 3)**
- [ ] Maine Zia Tutor AI se ek aisa sawal poocha jo kisi insan se poochte huay sharam aati **(Layer 4)**
- [ ] Maine ek annotation chhoda jo agle reader ki madad karega **(Layer 5)**

Koi bhi un-ticked box batata hai kaunsi layer abhi use nahi ho rahi.

## Start Here

Char moves, order mein:

1. [Thesis](../thesis/README.md) parho, us vocabulary ke liye jo baqi sab assume karta hai.
2. Getting Started: Crash Courses kholo aur What AI Actually Is se shuru karo.
3. Zia Tutor AI connector add karo, taake teacher zaroorat se pehle wahan ho.
4. Jab annotation margin aap tak pohanche, is page ke right edge par sidebar kholo aur pehla note
   us paragraph par chhodo jis se aap disagree karte ho.

Phir jitni jaldi ho sake real kaam shuru karo, kyunke kaam hi batata hai agay kya seekhna hai.

> **Itna seekho ke shuru kar sako. Itna banao ke gaps discover ho jaayen. Jab kaam demand kare,
> dobara seekho.**
