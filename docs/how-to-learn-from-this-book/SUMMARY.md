# How to Learn from This Book — Summary

Core idea: **"Foundation First. Practice Early. Depth on Demand."** Poora reference material front-to-back parhna galat hai; courses skim karna bhi galat hai. Book ka learning system 5 layers + ek 9-stage loop + ek 7-step per-course routine deta hai.

## 00 — The Five Layers

- **Content layers (sthir, aapka wait karti hain):** 1. Introductions (parho ek baar order mein, ~2-3 ghante — "done" jab Digital FTE apne alfaz mein define kar sako), 2. Crash Courses (practice sequence mein — "done" jab course jo maange woh ship kar chuke ho), 3. References (consult on-demand, kabhi "done" nahi).
- **Interactive layers (jawab dete hain):** 4. Zia Tutor AI (poocho jab confusion ho, one-to-one, "kabhi done nahi — teacher hai"), 5. Social Annotation (shared margin, Hypothesis se built-in, many-to-many). Tutor attention scale karta hai, margin accumulate hota hai — dono use karo, alag lamho ke liye.

## 01 — The Learning Loop

- 9-stage loop poori book par: **Orient → Learn → Practice → Recall → Apply → Unblock → Discuss → Verify → Continue** (har stage ka apna layer).
- Stage 5 (Apply) sab se zyada tootta hai — student ke paas coursework hai, employed developer ke paas job hai, jobs-ke-darmiyan phansa developer ke paas dono nahi. Yeh missing-input problem hai — [Getting Paid as a Vertical FDE] page isay supply karta hai.

## 02 — Layer 1: The Introductions

- 10 orientation pages ki list (About, How to Learn, Roles, Ecosystem, Preface, AI Is Non-Negotiable, Thesis, Operating Layer, What You Carry In, Getting Paid). Inka kaam vocabulary install karna hai (Digital FTE, AI Worker, Two-Layer Model, 10-80-10 Rule, invariants, FDE, vertical SoR) — yaad nahi, sirf pehchan zaroori.
- Agar sirf 3 parhni hon: About, Thesis, Getting Paid as a Vertical FDE. Thesis sab se zyada skip hoti hai aur sab se mehenga skip hai.

## 03 — Layer 2: The Crash Courses

- Naqsha: Foundations → General Agents → Personal Agent Harnesses → (Mode 1 ya Mode 2) → References/Companions. 2 rules: ek waqt mein ek course; jo sirf parha jaye, liya nahi gaya (closing section = seekhne ki jagah).
- **7-Step Course Routine:** 1) Promise+question list parho, 2) Slides skim karo, 3) Pehli baar structure ke liye parho, 4) Closing work karo (prompts/project/commands — reading ko skill mein badalta hai), 5) Quiz do (page band karke), 6) Flashcards (spaced repetition schedule), 7) Confusing passage annotate karo (90 sec, Layer 5).
- Honest self-grade: 3-sentence explain kar sakte ho? blank-screen dobara kar sakte ho? ek gap naam le sakte ho? Quiz-galat-jawab 4 moves: section wapis jao, galat samajh naam lo, apne alfaz mein explain karo, ek din baad retry.

## 04 — Layer 3: The References

- Glossary, Cheatsheets, Which AI Employees Should You Use in 2026 — **consult-on-demand**, front-to-back nahi. Jab: current page term assume kare, command/flag dekhna ho, AI workers compare karna ho.
- **Just-in-time education:** traditional fixed-sequence ki jagah, concept usi waqt seekho jab useful ho. On-demand ka matlab foundation-free nahi — foundation ke bina galat sawal bhi confidently answer hoga. **"Foundation first, then depth on demand."**

## 05 — Layer 4: Zia Tutor AI

- Book khud ko teach karti hai, named teacher ki tarah (connector-native, koi app download/subscription nahi). 3 steps: connector add+authorize, "Teach me the Agent Factory" kaho, baad mein "continue where I left off."
- Naam se greet karta hai, sessions/hafton mein yaad rakhta hai, book ke apne content se parhta hai (open internet se nahi).
- 2 aur tareeqe: System of Record connector (MCP, read-only, cite karta hai), Copy as Markdown button (per-page, Cmd/Ctrl+Shift+C).
- Poochne layak sawal examples diye gaye (beginner-friendly explain, quiz-one-at-a-time, correction explicitly maango — "AI default se agreement ki taraf jhukta hai"). **Augmentation, replacement nahi** — teacher + AI tutor milkar.

## 06 — Layer 5: Social Annotation with Hypothesis

- Har page mein built-in margin — passage highlight, comment/sawal/link attach, doosre reply karte hain. Har sawal signal hai kaunsa paragraph apna kaam nahi kar raha.
- Kaise use: sidebar kholo (Notes &amp; Highlights), likhne se pehle parho (account nahi chahiye), likhne ke liye login, group check karo (Public vs private group) phir highlight, likho/tag/post karo. Orphan annotation note (page edit ho to anchor kho sakta hai).
- **Tags:** question, correction, example, bridge, domain-tags (accounting/legal/medicine).
- **5 annotation types:** Clarify, Connect, Question, Apply, Correct — honest sawal sab se valuable hai. "Great point" avoid karo.
- Teachers ke liye: private Hypothesis group (Public nahi) — students zyada honest likhte hain.

## 07 — Putting It Into Practice

- **3 time plans:** Weekend (~8 ghante — About+Thesis+6 Foundations), Month of evenings (15-20 ghante, 4 shaamein/hafta — pehla Digital FTE ship), Cohort (ek term, slide decks + private annotation + weekly quizzes).
- **Classroom pattern (6 steps):** presentation → assign + 2 annotations (important+confusing) → confusing-se-shuru session → practical exercise + quiz + flashcards → real problem do → decisions explain/defend karwao.
- **Learner responsibility (6 habits):** sab verify karo (is book ko bhi), glossary khula rakho, ek waqt mein ek course, chhota jaldi ship karo, wapis sikhao, akele mat parho.
- **Exit Check (5 checkboxes, ek per layer):** Digital FTE define kar sakta hoon, project ship kiya, reference real-kaam-se khola, Zia se sharam-wala sawal poocha, agle-reader-ki-madad-wali annotation chhodi.
- **Start Here (4 moves):** Thesis parho → Crash Courses kholo (What AI Actually Is se) → Zia Tutor connector add karo → margin sidebar kholo pehla note chhodo.
