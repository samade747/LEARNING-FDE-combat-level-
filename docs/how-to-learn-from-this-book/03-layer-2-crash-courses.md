# 03 — Layer 2: The Crash Courses

**Getting Started: Crash Courses** naqsha rakhta hai, aur naqsha short hai: [Foundations](../foundations)
sab ke liye, phir [General Agents](../general-agents), phir
[Personal Agent Harnesses](../personal-agent-harnesses), phir do tracks mein se ek
([Mode 1](../mode-1-problem-solving) ya [Mode 2](../mode-2-manufacturing)), phir References aur
Companions.

Is layer par do rules chalti hain:

**Ek waqt mein ek course.** Chhe courses aadhe parhna, ek course poora karne se **kam** sikhata
hai. Sidebar ka order suggestion nahi — **dependency order** hai.

**Jo course sirf parha jaye, woh course liya nahi gaya.** Har Crash Course prompts, projects, ya
build par khatam hoti hai. Woh closing section wahi jagah hai jahan seekhna hota hai — kyunke sirf
wahi hissa hai jahan machine aapko galat sabit kar sakti hai.

Progress ko pages se mat measure karo. Isay measure karo us se jo aap explain, apply, aur verify
kar sakte ho.

## The Crash Course Routine — Saat Steps

Poore book par phaila nau-stage loop upar mila. Stages 1 se 4 tak ek single course ke andar hote
hain, isliye unka apna routine hai — saat steps, har baar. Ek loop, uske andar ek routine nested.
Yeh sirf do sequences hain jo yaad rakhne layak hain.

**1. Promise aur question list parho.** Har course batata hai ke woh kya cover karta hai, kitna
waqt lagta hai, aur kya assume karta hai. Course se **pehle** yeh list parho aur 2-3 sawalon ka
jawab dimagh mein sochne ki koshish karo. Ghalat guesses bhi useful hain — woh dikhate hain kaunsa
mental model correct hone wala hai.

**2. Slides skim karo.** Jahan course ke pass **Teaching Aid** ho, usay ek baar jaldi click through
karo. Paanch minute ke slides poore course ki shape de dete hain.

**3. Pehli baar structure ke liye parho.** Yahan master karne ki koshish mat karo. Lambe side trips
avoid karo, lekin ruko jab koi missing term next section block kare — [glossary](../glossary) kholo,
meaning lo, wapis aao. Is stage par kuch confusion normal hai.

**4. Closing work karo.** Prompts run karo. Project banao. Commands type karo. Yehi step hai jo
reading ko skill mein badalta hai — aur yehi step hai jo log tab skip karte hain jab thake hue hon.

**5. Quiz do**, page band kar ke, kuch dobara parhe bina. Phir sirf woh dobara parho jo miss huwa.

**6. Flashcards kaam karo** ek schedule par.

**7. Jo confuse kare usay annotate karo.** Tab band karne se pehle, us passage par ek note chhodo
jisne sabse zyada pareshan kiya. Yeh Layer 5 hai, aur 90 seconds leta hai.

> **Khud ko honestly grade karo.** Har course ke aakhir mein teen sawal: (1) Kya main core idea ko
> kisi colleague ko teen sentences mein, page khole bina, explain kar sakta hoon? (2) Kya main main
> task ko blank screen se dobara kar sakta hoon, course se copy kiye bina? (3) Kya main ek cheez
> naam le sakta hoon jo abhi bhi samajh nahi aayi? Confident haan, haan, aur teesre sawal ka koi
> specific jawab — matlab aap done ho.

## Quiz Aur Flashcards — The Practice Engine

Yeh do extras nahi hain. Inme lagaye minute har course ke sabse valuable minute hain, kyunke yeh
**recall** test karte hain, recognition nahi.

> **Course aapko sikhata hai. Quiz pata karta hai kaam hua ya nahi. Flashcards decide karte hain ke
> teen mahine baad bhi yeh aapke paas hai ya nahi.**

Quiz galat jawab par 4 moves, order mein: (1) relevant section par wapis jao, (2) precisely naam lo
ke kya galat samjha, (3) sahi jawab apne alfaz mein explain karo, book ke alfaz mein nahi, (4) ek din
baad dobara try karo. **Step 3 wohi hai jo log skip karte hain aur jo kaam karta hai.**

Flashcards spaced repetition use karte hain: same din, agla din, ek hafta baad, ek mahina baad.
Chaar chhoti reviews ek mahine mein, dohrayi hui re-reading se kam waqt leti hain aur behtar yaad
rehti hain.
