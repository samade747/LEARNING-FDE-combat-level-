# 05 — Complete Worked Example: Weekly Industry Brief

Ye ek **recurring task** hai jise aap dheere dheere trust karte hue **schedule** tak le jate ho —
autonomy ladder deliberately chadte hue.

**Scenario:** Har Monday industry news parhne mein poori subah lagti hai. Agent ko Sunday raat synthesis
karne do, Monday subah sirf review ho.

## Cowork Mein

1. **Session nahi, Project banao** — "Industry weekly brief" naam se. Folders + connectors add karo
2. **Project instructions:**
```text
This project produces a weekly industry brief, delivered Monday at 8am.
Sources:
- Articles saved to /weekly-brief/articles-this-week/
- Slack #industry-news channel from the past 7 days
- Notion page "Ongoing Themes"
Output:
- Top 3 stories (one paragraph each, with link)
- 1 paragraph "what changed for our space this week"
- Up to 3 new themes
Tone: Direct. No throat-clearing.
```
3. **Manually ek dafa chalao** — watch karte hue, end-to-end
4. **Dobara manually chalao** — check karo. 2 dafa clean ho to schedule karne ke qabil
5. **Schedule karo** — `/schedule`, Weekly, Sunday 9pm
6. **Monday subah review karo** — feedback project instructions mein file karo

## OpenWork Mein

Koi built-in scheduler nahi — **Step 7 sab ke liye same hai** (manual re-fire).

1. Workspace banao, articles subfolder mein daalo
2. Settings panel mein project instructions set karo (same content jaisa Cowork)
3. Slack + Notion connect karo (Extensions tab)
4. `prompt.md` workspace folder mein save karo (har Monday re-fire karne wala exact prompt)
5-6. Manually 2 dafa chalao, check karo
7. **Recurring banana:** Sunday-night calendar reminder — workspace kholo, prompt paste karo, run karo
8. Monday subah review, feedback Settings panel se file karo

## Kya Notice Karein

Autonomy ladder deliberately chadti hai:
1. Manual run, watching — supervised
2. Manual run dobara — calibration check
3. Scheduled (Cowork) / regularly-triggered (OpenWork) — walk-away, downstream review
4. 6-8 successful runs ke baad — ambient ban jata hai

> **Reusable shape:** workspace + instructions + manual runs + trust ke baad recur + feedback loop —
> yehi template hai har recurring workflow ke liye: Friday cleanup, Monday brief, daily inbox triage,
> end-of-month variance commentary.
