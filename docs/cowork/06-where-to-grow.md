# 06 — Where to Grow

## Connector Combinations Asal Value Hain

Zyada tar tasks shuru mein ek connector use karte hain. **Bare wins tab ate hain jab aap unhe chain
karte ho.** Dhoondne ka tareeqa: notice karo wo multi-tool tasks jo aap manually karte rehte ho. Har
jumla jismein *"aur phir main doosri tab kholta hoon..."* ho, ek candidate hai.

## Monthly Audits

Har mahine: agent ke paas kya access hai review karo — folders, connectors, skills, plugins, scheduled
tasks. Pichle mahine ka experimental connector is mahine ka permanent surface area hai jo aap bhool
chuke ho. 10 minute; 6 mahine skip karo aur pata chalega assistant ke paas 4 cheezon tak access hai jo
aapko yaad hi nahi.

## Jab Team Wahi Tool Use Kare

**Cowork team scale pe:** Owners private plugin marketplaces publish kar sakte hain, naye members ke
liye approved plugins auto-install kar sakte hain. Team ke plugin set/skill library ko **maintained
shared resource** ki tarah treat karo — document templates ki tarah.

**OpenWork team scale pe:** Shared repo se team ki standardized state distribute karo — skills library,
plugin set, instructions. Naye members repo clone karte hain.

**Confidentiality discipline:** Jab 2 associates ek matter pe kaam karein, dono ki conversation histories
mein privileged documents ke extracts hote hain — law firm ke liye ye **discoverable record** hai.
Engagement close hone pe sessions delete karna zaroori hai.

**Autonomy ladder individual hai:** Senior lawyer ne "walk away" trust kama liya, isse junior associate
ko wahi trust assume nahi karna chahiye. Shared instructions team-level hain; autonomy ladder individual
rehta hai.

## Cross-Model Review High-Stakes Outputs Ke Liye

High-stakes deliverables (board memo, settlement letter, regulatory filing) ke liye **doosre model se
check karwao.** Cowork mein doosra model dusri tab mein chalta chat tool hai. OpenWork mein Settings
panel se alag provider configure kar sakte ho.

## Achha Banne Ka Tareeqa

Padhna kaafi nahi — **use karna** hai. Friction jo mehsoos hoti hai, wahi concept se map hoti hai:

- *"Report ka format baar baar galat kyun ata hai?"* → Global/folder instructions mein format spec
  missing hai
- *"Agent aisi files kyun touch kar raha jo maine nahi manga?"* → Plan mein scope creep, redirect karo
- *"20 files ke batch pe slow kyun hai?"* → Task ko subagent-parallelism obvious banao
- *"Har Mangalwar yehi workflow kyun describe kar raha hoon?"* → Project/persistent workspace banao
- *"Isne kuch aisa bhej diya jo nahi bhejna chahiye tha?"* → High-autonomy mode ek aisi task pe jo ready
  nahi thi

> **Portability dividend:** Cowork ka intercept pattern OpenWork jaisa hai; subagents same tareeqe se
> kaam karte hain; autonomy-ladder discipline identical hai. Ek tool mein delegation calibration bana
> lo, doosra sirf "buttons kahan hain" seekhna reh jata hai.

**Ek task se shuru karo. Working folder use karo. Plan parho. Cautiously approve karo. Monthly audit
karo. Baaki khud ban jayega.**
