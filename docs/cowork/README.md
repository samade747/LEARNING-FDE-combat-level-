## Ek Line Mein Poori Cheez

> Ye chatbot nahi, **co-worker** hai jisay aap **assign** karte ho, sawal nahi poochte. **3 trust levers:
> folders, connectors, approvals.** Plan hi leverage hai — output nahi. **Autonomy ladder** deliberately
> chado: watching closely → ambient supervision → walk away → high-autonomy → scheduled.

## 5 Sab Se Zaroori Baatein

1. **Delegate karo, query mat karo** — assignments mein socho, prompts mein nahi
2. **3 trust levers: folders, connectors, approvals** — dedicated working folder banao, narrowest scope
3. **Plan leverage hai, output nahi** — kaam shuru hone se pehle plan mango
4. **Autonomy ladder deliberately chado** — ek rung per task type, track record ke sath
5. **Untrusted content hamesha cautious mode maangta hai** — kabhi high-autonomy mode kisi aur ke likhe
   text pe
