## Yeh Chapter Kis Baare Mein Hai

Agar [Zia Tutor AI](../ecosystem-zia-tutor-ai/README.md) teaching lane hai, to Zia Developer AI
**construction lane** hai — abhi **in development**. Yeh aapke coding agent (Claude Code ya OpenCode)
ke andar chalne wala plugin hai. Aap plain language mein ek business problem describe karte ho; yeh
guess nahi karta — book se grounded ek **decision** wapas deta hai: Mode 1 ya Mode 2, aur kaunsa shape,
aur kyun. Phir yeh spec likhta hai aur ek working agent build karta hai. Aap verify karke ship karte ho.

[FDE AF Model](../ecosystem-fde-af-model/README.md) ki zabaan mein yeh **reference domain builder** hai
— Layer 2 ka woh slot jo har vertical apni architectures aur compliance rules ke saath preload karta
hai, taake jo agents yeh banaye woh us profession ki constraints by default follow karein.
