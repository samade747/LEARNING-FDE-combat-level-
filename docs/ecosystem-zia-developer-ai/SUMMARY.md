# Zia Developer AI — Summary

Zia Tutor AI teaching lane hai to Zia Developer AI **construction lane** hai — abhi **in development**. Sabse zaroori line: yeh book ka **10-80-10** rule khud building par apply karta hai — Zia Developer AI intent set karta hai (10%), coding agent build execute karta hai (80%), aapka judgment loop close karta hai (10%). Tutor method sikhata hai; developer usay chalata hai.

## Chapter Overview
- Coding agent (Claude Code/OpenCode) ke andar chalne wala plugin. Business problem plain language mein describe karo; yeh guess nahi karta — book se grounded ek **decision** wapas deta hai (Mode 1 ya Mode 2, kaunsa shape, kyun), spec likhta hai, working agent build karta hai. Aap verify karke ship karte ho.
- FDE AF Model ki zabaan mein: **reference domain builder** — Layer 2 ka slot jo har vertical apni architectures/compliance rules ke saath preload karta hai.

## 00 — Kaise Kaam Karta Hai: Decide, Build, Rhythm
- **Decides, then builds:** book ke decision gates chalata hai, choice ka reason cite karta hai, spec likhta hai, aur ek deployable scaffold banata hai (koi throwaway skeleton nahi).
- **Kabhi gate par guess nahi karta** — requirements settle na ho to ek sabse sharp sawal poochta hai aur rukta hai (spec-driven discipline, architecture choice par apply).
- **Usi agent mein jo already use karte ho** — Claude Code/OpenCode marketplace se ek command mein install, decision knowledge portable skill hai, economy-tier models tak bhi pohanchta hai.
- **Usi kunwein se grounded** — wahi SoR jo Zia Tutor AI parhta hai; fail closed — aisi architecture invent nahi karta jise cite na kar sake.
- **10-80-10 rhythm:** Zia Developer AI (10% intent+spec) → coding agent (80% build) → aapka judgment (10% close). Zia Tutor AI ka mirror: wahi source, doosra host.
- FDE AF Model fit: Layer 2 reference domain-builder slot. Aage har vertical apna domain builder isi pattern se banayega, apni domain constraints ke saath preloaded. `/vsor`, `/vtutor` commands sample repositories se shuru hote hain, blank folder se nahi.
