# 05 — Terms This Reference Adds + Where This Leads + Sources

## Terms (English — precision ke liye, glossary-style)

- **Model picker** — model ya reasoning-effort level choose karne ka control.
- **Thinking mode / extended thinking** — zyada reasoning effort dene wala mode, hard tasks par
  worth-it.
- **State summary** — lambi chat ke decisions/open-items/rules ka chhota record, fresh chat mein
  paste karne layak.
- **Project** — ek ongoing stream-of-work ka workspace (chats + knowledge + instructions).
- **Project knowledge** — project-level stored files, har conversation use kar sakti hai.
- **Standing instructions** — stable rules jo broadly apply hoti hain.
- **Memory** — context jo assistant conversations se rakhta hai, baad mein use kar sakta hai.
- **Incognito/temporary chat** — history+memory se bahar, lekin vendor ~30 din copy rakhta hai (
  memory-free, trace-free nahi).
- **Artifact** (Claude) — chat ke bagal banta separate output (doc/code/diagram/page/app).
- **Writing block, code block** (ChatGPT) — conversation ke andar editable region, canvas ki jagah.
- **Skill** — packaged method (instructions+examples+resources+kabhi code), matching task par load.
- **Agent Skills standard** — agentskills.io ka open spec, kai vendors read karte hain.
- **Plugin** — skills+connectors+commands ka bundle, ek kaam-category ke liye.
- **Custom GPT** (ChatGPT) — apni instructions/persona/knowledge/tools wala separate assistant.
- **Connector** (Claude) — permissioned connection outside system tak.
- **App** (ChatGPT) — same category, naam alag.
- **MCP** — outside tools/data connect karne ka open standard.
- **Research mode** — multi-step investigation + cited report.
- **Enterprise Search** (Claude) — organization-wide search, connected tools ko ek searchable base
  ki tarah treat karta hai.

## Where This Leads

Ab tum Claude aur ChatGPT ke main chat workspace mein raasta dhoond sakte ho. [Just Delegate It](../just-delegate-it-crash-course/README.md)
se aaye ho to wahan wapis jao jahan se bheje gaye the. Baaqi Foundations controls ke peeche ke ideas
explain karti hai:

- [Markdown In, HTML Out](../markdown-html-crash-course/README.md) — document layer jo abhi mile
  outputs ke peeche hai.
- [Code You Never Write](../code-you-never-write-crash-course/README.md) — jab tumne software
  describe ki aur working code aa gaya, wahan kya hua.
- [Skills & Connectors](../skills-connectors-crash-course/README.md) — Concepts 7+8 ko zyada deep.
- [How to Think in the AI Era](../how-to-think-ai-era/README.md) — Concept 9 ka judgment aage
  develop karta hai.

Baad mein Cowork & OpenWork aur General Agents courses chat window se desktop/agentic systems tak
le jate hain. Yahan ki proving loop [Trusting the Checker](../trusting-the-checker/README.md) mein
serious engineering discipline ban jati hai.
