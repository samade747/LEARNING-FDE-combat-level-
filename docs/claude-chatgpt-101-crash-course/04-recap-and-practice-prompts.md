# 04 — Recap + Try This Now (6 Prompts) + Quick Self-Check

## Chhoti Recap

- **Models aur thinking modes** control karte hain kitni capability spend hoti hai.
- **Attachments** abhi ka zaroori context dete hain.
- **Projects** ek stream-of-work ka context sath rakhte hain.
- **Standing instructions** stable rules hold karti hain.
- **Memory** evolving context hold karti hai.
- **Artifacts, writing blocks, code blocks** finished kaam chat-scroll se bahar rakhte hain.
- **Skills** repeatable methods package karti hain.
- **Plugins** poore kaam-category ke liye capabilities bundle karte hain.
- **Connectors (Claude) aur apps (ChatGPT)** external systems tak reach dete hain.
- **MCP** dono ke neeche shared integration standard hai.
- **Search, thinking, research** teen alag routes, teen alag sawalon ke liye.
- **Jo kaam tum jaante ho usi par test karna** — trust isi se earn hoti hai.

Products badalte rehenge. Yeh mental model current interface se bohat lamba chalega.

## Try This Now: Chhe Prompts (~25 minute)

**1. Guided tour maango.** Run karne se pehle predict karo 2 features jo mention honge:

> Give me a guided tour of this workspace as it exists today. Walk through:
> how I change models and when I should; what happens when I upload a file;
> what projects are for; what you remember about me and where I control
> that; where the research option lives. Keep it practical, one short
> paragraph per feature, tell me which features need a paid plan.

*Notice karo:* apni prediction se compare karo, phir screen par jo dikh raha hai usse. **Jahan yeh
apne interface ke baare mein ghalat ho, wahi sab se interesting hissa hai.**

**2. Ek task dono assistants mein chalao.** Apne hafte ka ek chhota real task pick karo. Predict karo
kaunsa behtar karega, kyun:

> Here is a real task from my work: [paste]. Complete it. Then, in three
> sentences, tell me what additional context would have helped you do it
> better.

*Notice karo:* outputs compare karo, phir yeh dekho har ek ne kya "missing" bola — doosri comparison
usually zyada sikhati hai.

**3. Apna pehla project set up karo.** Ek stream pick karo jahan background/files baar-baar repeat
hui hain:

> I want to set up a project for this stream of work: [describe]. Interview
> me briefly. Then give me two things I can paste into the project
> settings: (1) project instructions covering my role, audience, tone, and
> standing rules; (2) a priority-ordered list of five to ten documents I
> should upload as project knowledge.

*Notice karo:* jo sawal AI poochta hai wahi context hai jo tum har hafte haath se retype kar rahe
the.

**4. Memory audit karo:**

> Show me what you currently remember about me from our conversations, as
> a plain list. For each item I will tell you: keep, correct, or delete.
> Then tell me where in settings I can manage memory myself.

*Notice karo:* kya kuch shared screen par embarrass karega, kya kuch stale hai.

**5. Teen real sawal route karo.** Ek jo quick fact chahta hai, ek jo hard reasoning, ek jo proper
report deserve karta hai. Poochne se pehle route choose karo (search/thinking/research), phir bhejo.
*Notice karo:* mismatches — research jo search hona chahiye tha dono cockpits ki sab se common waste
hai.

**6. Assistant ko apni history par prove karo:**

> I want to test whether you can take over a recurring task of mine. The
> task: [describe precisely]. I am giving you a past example where I
> already know the correct result: [attach]. Reproduce the analysis the
> way I would have done it. I will compare your result with what I know
> to be correct, and we will iterate. I am holding back my original answer
> until we finish, so your work is not shaped by it.

Teen cheezein likho: kya match hua, kaunsi extra description chahiye thi, kya human reh jana chahiye.

## Quick Self-Check

1. Model tier pattern current names se pehle kyun seekhni chahiye?
2. Thinking mode kab use karni chahiye?
3. Instructions, memory, aur projects ka separation rule kya hai?
4. Ordinary chat aur artifact/writing block mein farq kya hai, aur jab output data ho ya act-pe-wali
   number ho to kya badalta hai?
5. "Projects store ___; skills perform ___" — complete karo.
6. MCP kya hai, aur jab tum ek se zyada assistant use karo to kyun matter karta hai?
7. Pehla AI test ek purana case kyun use karna chahiye jiska correct result pata ho?
8. Passing test kya deta hai, kabhi kya transfer nahi karta?

<details>
<summary>Answers</summary>

1. Model names/versions fast badalte hain. Pattern (fast, thinking, flagship) zyada tak chalta hai —
   task se choose karo, phir current names/levels seekho.
2. Multi-step reasoning, careful analysis, math, difficult code — jahan extra reasoning wait ke
   layak ho.
3. **Instructions for stable rules, memory for evolving context, projects for scoped work.**
4. Chat conversation hai. Artifacts/writing/code blocks ek alag work-product hold karte hain jo edit/
   use ho sakta hai. Data ho to table/spreadsheet maango. Act-pe-wali number ho to code se computed
   maango, check karo kaunsa column use hua.
5. **Projects store knowledge; skills perform tasks.**
6. MCP = Model Context Protocol, outside tools/data connect karne ka open standard. Integration
   concepts (aur kabhi tools khud) products ke across carry hoti hain.
7. Kyunke compare karne ke liye ek trusted answer chahiye — bina known truth ke pata nahi chalega AI
   ne kaam reproduce kiya ya sirf aisa lagta hai.
8. **Earned confidence for similar future work** deta hai. **Accountability transfer nahi karta** —
   tum phir bhi naye results verify karte ho, final result ke peeche khade hote ho.

</details>
