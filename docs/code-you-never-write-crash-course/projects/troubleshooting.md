# Stuck Mid-Project? Yeh 6 Symptoms

Apna symptom dhoondo, fix paste karo. Koi bhi tumse yeh maang nahi raha ke samjho galat kya hua —
wo AI ka kaam hai.

1. **"File open/read nahi kar sakta."** Usually file ka problem, AI ka nahi. _"Isme exactly kya
   ghalat hai, batao — format, kya parh sakte ho/nahi, kya re-export karoon."_ CSV ke sath Excel
   bhi mila to doosra try karo.

2. **"Answer mila, par code block kabhi nahi dikha."** Concept 4 ka silent estimate. Firmly bolo:
   _"Stop. Write and run code to answer this, show me the code, row count pehle do."_

3. **"Number match nahi karta jo maine counted/jaanta."** "Galat hai" mat bolo. Symptom report
   karo: _"Tumhara total X hai, maine Y count kiya. Row count, date range, pehli 5 rows dikhao jo
   code dekhta hai."_ Yeh projects mein, mismatch khud **catch** ho sakta hai, bug nahi.

4. **"Same fix baar baar fail ho raha."** 3 strikes = approach galat, typing nahi. _"3 baar try kar
   liya. Current code bhool jao. Problem fresh restate karo, 2 alag approaches propose karo."_

5. **"Mera file mein private data hai, upload karne se nervous hoon."** Achha instinct — act karo.
   _"Analysis se pehle, naam/account numbers hata kar cleaned copy banao, sirf usi par kaam karo,
   kya hataya confirm karo."_ Ya khud wo columns delete karo pehle. Sensitive data upload karne se
   pehle tool ki data policy check karo.

6. **"Free-tier usage khatam ho gaya beech mein."** Har project free tier mein fit hota, par heavy
   iteration daily cap hit kar sakti. Reset wait karo (saved brief resume karna free hai), ya alag
   model family mein brief paste karo.

Pattern sab 6 ke neeche: **stuck ho to, stuckness ko AI ko describe karo.** Wohi skill jo code
order karti, project bhi rescue karti.
