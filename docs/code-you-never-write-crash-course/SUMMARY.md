# Code You Never Write — Summary

Third Foundations course — AI ko real tedious work ka developer banana, bina code likhe/parhe.
Fetched: Zia Tutor AI, 2 windows (complete), 2026-10-23.

## 00 — Overview
- Bookkeeper kahani, "prove it in 2 minutes", dependencies (AI Prompting 2026, Markdown In HTML
  Out), needs+walk-away-with, 4 parts in brief.

## 01 — Part 1: The Deal (Concepts 1-3)
- Code coding se gated nahi (AI developer, insaan client). Code = exact instructions, Python vs
  JS/TS, language choose nahi karte. Dividing line: VPRF signals, answer vs code problem.

## 02 — Hands Move + Brief (Concepts 4-5)
- 3 lines (write+run code, show code, row-counts-first) — automatic estimate se bachne ke liye.
  5-section brief (Goal/Input/Output/Rules/Edge cases), Rules+Edge cases = beginners ki skipped
  pair.

## 03 — Verify, Errors, Keep (Concepts 6-8)
- 5-check verification ladder (known-answer/reality-questions/plain-English-replay/adversarial-
  pass/cross-model). Errors = dialogue, paste red text. Keep script+brief+sample in one folder.

## 04 — Five Surfaces (Concepts 9-11)
- Claude.ai/ChatGPT/Gemini (zero-risk sandbox). Claude Code/OpenCode (agent in folder, terminal).
  Cowork/OpenWork (plan-then-approve desktop apps).

## 05 — Blast Radius + Edge (Concepts 12-13)
- 4 rules (copies/dry-run/smallest-folder/new-files-output). Edge of one-prompt code: multi-user
  software, unattended automation, no-undo acts, judgment-in-computation-costume.

## 06 — Recap + Projects Overview
- 13-concept recap, "you are the client not the contractor" identity, off-the-shelf-app test
  filter, 4 projects pointer.

## 07 — Test Your Understanding
- Book's own 32-question scenario-based `<Quiz>` block (English, verbatim, answers+sources
  inlined).

Practice projects (4) scaffolded in `projects/`: Money Detective, What's My Grade Really, The
Books Don't Match, Photo Gallery Rescue — each with sample rehearsal data, known-answer test, and
a real catch — plus `troubleshooting.md` (6 stuck-symptom fixes).
