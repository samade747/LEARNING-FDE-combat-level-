# 00 — Overview: Code Jo Tum Kabhi Nahi Likhoge

## Bookkeeper Ki Kahani

Chhoti company ki bookkeeper — kabhi code nahi likha, kabhi nahi likhegi. Har mahine 2 files match
honi chahiye: company ne kya record kiya vs bank ne kya charge kiya. Har mahine ek shaam line-by-
line mismatches dhoondne mein jaati.

Pichle mahine usne naya try kiya: AI chat open kiya, plain English mein type kiya: _"Yeh do files
match honi chahiye... har transaction dhoondo jo ek mein hai doosri mein nahi."_ Ek minute baad 23
mismatches screen par, amount+date ke sath. Shaam ki hunting khatam.

**Usne programming kabhi nahi seekhi, code ki ek line kabhi nahi parhi.**

Yeh accounting ke sath specific nahi hai: teacher 200 grades, nurse logs ka mahina, student badly-
named files ka folder — same problem, same solution.

70 saal se code ka ek gate tha: khud likho. **Yeh gate ab khula hai.** Python — duniya ka sabse
useful programming language — ab har us insaan ke liye khula hai jo problem clearly describe kar
sake. 6-month course ke baad nahi — **aaj, abhi khuli chat tab mein.**

**Tum code likhna nahi seekh rahe. Tum code ke liye achha client banna seekh rahe ho.** Achhe
clients bricks nahi lagate — clear briefs likhte hain, jo measure kar sakte hain uske against kaam
check karte hain, aur jo order kiya wo keep karte hain.

Tumhe code ka syntax kabhi parhna nahi — yeh is course ki freedom hai. **Result check karna — yeh
responsibility hai jo wapas maangi jati hai.**

## Prove It in 2 Minutes

Expenses paste karo, bolo "write and run code to total them by category." AI glance se answer
nahi deta — chhota program likhta hai, apni numbers par chalata hai, totals report karta hai. **Yeh
numbers compute hui, estimate nahi.** Tumne language choose nahi ki, install nahi kiya, code copy
nahi kiya, run button nahi dabaya.

Phir: "Groceries lines khud hand se add karo: 4,250+2,890+3,120 — kya yeh match karta?" Yeh match
karta hai. Yeh chhota check **Concept 6 ka beej hai** — AI-written code trust karne walon aur sirf
ummeed karne walon mein farq.

## 4 Hisse, Short Mein

1. **The deal** — code ab likhne se gated nahi, 4 signals batate hain kab code chahiye
2. **Commissioning code** — compute force karna, problem brief karna, bina parhe check karna,
   errors handle karna, script keep karna
3. **5 surfaces** — same skills browser chat mein, terminal mein, plan-karne-wali desktop app mein
4. **Power, safely held** — 4 rules jo mistake ka cost shrink karte, aur one-prompt code ki limit

## Dependencies — 60-Second Version

- **AI Prompting in 2026** se: AI chhota program likh/run/use kar sakta hai, sirf tab reliably jab
  wording mangti ho. Sabse valuable habit: **loop** (context → options → react → ask again).
- **Markdown In, HTML Out** se: AI ko likhte waqt headings/bullets guesswork hatate hain
  ("Markdown"). Insaan ko parhne wala result chahiye to **HTML page** maango.

## Zaroorat Aur Kya Milega

**Chahiye:** ek free chat account (Claude.ai, ChatGPT, Gemini); apna ek real spreadsheet/folder;
kuch install karne ki zaroorat nahi (Part 1-2).

**End tak:** code problem spot kar sakoge; 5-section code brief likh sakoge; computation force kar
sakoge estimation ke upar; result check kar sakoge jo parh nahi sakte; real files par scripts safely
chala sakoge; built cheez keep kar sakoge (forever rerun hone wala script).
