# 06 — Recap + Projects Overview

## Short Recap — 13 Concepts, Ek Line Har Ek

1. AI code likhta **aur** chalata hai. "Can I describe this?" poochho, "Can I build this?" nahi.
2. Code dono directions mein exact hai. AI language choose karta — is kaam ke liye Python.
3. 4 signals code problem mark karte: Volume, Precision, Repetition, Files. Ek kaafi hai.
4. Words bolo: "Write and run code. Show me it ran. Row counts first."
5. Problem brief karo, program nahi. Goal, Input, Output, Rules, Edge cases.
6. Jo pehle se pata, uske against results test karo. Known-answer test everyday wala hai.
7. Errors dialogue hain. Red text paste karo. Galat number ko symptom ki tarah report karo.
8. Brief+script+known-answer sample ek folder mein rakho. Describe once, run forever.
9. Browser chat zero-risk sandbox mein code chalata — seekhne ka home surface.
10. Claude Code/OpenCode agent ko folder ke andar daalte — no uploads, scripts stay.
11. Cowork/OpenWork same power desktop app mein wrap karte jo act se pehle plan karta.
12. Copies pehle, dry run destruction se pehle, sabse chhota folder, naye files mein output.
13. Multi-user software, unattended automation, no-undo actions, judgment calls — baqi book chahiye.

**Underneath sab ke: ek identity, ek skill.** Identity: **tum client ho, contractor nahi.** Skill
(jo prompting course ko kabhi nahi chahiye thi): **jo kaam dekh nahi sakte, uspar trust kar sakte
ho — kyunke tumne usay kisi cheez ke against test kiya jo tum pehle se jaante the.**

## 🚀 Projects — Ek-Line Filter

Do-this-now boxes tumhare diye gaye data par rehearsals thi. 4 projects **real cheez** hain:
tumhara data, tumhare stakes, end mein ek **catch** (AI ke code ne jo true cheez dhoondi jo tumhe
pehle nahi pata thi, aur jispar tum kuch kar sakte ho).

> **Off-the-shelf-app test:** apna data point karne se pehle ek sawal pucho — _"Kya kisi company ne
> is exact problem ke liye pehle hi app bana rakha hai?"_ Haan ho (jaise Splitwise bill-split ke
> liye) to yeh galat problem hai yahan ke liye. App sirf tab exist karta jab rules har kisi ke liye
> same hon — tab tumhara apna kuch nahi hota brief karne ke liye.
>
> Right problems opposite hote: **market of one** — tumhare rules, tumhari mess, answer jo sirf tum
> confirm kar sakte ho.

4 projects (`projects/` folder mein full scaffold):

1. **Money Detective** (~45 min) — apna spending history hunt karo, leak dhoondo
2. **What's My Grade, Really** (~30-45 min) — teacher ke exact rules se real grade nikalo
3. **The Books Don't Match** (~45 min) — collection reconcile karo, person naam karo
4. **Photo Gallery Rescue** (~45 min) — duplicates safely delete karo, date se sort karo

Money Detective se shuru karo — baqi teeno ke moves yehi sikhati hai.
