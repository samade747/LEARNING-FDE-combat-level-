# 07 — Test Your Understanding

Book ka apna `<Quiz>` block (English, verbatim options summarized + answer/explanation) — 32
scenario-based questions. Yeh scenarios tumhe doosron ke spreadsheets, folders, broken runs mein
daalte hain. Reasoning se answer do, longest option se nahi.

**Source:** Code You Never Write, Test Your Understanding section. (Zia Tutor AI connector,
window 2, fetched 2026-10-23.)

---

1. **Office manager, 3 files combine karti Friday ko, sochti programming course chahiye.**
   **Answer: Job commission ho sakta hai, coded nahi** — wo repeating task describe karti, AI
   script likh+chalata. _Concept 1._

2. **2023 mein AI code try kiya, block haath mein mila, kahin paste nahi kar saka.** **Answer:**
   unlearn karo ke AI code deta hai dealing-ke-liye — aaj same reply mein likhta **aur** chalata
   hai, kuch install nahi. _Concept 1._

3. **Reader puchta AI language kyun choose karta, user nahi.** **Answer:** language choice
   technical judgment hai jo client delegate karta — jaise architect steel/timber choose karta.
   _Concept 2._

4. **Network engineer ka script galat rule se 40 config files flawlessly rename kar deta.**
   **Answer: Code dono directions mein exact hai** — correct aur wrong instructions ko same
   perfect obedience se execute karta. _Concept 2._

5. **User browser calculator chahta, team click kar sake.** **Answer: JavaScript** — output click-
   able hai, choice output follow karta, AI khud decide karta. _Concept 2._

6. **"Roughly sales trend kaisa tha" — confident answer, act kar liya.** **Answer:** answer-problem
   lagta par **Precision trip karta** — decision number par rehta, phrasing casual ho tab bhi.
   _Concept 3._

7. **4 tasks mein se code problem kaunsa?** **Answer: 80 contracts scan karo non-standard clause ke
   liye** — Volume+Files fire karte. _Concept 3._

8. **School administrator AI se fee spreadsheet dekhne bola, 8 names mili, real 11 thi.**
   **Answer:** AI ne **answer diya jahan compute karna chahiye tha** — skim ne partial payment ko
   paid padh liya. _Concept 3._

9. **5,000-row file, data question. Row-count/column-names/date-range line ka kaam kya?**
   **Answer: Cheapest lie detector** — real reading exact facts deta, invented guess expose
   karta. _Concept 4._

10. **Confident totals, koi code block nahi, koi row counts nahi.** **Answer: Data ke baare mein
    opinion, analysis nahi** — invoice jaisa kaam jo kisi ne dekha nahi. _Concept 4._

11. **"In Python" add karne se kya ghalat hota?** **Answer:** AI ka hath ek guess par force karta
    jo beginner justify nahi kar sakta — rare job jahan Python galat ho, wahan steer galat ho
    jata. _Concept 4._

12. **Half-know-programming log kyun worse briefs likhte?** **Answer:** "how" (loops/libraries/
    language) micromanage karte, "what" (outcome) under-specify karte. _Concept 5._

13. **5 sections mein beginners kaunse 2 skip karte, jo wrong answers prevent karte?**
    **Answer: Rules + Edge cases** — professional knowledge + imperfect-data decision carry karte.
    _Concept 5._

14. **User apne edge cases nahi jaanta.** **Answer:** discovery pehla prompt banao — AI files
    inspect kare, ambiguous kya hai bataye, phir Edge cases knowledge se likho. _Concept 5._

15. **Skeptic: "code parh nahi sakta, correct kaise jaanu?"** **Answer:** outputs ko independent
    knowledge ke against verify karo — jis expert ka craft follow nahi kar sakte, uska result check
    karo. _Concept 6._

16. **"Sabse powerful move" kaunsa?** **Answer: Known-answer test** — jo answer pehle se pata, uspar
    chalao, trust earned hota hai. _Concept 6._

17. **Pharmacist ne fake gap plant ki data mein, stock-check chalaya.** **Answer: Known-answer test
    ka elegant form** — fake gap catch hui, iss se 4 real gaps par trust bana. _Concept 6._

18. **Script bina error finish hoti, par sales total bohot low lagta.** **Answer:** symptom doctor
    ki tarah report karo — expected value + row-count/sample-rows maango fix se pehle. _Concept 7._

19. **Marketer ne "codec" error paste ki, ek word samjhe bina, 40 second mein fix hui.**
    **Answer:** errors parhna zaroori nahi, **paste karne ki willingness** zaroori hai. _Concept 7._

20. **Same fix 3 baar fail.** **Answer: Approach galat hai, typing nahi** — AI se problem fresh
    restate karwao, 2 alag approaches maango. _Concept 8 se pehle, Concept 7._

21. **Teacher ka submission-check brief pehli baar effort, next baar 1 sentence.** **Answer:
    Repetition** — ek baar likha script asset ban jata, "use karna" se "accumulate karna" shift.
    _Concept 8._

22. **Brief ko script ke sath kyun rakhna?** **Answer:** script = how (machines), brief = what+why
    (humans+future AI) — rule change par dono do, re-explain na karna pade. _Concept 8._

23. **Claude.ai sandbox zero-risk kyun, aur matching limit?** **Answer:** provider-side temporary
    computer, machine touch nahi hota; limit: sirf jo upload karo dekhta. _Concept 9._

24. **Network engineer, 40 devices daily, kaunsa surface?** **Answer: Claude Code/OpenCode** —
    sirf apne machine ka code schedule par chal sakta, doosre systems touch kar sakta. _Concept 10._

25. **Terminal reframe kya hai?** **Answer:** chat box jo folder ke andar baitha hai — agent
    already-there files dekhta, upload nahi. _Concept 10._

26. **Cowork/OpenWork ki defining feature?** **Answer: Plan-then-approve** — Concept 6 ka plain-
    English replay, work se pehle move kiya gaya. _Concept 11._

27. **Apne machine par code chalte waqt kaunse 2 facts bite karte?** **Answer:** agent-deleted files
    aksar recycle bin skip karti; script-edited files ka undo history nahi hota. _Concept 12._

28. **Dry run demand karna kya buy karta?** **Answer:** har operation ki list — misunderstanding
    pakadte ho jab tak wo words hai, actions nahi. _Concept 12._

29. **Researcher ke dry run mein 40 deletions, 6 galat grouped.** **Answer:** 2-minute plan-read
    ne 6 bachaye — dry-run ritual catastrophe ko shrug mein badalta hai. _Concept 12._

30. **4 tasks mein se kaunsa edge ke paar hai (one-prompt code se zyada chahiye)?** **Answer:**
    always-on service jo clients ko automatically weekly email kare, unattended, no human review.
    _Concept 13._

31. **"Judgment computation ka costume pehne" — "promote karne wale employees compute karo."**
    **Answer:** arithmetic trivial hai, **criteria poora problem hain** aur wo tumhare hain — code
    computes, tum decide. _Concept 13._

32. **Recap ka ek identity + ek naya skill (jo prompting course ko kabhi nahi chahiye thi).**
    **Answer:** tum **client ho, contractor nahi**; skill: **jo dekh nahi sakte, uspar trust kar
    sakte ho** — kyunke tumne usay jo pehle jaante the uske against test kiya. _Recap._
