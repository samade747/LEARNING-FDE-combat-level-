## Ek Line Mein Poori Cheez

> **Tum code likhna nahi seekh rahe — tum code ke liye achha client banna seekh rahe ho.**
> Describe the problem in plain words, AI likhe+chalaye+repair kare, tum check karo jo dekh nahi
> sakte. 4 signals (VPRF: Volume/Precision/Repetition/Files) batate kab code chahiye; 5-section
> brief (Goal/Input/Output/Rules/Edge cases) order karti; known-answer test trust kamata.
