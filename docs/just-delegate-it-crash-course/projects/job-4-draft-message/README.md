# Job 4 — A Letter or Message You Need to Send

**Time:** ~15 min · **Tool:** any free AI assistant

## Steps

1. Brief run karo:
   ```text
   Outcome: a first draft of [the letter or message], for me to edit.
   Context: [who it is to, what they know, what I want to happen].
   Constraints: under [length]. [Tone.] No promises about dates or money.
   Authority: draft, but do not send. Do not invent facts I did not give.
   Deliverable: the draft, then a list of anything you assumed.
   Verification: I will check every fact and every promise before sending.
   ```
2. **Notice:** "draft, but do not send" ek habit hai — jis din assistant **send** kar sakta hai, yeh
   ek permission ban jati hai, default nahi.

## Done Jah

- [ ] Draft + list of assumptions
- [ ] Har fact/promise manually check ki bhejne se pehle
