# Job 3 — A Document You Must Reply To

**Time:** ~15 min · **Tool:** any free AI assistant

## Steps

1. Names/private details hatao kisi real document se, phir:
   ```text
   Outcome: the three things this document asks me to do, and by when.
   Context: [who sent it and why it matters], with names removed.
   Constraints: use only the text I paste. Quote the sentence for each
   item. Write "not in the source" if it does not say.
   Authority: none. Do not draft a reply.
   Deliverable: a three-row table: what, by when, the quoted sentence.
   Verification: I will find each quoted sentence in the original.

   [paste the text, with names and private details removed]
   ```
2. **Notice:** "Authority: none" ek real line hai — AI ko sirf samajhne tak rok deti hai, reply
   tumhara kaam rehta hai.

## Done Jah

- [ ] Table mein 3 items, har ek quoted sentence ke sath
- [ ] Har quote original text mein mili (word-for-word check ki)
