# Job 2 — A Weekly Summary of Something You Follow

**Time:** ~15 min · **Tool:** any free AI assistant

## Steps

1. Brief run karo:
   ```text
   Outcome: a summary of what happened in [a topic you follow] this week.
   Context: I follow this for [why]. I already know [the background].
   Constraints: only sources dated in the last seven days. Say what you
   searched.
   Authority: choose the sources. Say when two sources disagree instead
   of picking one silently.
   Deliverable: eight bullet points at most, each with its source and date.
   Verification: mark anything that comes from a single source.
   ```
2. **Notice:** yeh job har hafte wapas aati hai — 2nd baar ke baad, Concept 8 apply hoti hai (save
   the brief, context ko Project mein rakho).

## Done Jah

- [ ] 8 ya kam bullets, har ek source+date ke sath
- [ ] Single-source items marked
