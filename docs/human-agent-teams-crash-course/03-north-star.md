# 03 — Part 4: North Star (Concepts 8-9)

## Concept 8 — Ek Goal Jo Agent Ko Proactive Banaye

Context aur roles agent se **assign kiya hua** kaam karwate hain. **North star** usay **sahi** kaam
propose karne deta hai. North star ek ambitious, wide-reaching goal hai jo batata hai kaunsa kaam
worth-doing hai — **wahi ek sentence jispar baaki sab measure hota hai.** Insan hamesha isay set karta
hai, business mission mein grounded.

Ek dafa likha jaye, team ke agents ke sath share karo. Phir (yehi hissa log skip karte hain) **naam lo
kaunse agents bina poochhe act kar sakte hain.** Har agent yeh nahi karna chahiye — sirf woh jinke paas
skills aur kamaya hua trust ho.

> **Anthropic ka example:** Ek team ka north star tha "onboarding ko zyada helpful banao." Ek agent ne
> khud onboarding error messages rewrite karne ka propose kiya — jo agle hafte onboarding success
> measurably barha gaya. Agent ne poochha nahi. North star ne bataya yeh rewrite on-mission hai.

## Concept 9 — Proactivity Ek Privilege Hai Jo Grant Karte Ho

Risk: agent aisa kaam propose kare jo usay nahi karna chahiye. To proactivity **naam se hoti hai, assume
nahi.** Aap batate ho kaunse agents workstreams suggest kar sakte hain, aur north star har proposal ka
test hai.

> **Claude Tag isay explicit, revocable grant ki tarah ship karta hai:** "ambient" mode jo per-channel
> enable karte ho, standing instructions jo memory mein persist hoti hain, ek dial jo koi bhi team
> member badal sakta hai. **Proactivity naam se hoti hai, per-workspace scoped hai, insano se tuned
> hoti hai.**

**Draft karo:**
```text
Help me write a north star. One ambitious goal, grounded in our
mission. State why it matters. Name which agents may propose new
work against it, and the guardrails.
```

**Check karo:** Named agent isay parh ke, kya on-mission idea ko off-mission se alag bata sakta hai?
Nahi to star bohat vague hai.
