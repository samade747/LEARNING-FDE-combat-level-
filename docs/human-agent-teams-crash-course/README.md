## Yeh Course Kis Baare Mein Hai

Yeh course ek unit (trustworthy Digital FTE) se **team** tak jaane ka operating model hai. Team kai ka
bara version nahi hai — **yeh bilkul alag cheez hai, aur alag skill maangti hai:** worker banana nahi,
balke **insaan ke sath un mein se kai ka team chalana.**

> **Note is course ke kism ke baare mein:** Baqi workforce courses build-along hain. **Yeh nahi hai.**
> Yahan aap code kam likhte ho. Aap **operating documents** likhte ho (roster, role cards, north star,
> verification rubric) jaise ek manager likhta hai — sivaye iske ke aapka agent draft karta hai aur aap
> decide karte ho. Yeh deliverables kam glamorous hain, code se zyada decisive hain: **zyada tar
> human-agent teams practices par fail hoti hain, technology par nahi.**

## Kya Banega (8 Files Ka Artifact Set)

App nahi — operating documents ka set jispar team chalti hai:

- **Team roster** — har member (human/agent), role, owner, tools, autonomy level
- **Role card** har agent ke liye — kya own karta hai, kya nahi, tools, kaise check hota hai, kab escalate
- **Working agreement** — default se kya public hai, security boundaries, kya private rehta hai
- **North-star doc** — team ka ek ambitious goal, aur kaun unprompted act kar sakta hai
- **Verification rubric** — work product kaise graded hota hai
- **Doer-verifier setup** — ek agent jiska kaam sirf doosre ko check karna hai
- **Weekly report** — "lessons and missteps" log
- **Attention budget** — aap kya review karte ho, kya batched hota hai, cap kya hai
