# Skills & Connectors — Projects

5 projects jo chapter ko ek rakhi-jane-wali cheez mein chain karte: ek private skill
(`SKILL.md` + uske around ka workflow). Har ek free account mein fit hota.

**Filter: market-of-one test** — skill tab place deserve karti jab wo _tumhara_ specific repeated
tareeqa capture kare, jo koi app tumhare liye nahi karta. Koi app tumhari class notes _tumhare_
format mein nahi likhta. Jo task app already sab ke liye karta, wo sirf achhi prompt hai.

Project 1 is week karo, ek task par jo tum repeat karte ho.

1. [1-build-first-skill](1-build-first-skill/README.md) — 🛠️ pehli real skill banao (30-45 min)
2. [2-connect-app-readonly](2-connect-app-readonly/README.md) — 🔗 ek app read-only connect karo (20-30 min)
3. [3-wire-together](3-wire-together/README.md) — ⚙️ Skill+Connector wire karo (45-60 min)
4. [4-make-portable](4-make-portable/README.md) — 🤝 portable banao, ya hand-off karo (30 min)
5. [5-audit-a-skill](5-audit-a-skill/README.md) — 🕵️ stranger ki skill audit karo (15-20 min)
