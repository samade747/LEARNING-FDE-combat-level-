# Stuck Mid-Project? Yeh 5 Symptoms

Har stall niche ki ek category mein aata. Kisi ko bhi samajhna zaroori nahi _kyun_ toota — AI ko
problem describe karna khud fix hai.

1. **"Skill kabhi fire nahi hoti, ya galat cheezon par fire hoti."** Dono description problems
   hain (06's timing list dekho). Pucho: _"When would you use my [name] skill, and when would you
   not?"_ Phir tumhare bole phrases add kar ke, ya "Do NOT use for..." line se tight karo.

2. **Connector "file nahi dhoond pa raha".** Usually permissions ya scope. Confirm connector
   **is specific chat** ke liye enabled hai, aur tumhara apna account file khol sakta hai.

3. **AI ne glance se answer diya, connected data use nahi kiya.** Naam lo: _"Use my [app]
   connector to fetch the actual file before answering, and tell me which file you used."_

4. **Write access ya sensitive data se nervous ho.** Read-only raho, jo zaroori nahi hata do.
   Write access sirf tool ko achha behave karte dekhne ke baad do.

5. **Chat lambi aur confused ho gayi.** Fresh chat start karo, task 2 lines mein restate karo —
   tangled chat rescue karne se abandon karna cheaper hai.
