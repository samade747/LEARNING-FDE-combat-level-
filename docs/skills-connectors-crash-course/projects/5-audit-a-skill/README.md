# Project 5 — Audit a Skill Before You Trust It

**Time:** ~15-20 min · **Tool:** Claude.ai

Internet se skill ek contract hai jo sign karne se pehle parhna chahiye. Official directory se
ek skill install karo jo tumne nahi likhi. Rely karne se pehle AI se read-back maango:

```text
Read the skill I just installed and tell me, in plain language, exactly
what it instructs you to do. Then flag anything in it that contacts an
external server, handles passwords or credentials, or could send my data
somewhere I didn't intend. If it's clean, say so plainly.
```

AI skill kholta, kya karti hai explain karta, seedha verdict deta — clean, ya "yahan line hai jo
internet reach karti."

## Done

- [ ] Ek sentence mein bata sakte ho skill (jo tumne nahi likhi) kya karti hai
- [ ] Pata hai kya yeh account se bahar kuch reach karti hai
