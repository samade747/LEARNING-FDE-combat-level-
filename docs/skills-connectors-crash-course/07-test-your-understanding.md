# 07 — Test Your Understanding

Book ka apna `<Quiz>` block (English, verbatim options summarized + answer/explanation) — 29
scenario-based questions. Reasoning se answer do, longest option se nahi.

**Source:** Skills & Connectors Assessment. (Zia Tutor AI connector, window 2, fetched
2026-10-23.)

---

1. **Teacher har hafte same brand-voice rules paste karti, AI bhool jata.** **Answer:** Chat ek
   baar batata, **Skill** har baar sikhati, **Connector** apps tak hath deta. _The one idea._

2. **Kitchen analogy — Connectors/Skills kaunse map hote?** **Answer: Connectors = kitchen
   (stove/knives/real ingredients), Skills = recipe cards.** _The one idea._

3. **Accountant har monthly chat mein formatting rules re-explain karti.** **Answer: Skill** —
   repeatable task, sirf input change hota. _Concept 1._

4. **Mystery strip karne par, Skill fundamentally kya hai?** **Answer: Folder with SKILL.md** —
   naam+description+plain-English instructions. _Concept 2._

5. **"Dynamically" load karna, progressive disclosure actually kya matlab?** **Answer:** AI sirf
   short description load rakhta, match hone par full instructions kholta. _Concept 2._

6. **Doctor darta hai Drive connect karne se poori hospital drive mil jayegi.** **Answer:** AI
   tumhari permissions inherit karta — account jo khol nahi sakta, connector bhi nahi. _Concept 3._

7. **Read-only vs write action ka farq kya hai?** **Answer:** "Search and summarize" read-only,
   low-risk; "Send this email"/"create this issue" write action. _Concept 3._

8. **Skill vs Project confuse karne wala beginner.** **Answer:** Project chat khulte hi load
   hota (always-on); Skill match hone tak dormant rehti, phir kahin fire hoti. _Concept 4._

9. **"Create a PowerPoint about Q3 results" — koi skill naam liye bina fire hoti.** **Answer:**
   Claude.ai mein skills automatically fire hoti — AI request ko har enabled skill ki description
   se match karta. _Concept 5._

10. **Auto-detection miss ho jaye, specific skill force karna — har jagah chalne wala method?**
    **Answer:** Skill ka naam plain English mein bolo ("use my brand-voice skill..."). _Concept 5._

11. **"Code execution and file creation" on hone par, bina naam liye "deck banao" bola.**
    **Answer:** Built-in PowerPoint skill khud activate hoti, real deck banati — built-ins
    automatically fire karte. _Concept 6._

12. **Tens of thousands community skills — "gift aur hazard".** **Answer: Hazard** — stranger ka
    free skill text file hai jise tum AI ko follow karne de rahe, harmful hidden instructions
    carry kar sakta. _Concept 6._

13. **Drive connect kiya, fresh chat mein AI use nahi kar raha.** **Answer:** Connector har specific
    conversation ke liye enable karna hota (+/Connectors menu se) chat use karne se pehle.
    _Concept 7._

14. **Skills+Connectors together ka division of labor?** **Answer: Connector real data fetch
    karta, Skill output tumhare tareeqe se shape karta** — ek sentence se finished result.
    _Concept 8._

15. **Friction test: Skill ya Connector ya dono?** **Answer:** How re-explain = Skill; app se
    data fetch = Connector; dono = dono. _Concept 9._

16. **Tool banane se pehle 2 honest cautions kya hain?** **Answer:** Har task skill deserve nahi
    karta (one-off = achhi prompt); zaroorat-se-zyada connector = khula darwaza. _Concept 9._

17. **Bina code likhe khud skill banana, fastest path?** **Answer: skill-creator skill** — describe
    karo, clarifying questions ka jawab do, SKILL.md likha jata. _Concept 10._

18. **SKILL.md ka kaunsa part hamesha loaded rehta?** **Answer: Frontmatter (naam+description)** —
    isi se AI relevance decide karta. _Concept 11._

19. **Folder naam "Client Monthly Summary" rakha, upload misbehave kiya.** **Answer: kebab-case
    chahiye** (`client-monthly-summary`), spaces/capitals/underscores nahi. _Concept 11._

20. **Kaunsa field decide karta skill kabhi fire hogi?** **Answer: Description** — AI sirf isi ko
    parhta relevance ke liye, instructions ko nahi. _Concept 12._

21. **Skill quick one-off questions par bhi fire ho rahi, jo ignore karni chahiye.** **Answer:
    Negative trigger** description mein add karo ("Do NOT use for one-off calculations..."). _Concept 12._

22. **Draft generate+parhne ke baad, output ke alawa kya test karna?** **Answer: Triggering** —
    jo phrases chalni chahiye wo try karo (loads confirm), unrelated requests try karo (takeover
    nahi honi chahiye). _Concept 13._

23. **Naya skill kisi phrasing se activate hi nahi hoti.** **Answer:** Description vague hai ya
    tumhare bole exact words missing hain — wo phrases add karo. _Concept 13._

24. **Firm chahti sab accountants same skill use karein, current rahe.** **Answer:** Shared skills
    view-only hain, original change hone par khud auto-update hoti. _Concept 14._

25. **Skill portable hai, honest caveat kya hai?** **Answer:** Basic SKILL.md travel karta, par
    har product apna install path/syntax/features add karta. _Concept 14 / Part 4._

26. **ChatGPT Custom GPTs aur Gemini Gems — Skill jaise hi hain?** **Answer:** Skill open standard
    se portable hai; GPT/Gem vendor-specific assistant hai jo kahin aur nahi chal sakta.
    _Part 4._

27. **Stranger ki skill ke 2 named dangers?** **Answer: Prompt injection** (unintended actions mein
    push) **+ data exfiltration** (info secretly bahar bhejna). _Part 5._

28. **Bina likhi skill enable karne se pehle vet karna, no-technical-skill move?** **Answer:** AI
    se pucho skill parh kar exactly kya instruct karti hai batao, external-server/credentials/
    data-leak flag karo. _Part 5._

29. **Caution capability ke sath kaise change karni chahiye?** **Answer:** Saath mein uthni chahiye
    — built-in se community skills+write access ki taraf jate waqt caution bhi badhao. _Part 5._
