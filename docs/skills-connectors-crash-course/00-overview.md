# 00 — Overview: Chat Box Ko Coworker Banana

Zyadatar log AI vending machine ki tarah use karte: request type karo, jo niklay le lo, chale
jao. Kal phir poori request type karo — same instructions, same context, same "nahi, hamare
invoices _aise_ dikhte hain." Machine kuch bhi yaad nahi rakhti.

2026 mein ek alag tareeqa hai, aur yeh ab sirf programmers ke liye nahi. **Tum AI ko ek task ek
baar seekha sakte ho, aur wo hamesha tumhare tareeqe se kare — yeh Skill hai.** Tum AI ko safe
access de sakte ho un apps tak jahan tumhara kaam rehta hai — files, email, tracker — **yeh
Connector hai.**

Koi programming background nahi chahiye. End tak pata hoga: Skills/Connectors kya hain, kab
kaunsa use karna, kaise existing wale use karna, khud banana, aur 5 tools mein safely kaam karna.

## Ek Idea Jo Sab Ke Neeche Hai

**Chat message batata hai AI ko kya karna hai _is baar_. Skill sikhata hai AI ko kaise karna hai
_har baar_. Connector AI ko _hath_ deta hai tumhari real apps tak pahunchne ke liye.**

**Kitchen analogy:** one-time chat message = counter ke paar chillaya order ("sandwich banao") —
ek baar banta, bhool jata. **Connectors = kitchen khud** (stove, knives, stocked pantry, fridge
real ingredients se bhari) — bina inke cook meal describe kar sakta, bana nahi sakta.
**Skills = recipe cards** — ek dish banane ke exact steps, _tumhare_ tareeqe se, same aaye chahe
tum cook karo ya naya hire.

2 jagah analogy exact nahi rehti: (1) tumhare ingredients AI ki kitchen mein move nahi hote — AI
tumhare live app mein pahunchta hai jab pucho, sirf jahan tumhara account pehle se pahunchta.
(2) Real cook dish taste kar ke fix karta; AI card follow karta — same skill ke 2 runs thoda alag
aa sakte. **Tasting tumhara job rehta hai.**

## 14 Ideas, Ek Line Mein

1. Chat box se operating layer tak — 2 kisam ka kaam jo hand se dobara karte ho
2. Skill actually kya hai — folder with text file, tumse koi code nahi
3. Connector actually kya hai — ek app tak safe access, tumhari permissions ke sath
4. Skills vs Connectors vs Projects vs Custom Instructions — 4 features, ek clean split
5. Slash command, ya automatic — Claude.ai mein skills khud shuru hoti
6. Built-in skills — Word, PowerPoint, Excel, PDF, ek switch ke peeche
7. Apps connect karna — ek minute per app, phir per-chat enable
8. Skills + Connectors together — dono ka kaam jab saath use ho
9. Kaunsa problem kaunsa chahta — friction se diagnose karo
10. Fastest path — tum describe karo, AI likhta hai
11. SKILL.md ki anatomy — file ka kaunsa part AI view mein rakhta
12. Description field — decide karta skill kabhi fire hogi ya nahi
13. Test, phir iterate — kya fire karta test karo, output test karo, hard cases test karo
14. Saving aur sharing — ek click se list mein, Team plans share kar sakte
