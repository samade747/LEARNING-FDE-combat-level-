# Skills & Connectors — Summary

Fourth Foundations course — AI ko ek task ek baar sikhana (Skill) + apps tak safe access dena
(Connector). Fetched: Zia Tutor AI, 2 windows (complete), 2026-10-23.

## 00 — Overview
- Kitchen analogy (Connectors=kitchen, Skills=recipe cards), 14-ideas-in-one-line, Foundations
  placement.

## 01 — Part 1: Two Upgrades (Concepts 1-5)
- Chat→operating layer. Skill = folder+SKILL.md, progressive disclosure. Connector = MCP, 3 facts
  (inherit permissions, read-only/write, per-conversation+scope). Skill vs Connector vs Project vs
  Custom Instructions. Automatic firing vs slash command.

## 02 — Part 2: Using What Exists (Concepts 6-9)
- Built-in Word/PPT/Excel/PDF skills (behind "Code execution" switch). Connecting apps (1 min,
  per-chat enable). Skills+Connectors together (2 worked examples). Friction-based diagnosis table.

## 03 — Part 3: Building Your Own (Concepts 10-14)
- skill-creator fastest path. SKILL.md anatomy (frontmatter always-loaded, kebab-case rules).
  Description field = whole game, negative triggers. Test-then-iterate + timing list. Save+share.

## 04 — Part 4: Five Places
- Agent Skills open standard (agentskills.io), Agentic AI Foundation. 5-surface table. ChatGPT
  Custom GPTs / Gemini Gems = NOT portable (vendor-locked); Skills ARE portable.

## 05 — Part 5: Safety
- 2 real risks (malicious skills: prompt injection + data exfiltration; over-broad connector
  write access). Safe-use checklist (7 items). Scope=Connector idea, not Skill idea.

## 06 — Recap + Try This Now
- 8-point recap, 6 try-this-now exercises.

## 07 — Test Your Understanding
- Book's own 29-question scenario-based `<Quiz>` block (English, verbatim, answers+sources
  inlined).

Practice projects (5) scaffolded in `projects/`: build first skill, connect app read-only, wire
together, make portable/hand-off, audit a skill — plus `troubleshooting.md` (5 stuck-symptom
fixes).
