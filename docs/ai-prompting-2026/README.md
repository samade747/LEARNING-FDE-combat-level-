## Yeh Course Kis Baare Mein Hai

Zyada tar log AI ko Google search ki tarah use karte hain: chhota sawal type karte hain, jawab
sarsari parhte hain, aage barh jate hain. Yeh trivia ke liye chalta hai. Yeh un cheezon ke liye fail
ho jata hai jo aapki zindagi aur kaam mein waqai matter karti hain.

Power users kuch alag karte hain. Wo AI ko brief karte hain jaise ek smart-lekin-naye colleague ko
brief karte — files, context, constraints, aur ek clear ask ke saath. Wo ek option ke bajaye teen
expect karte hain. Wo argue karte hain. Wo iterate karte hain. Wo kaam check karte hain. Novice prompt
aur power-user prompt ke darmiyan farq cleverness nahi hai — yeh chand habits hain jo koi bhi ek
dopeher mein seekh sakta hai.

Yeh course wohi dopeher hai. **13 Concepts**, chaar chhote parts mein group kiye gaye. Koi code nahi,
koi setup nahi.

> *Is page se pehle:* [What AI Actually Is](../what-ai-actually-is-crash-course/README.md) parh lo. Wo
> course batata hai machine **kya** hai; yeh course sikhata hai usse **kaise baat** ki jaye.

Ek fact poore page ke neeche hai, jo aap "What AI Actually Is" mein mil chuke: model **stateless** hai
— iski apni koi memory nahi turns ke darmiyan, aur har baar sirf jo iski context window mein hai usi
se jawab deta hai. Isi liye ek insight poore page mein chalta hai: **almost har "advanced technique"
yahan do moves mein se ek hai — sahi context andar lana, ya ghalat context bahar rakhna.**
