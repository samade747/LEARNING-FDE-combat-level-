## Ek Line Mein Poori Cheez

> **A System of Record decides what is true. A System of Context decides what arrives.** Kai domains,
> kai Vertical Systems of Record, **ek** System of Context unko connect karta hai bina authority
> flatten kiye. Records truth own karte hain, layer relevance assemble karti hai, Worker permission
> ke andar reason+act karta hai, evidence us record tak wapis jati hai jiska result hai.
