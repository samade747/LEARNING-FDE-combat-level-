# 01 — The One Law: Authority Kabhi Nahi Hilti, Aur Model Bhi Source Nahi Hai

## The One Law: Authority Never Moves

> **Delivery driver example:** Driver parcel tumhare darwaze pe laata hai. Parcel sender ka hota hai,
> driver ka nahi. **System of Context driver hai. Record sender hai.** Jab Worker batata hai answer kahan
> se aaya, record ka naam lena hai — driver ka nahi.

Poore page ka base ek sentence hai, wall pe likhne jaisa:

> **The System of Context carries authority. It never holds it.**

Jab Worker standard cite karta hai, citation seedha Vertical SoR ke register row ko point karti hai —
publisher, class, jurisdiction, version, stable ID. **Context layer ko point nahi karti, aur jo copy yeh
layer hold kar rahi hai usay bhi nahi.** Copy sirf **finding aid** hai. Record **source** hai.

Yeh sab se zyada matter karta hai jab kuch change hota hai. Standard supersede hota hai, aur tumhara
**impact record** har map/reflex/evaluation case ko trace karta hai jo move hona chahiye — yeh chain
record ke through chalti hai. Context layer ko dusri authority banne do, aur chain ek branch grow kar
legi jisay koi govern nahi karta — corpus current hai, lekin Worker purani rule quote kar deta hai us
index se jisay message hi nahi mila.

## The Model Is Not a Source Either

Upar wali law kehti hai authority sirf records mein rehti hai, connecting layer mein kabhi nahi. Yeh
model mein bhi nahi rehti. **Model information pe bohot acha reason kar sakta hai. Lekin wo jagah nahi
ban sakta jahan se information aati hai.**

Frontier model se poocho current lease classification threshold kya hai — fluently answer karega, shayad
sahi bhi ho. **Yehi khatarnak hai.** Gap accuracy ka nahi — accuracy ke **ird gird** sab kuch hai.

- **A model has no source.** Weights ek training corpus ka compression hain, record nahi. Koi register
  row nahi: publisher, authority class, jurisdiction, version, effective period, owner, rights basis,
  ya text tak wapas raasta — kuch nahi. Tumhare source register ke **9 columns** hain — model answer mein
  zero hain, aur baad mein add nahi ho sakte.
- **Plausibility is not provenance.** Model most likely continuation produce karta hai. Rule jo rule jaisi
  lagti hai aur rule jo asal mein rule hai — shape same hai, to fluency correctness ke baare mein kuch
  bhi nahi batati. Record mein "assumption likhi as confirmed fact" sales ka invented citation hota hai —
  model-supplied rule wahi error hai, behtar grammar ke sath.
- **A model release can be named and dated. The propositions inside it cannot.** Standard change hone pe
  tum page edit karte ho, impact record trace karta hai. Weights ke andar ek statement edit nahi ho sakta
  — koi source lineage, authority class, jurisdiction, effective period, ya alag version nahi. Model
  release ka naam lena fix nahi karta — release ek label hai millions propositions ke upar.
- **A model must not be the permission enforcement point.** Identity system ko supply ho sakti hai, lekin
  model ke context mein jo bhi daalo, uski reasoning ke liye available hai — **jo bhi puch raha ho**. Isi
  liye [permission model tak pohanchne se pehle filter hoti hai](04-permission-provenance-conflict.md), baad
  mein kabhi nahi.
- **Knowledge ka cutoff hota hai, profession ka nahi.** Rules regulator ke schedule pe badalte hain,
  laboratory ke nahi.

### Teen Jagah Jahan Model Chup-Chaap Source Ban Jata Hai

Koi bhi waqt decision jaisa nahi lagta — isi liye naam dena zaroori hai.

1. **The gap fill.** Retrieval kuch nahi laati, model phir bhi apne "pata" se jawab de deta hai — output
   shape mein grounded jaisa hi hota hai, koi error message nahi. **Cure:** missing evidence packet ka
   field hai, aur reflex jo apna governing source nahi dhoondh paata **escalate** karta hai, proceed nahi.
2. **The drifting paraphrase.** Model sahi passage retrieve karta hai lekin apne words mein restate karta
   hai — restatement chup-chaap ek threshold, condition, ya scope kho deta hai. Yehi drift corpus ke andar
   bhi hoti hai paraphrased authority ki surat mein — **cure:** governing text ko quote aur cite karo, re-
   express mat karo.
3. **Unmanaged persistent model memory.** Model jo sessions ke across facts carry karta hai, koi owner
   koi version nahi — yeh unversioned, unauditable store ban gaya. Teenon mein sab se mushkil notice karne
   wala, kyunke yeh product feature ke zariye aata hai, design decision ke nahi.

### Model Asal Mein Kis Liye Hai

Yeh model ko kam zaroori nahi banata — **alag** banata hai. Model execution layer hai — **10-80-10 rule**
ke middle eighty mein. Governing rule, current facts, supporting context do, model reflex apply karega,
calculation chalayega, missing evidence notice karega, conflict spot karega, working paper draft karega,
reasoning explain karega taake reviewer check kar sake. Yeh bohot bara professional kaam hai — kisi bhi
hisse ke liye model ko source banne ki zaroorat nahi.

Records pehle das percent (governed intent) rakhte hain. Model aathar percent carry karta hai. Named
human aakhri das percent close karta hai. **System of Context isi liye exist karta hai ke middle eighty
ko supply karna hota hai, aur model khud ko supply nahi kar sakta.**

> **Ek test har borderline case settle karta hai:** Can a reviewer rebuild this conclusion from the
> record, without asking the model? Haan — model ne reason kiya. Nahi — model source tha, aur conclusion
> defensible nahi hai.
