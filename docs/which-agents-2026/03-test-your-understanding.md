# 03 — Test Your Understanding

Yeh chapter apni koi live-site quiz widget nahi rakhta (reference chapter hai, numbered course nahi) —
neeche ek 12-question scenario-based self-check hai, isi page ke content se grounded. Jawab dene ke
baad `quiz.md` mein answer key dekho.

1. Tum ek developer ho jo roz code likhta hai aur apna phone bhi WhatsApp automation ke liye use karna
   chahta ho. Table ke hisaab se tumhara starting pair kya hai?
2. Ek executive AI adoption ka feel lena chahta hai, bina kisi team ko rollout kiye. Us ke liye sirf ek
   tool kaunsa hai, aur kyun "sirf ek" kaafi hai?
3. Security-conscious team IP-sensitive kaam kar rahi hai aur codebase khud audit karna chahti hai.
   Kaunsa tool fit hai, aur uski **container approach** kaise kaam karti hai?
4. OpenClaw "Free + API Costs" category mein hai jabke Claude Code "Free + Subscription" mein — farq
   kya hai in dono pricing models ka?
5. Ek domain expert (non-technical) ko Cowork install karne se pehle kya download karna padta hai, aur
   kyun?
6. Side-by-side comparison table mein Claude Cowork aur Codex dono "No" open-source column mein hain —
   lekin unka "backed by" alag hai. Kya farq hai?
7. "Fleet" ka matlab kya nahi hai (passage ke mutabiq), aur "coverage" ka matlab kya hai?
8. Migration timeline mein Month 3 par kaunsa tool add hota hai, aur kis kism ke kaam ke liye?
9. NanoClaw OpenClaw se "half-million lines of code" wali comparison mein kaise alag hai, aur yeh farq
   security ke liye kyun matter karta hai?
10. Trade-offs section ke mutabiq, Claude Code ka ek weakness kya hai one-shot tasks ke liye?
11. "Beyond the Core Fleet" section no-code builders ka zikar karta hai (Vellum, Copilot Studio,
    waghera) — yeh kis audience ke liye hain, aur SDK-based tools se kaise alag hain?
12. Ek team paanch se zyada tools accumulate kar chuki hai bina client-work ke. Passage ke mutabiq yeh
    kyun ek anti-pattern hai?
