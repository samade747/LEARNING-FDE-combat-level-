## Ek Line Mein Poori Cheez

> **4 layers: Prompt, Context, Harness, Loop.** Ye 4 skills nahi hain jinme se chuno, aur 4 steps nahi
> hain jo chado. Ye **4 containers hain, ek doosre ke andar**, har ek alag kaam ka zimmedar. Jab kuch
> toote, sawal ban jata hai: **"kaunsi layer toti?"**

## Sab Se Zaroori Sentence (Yaad Rakhne Layak)

> **"A good prompt fails inside bad context. Good context fails inside a bare harness. A good harness
> sits idle without a loop. So when something breaks, name the layer before you reach for a fix."**
