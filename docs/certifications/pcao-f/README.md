## Kyun Pehle

Associate Foundations wo baseline judgment establish karti hai jo har AI professional ko specialize
karne se pehle aani chahiye: effective prompting, output evaluation + validation, hallucination /
inconsistency detection, results validation, appropriate workflow selection, product capabilities +
limitations, governance + responsible use, aur "kab human review chahiye". PCAR-F ki architecture
usi judgment par bnti hai.

## Domain Weights (CCAO-F Blueprint Se Aligned)

Official CCAO-F Exam Guide v1.0 ka blueprint (is repo ne PDF khud padha 2026-08-24) — 7 domains:

| # | Content Domain | Weight |
| --- | --- | ---: |
| 2 | **Output Evaluation and Validation** | **21%** |
| 4 | Workflow Integration and Solution Design | 16% |
| 6 | Governance, Risk, and Responsible Use | 15% |
| 1 | Prompting and Task Execution | 14% |
| 3 | Product and Model Selection | 12% |
| 5 | Configuration and Knowledge Management | 12% |
| 7 | Troubleshooting and Optimization | 10% |

**Domain 2 + 4 + 6 = 52% of the exam.** Sab se bara domain prompt-likhna nahi — output evaluate
karna hai. Poori objective-level detail: [`../ccao-f/01-domain-blueprint.md`](../ccao-f/01-domain-blueprint.md).
