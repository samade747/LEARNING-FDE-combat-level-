## Ek Line Mein Poora Exam

> Yeh exam poochta hai: **kya tumhe "Agent Factory Model" ki poori zubaan aati hai** — roles kya hain,
> ecosystem kaise ek System of Record par khara hai, model kahan chalta hai (local/server/cloud),
> aur ek reliable agent ke 4 layers: **Loop** (kab chalta hai, kya yaad rakhta hai), **Harness** (ek
> beat ke andar kya allowed/pata/proven), **Evals** ("PASS" ko number se defend karna), aur
> **Runtime** (agent kahan rehta hai jab laptop band ho) — plus **General Agents** browser surface.
