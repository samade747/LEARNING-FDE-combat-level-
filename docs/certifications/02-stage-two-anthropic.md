# 02 — Stage Two: Anthropic Certification (CCAO-F → CCAR-F, + CCDV-F, CCAR-P)

## Stage One Complete Hone Ke Baad — Aur Yeh Optional Hai

⚠️ **Gen 61 (1 Sep 2026):** Stage Two **optional** hai. Book: *"They are optional; Panaversity assists
participants who choose to sit them."* Panaversity credentials + FDE Internship Program khud apni jagah
standalone value rakhte hain.

Ek dafa **FDE Internship Program** mil jaye — agar aap choose karo — official Anthropic exams shuru
karo. FDE path ke liye order: **CCAO-F pehle → CCAR-F baad**. Yeh order Anthropic ka apna rule nahi —
Panaversity ka recommended learning sequence hai, jo Stage One (Associate → Architect) ko mirror
karta hai: pehle broad Claude judgment, phir architecture validate karo. Panaversity internship
participants ki registration mein assist karta hai.

## Exam Mechanics — Sab Exams Shared Hain

- **Proctored aur identity-verified** Pearson VUE ke zariye, har exam **120 minutes**
- Online **OnVUE** ya test-centre appointment dono possible
- Score **100 se 1,000**, **720 cut score** — fixed standard, doosre candidates ko beat karna nahi
- Har credential **12 months** chalta hai. **On-time renewal free** hai (non-proctored refresher se)
  — lekin lapse hone par full proctored exam full price pe dobara dena parta hai
- Item format: multiple-choice + multiple-response; **har item batata hai kitne responses select karne
  hain**

### ⚠️ 720 = Scaled Score, 72% Nahi (Gen 61 Har Page Pe Repeat)

**720 ek scaled score hai (100–1000 range pe), 72-percent-correct nahi.** Exam criterion-referenced
hai — ek formal standard-setting study se cut score set hota hai. Score report **per-domain
percent-correct** deta hai lekin guide explicit hai: **woh section percentages pass/fail decide nahi
karte. Koi per-domain minimum nahi.** Result = total scaled score vs 720.

> Practical: ek strong total jo ek thin domain ko chhupa raha ho — wohi profile hai jo alag scenario
> draw pe fail kar sakta hai. Total nahi, apna per-domain breakdown parho.

**Agar exam content significantly change ho**, Anthropic renewal assessment ki jagah full retake
require kar sakta hai.

## Koi Prerequisites Nahi (Lekin Eligibility Alag Cheez Hai)

Koi bhi exam doosre ko require nahi karta — Developer pass kiye bina Architect exam de sakte ho.
Credential exam result pe hi diya jata hai.

**Yeh eligibility se alag hai.** Certification prerequisites koi nahi, lekin **eligible organisational
account** phir bhi chahiye registration ke liye (dekho [01](01-stage-one-panaversity.md)). Anthropic
ki programme CCAO-F ko CCAR-F se pehle require nahi karti — CCAO-F→CCAR-F order Panaversity ki
recommendation hai, uske apne 2-exam gate ke baad.

## Konsa Credential Aapka Hai — FDE Ke Liye

Chaaron credentials role-based hain, koi formal ladder nahi. Lekin is book ka specific target role
**Vertical FDE** hai — us ke liye recommended initial pair:

```
CCAO-F → CCAR-F
```

- **CCAO-F se shuru karo** — wo broad judgment validate karta hai jo FDE ko customers + teams ke sath
  chahiye: prompting, output evaluation + validation, workflow integration, product selection,
  **configuration + knowledge management** (gen 61 addition), governance, responsible use,
  troubleshooting, aur "kab human review chahiye"
- **Phir CCAR-F** — architectural judgment validate karta hai: agentic architecture, Claude Code
  configuration, prompt engineering, tool design + MCP, context management

Doosre credentials useful rehte hain:

- **CCDV-F** — un FDEs ke liye natural **additional** credential jo deeper proof chahte hain ke wo
  Claude applications, integrations, agents, workflows, tools, aur production systems build + ship kar
  sakte hain. Recommended experience (required nahi): **1–5 saal software engineering + 6mo+ hands-on
  Claude/comparable LLM, Python ya TypeScript, REST APIs + CLI fluency.**
- **CCAR-P** — senior architects ke liye professional capstone jo poore solution ka ownership rakhte
  hain end-to-end (stakeholder communication + lifecycle management sameet). Recommended experience:
  **3+ saal systems architecture / platform engineering + 6mo+ hands-on Claude in production.**

**Ek rule note karo:** agar aapki organisation ke liye partner-program standing matter karti hai,
**CCAO-F Claude Partner Network tier eligibility mein count nahi hota.** Baaqi teen technical
credentials (Developer Foundations, Architect Foundations, Architect Professional) count hote hain.
**Lekin** FDE learning progression ke liye CCAO-F ab pehla step hai — iska educational value kam nahi
hota, bas partner-tier math mein CCAR-F wala exam count hota hai, CCAO-F wala nahi. Pair (CCAO-F →
CCAR-F) dono kaam karta hai: learning progression + technical credentialing.

## Course Badges Certifications Nahi Hain

Do cheezein similar sound karti hain — inhe confuse mat karo:

| | Academy badge | Certification |
| --- | --- | --- |
| Cost | Free | $99 to $175 per attempt |
| Assessment | Course quizzes, or none | 53 to 63 scored items, proctored |
| Identity check | None | Government photo ID |
| Credential | Completion badge | Credly digital credential |
| Says | "I took the training" | "I passed an independent exam" |

- **Anthropic Academy courses** free aur self-paced hain, completion pe course badge milta hai — koi
  proctor, fee, ya identity check nahi
- **Claude Certification Program** upar ke 4 proctored exams hain — bilkul alag cheez

Dono useful ho sakte hain (free Academy courses achi preparation hain), lekin **"Claude Certified" CV
par mat likhna jab tak Pearson VUE exam pass nahi kiya.**
