# 01 — Domain Blueprint (Guide Section 6)

*Source: Official exam guide, Section 6 "Exam Content Outline (Blueprint)". Domain numbering **guide
ke apne 1-7 order mein hai** — weight ke hisaab se descending sort nahi, kyunki sample questions bhi
isi numbering ko refer karte hain (dekho [03](03-how-to-prepare-and-sample-questions.md)).*

## 7 Domains + Weights

| # | Content Domain | Weight |
| --- | --- | --- |
| 1 | Prompting and Task Execution | 14% |
| 2 | **Output Evaluation and Validation** | **21%** |
| 3 | Product and Model Selection | 12% |
| 4 | Workflow Integration and Solution Design | 16% |
| 5 | Configuration and Knowledge Management | 12% |
| 6 | Governance, Risk, and Responsible Use | 15% |
| 7 | Troubleshooting and Optimization | 10% |
| | **Total** | **100%** |

**Sab se bara domain prompt-likhna nahi hai — output evaluate karna, problems spot karna, result pass
karne se pehle validate karna hai.** Domain 2 (21%) + Domain 4 (16%) + Domain 6 (15%) milke exam ka
52% hain — inhi teeno pe sab se zyada waqt do.

## Detailed Objectives Per Domain

### Domain 1 — Prompting and Task Execution (14%)

- Business aur technical tasks ke liye effective prompts banana
- Task decomposition techniques apply karna complex requests structure karne ke liye
- Prompts iterate karna output quality improve karne ke liye
- Prompting strategy task-type ke hisaab se adapt karna (analysis, research, drafting, brainstorming)

### Domain 2 — Output Evaluation and Validation (21%)

- Claude-generated outputs ko accuracy aur completeness ke liye evaluate karna
- Responses mein hallucinations, inconsistencies, aur biases identify karna
- Fact-checking aur validation techniques apply karna
- Decide karna kab human review ya additional verification zaroori hai
- Outputs ko intended audience ke liye edit/adapt/refine/compare karna
- Information organize/curate karna aur appropriate output format select karna (artifacts, inline,
  structured data)

### Domain 3 — Product and Model Selection (12%)

- Appropriate Claude product features select karna (Projects, research mode, chat, artifacts)
- Claude model types differentiate karna (Haiku, Sonnet, Opus)
- Model selection ko task requirements ke sath align karna (cost, speed, quality)
- Context limitations aur memory considerations samajhna/manage karna (kab restart, summarize, ya
  persist karna hai)

### Domain 4 — Workflow Integration and Solution Design (16%)

- Claude apply karna requirements aur use-cases analyze karne ke liye
- Claude leverage karna research, planning, aur process optimization ke liye
- Claude use karna solution design, development, aur iteration support karne ke liye
- Claude ko existing workflows mein integrate karna (augment ya redesign karne ke liye)
- Claude ki value aur limitations stakeholders ko communicate karna

### Domain 5 — Configuration and Knowledge Management (12%)

- Claude Projects configure karna instructions + knowledge sources ke sath
- Uploaded knowledge aur connectors manage karna (jaise Google Drive, Gmail)
- Effective system-level instructions banana
- Claude configurations, knowledge sources, aur instructions ko inform/maintain/update karna

### Domain 6 — Governance, Risk, and Responsible Use (15%)

- Appropriate aur inappropriate use cases identify karna
- Data-sensitivity, regulatory, aur privacy considerations apply karna
- Organizational AI policies aur governance standards follow karna
- AI usage ke ethical implications samajhna

### Domain 7 — Troubleshooting and Optimization (10%)

- Underperforming prompts ya poor outputs ke issues identify/diagnose/resolve karna
- Feedback aur results ke hisaab se approach adjust karna
- Workflows ko efficiency aur effectiveness ke liye optimize karna
