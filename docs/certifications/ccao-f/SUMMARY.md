## 00 — Quick Facts + Audience

- $99 · 60 Q · 120 min · Pearson VUE proctored · scaled 720/1000 · 12-month validity
- Purpose: independent assessment ke real-world business workflows mein Claude effectively/
  responsibly use ho raha hai
- Audience: operations, marketing, PM, education, comms — internal staff + external consultants dono
- MQC: regular hands-on Claude experience, prompt structuring + task orchestration + Projects/
  Artifacts familiarity, process-reimagination level tak
- Koi mandatory prerequisite nahi — credential sirf exam performance pe
- Not intended for: software developers/API builders/ML specialists (unka scope Architect/Developer
  credentials hai)
- CCAO-F Claude Partner Network tier eligibility mein count nahi hota (sirf 3 technical certs count
  hote hain)

## 01 — Domain Blueprint

7 domains, guide ki apni numbering (1-7, weight-descending nahi): (1) Prompting and Task Execution
14%, (2) Output Evaluation and Validation 21% (sab se bara), (3) Product and Model Selection 12%,
(4) Workflow Integration and Solution Design 16%, (5) Configuration and Knowledge Management 12%,
(6) Governance/Risk/Responsible Use 15%, (7) Troubleshooting and Optimization 10%. Domains 2+4+6
milke 52% — inhi pe focus karo. Har domain ke full objectives file mein hain.

## 02 — Book Coverage + Scoring

"Foundations (Everyone)" mapping table — What Claude is/isn't, useful output, markdown/HTML formats,
browser/desktop agents already covered; Code You Never Write, Skills & Connectors, How to Think in
AI Era abhi khaali. Koi explicit in/out-of-scope appendix nahi (CCAR-F ke unlike) — scope sirf domain
objectives se define hota hai. Scoring: criterion-referenced, cut score 720 formal standard-setting
study se, domain-wise % sirf informational hai, pass/fail total scaled score se decide hota hai.

## 03 — How to Prepare + Sample Questions

Prep: blueprint self-assess, official docs (Projects/Artifacts/Memory/Skills/Code Execution), prompt/
task-decomposition practice, real Project banao + outputs evaluate karo, responsible-use judgment
practice. 3 full sample questions (pehli baar poori tarah transcribe hui): Sample 1 (Domain 2) —
regulation-summary citation verify karna hallucination-check ke liye; Sample 2 (Domain 3) — high-volume
short replies ke liye faster/cheaper model choose karna; Sample 3 (Domain 6) — regulated PII
anonymize karna upload se pehle. Teeno ka answer + rationale doc mein hai.

## 04 — Policies, Resources + Doc Control

Registration: Partner Academy se guide/T&C review, checkout, Pearson VUE account, schedule (24h+
free reschedule). Policies: govt photo ID exact-match, accommodations pre-approval zaroori, retake max
4/12mo (14/30/90-din waits), no-show/late = fee forfeit. Exam-day: webcam/clear workspace/no
communication/no content capture, NDA required (decline = session end, no refund). Renewal: 12-month,
on-time free non-proctored assessment, lapse = full retake. Doc control v1.0 (July 2026). Prep links:
official PDF, flashgenius.net sample test, free Academy courses (Claude 101, AI Capabilities/
Limitations). Repo push: abhi priority nahi (PCAR-F/CCAR-F focus), advising/selling-heavy roles ke
liye better fit.
