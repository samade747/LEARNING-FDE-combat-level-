# CCAO-F Practice — 8 Judgment Drills

**Type:** Worksheet-style (no code) — jaisa `harness-engineering`'s `tool-diet` ya
`ecosystem-designing-the-vertical-sor`'s `fill-the-templates`. CCAO-F ki skill (output evaluation,
governance judgment, troubleshooting) code se test nahi hoti — ek pytest suite yahan galat tool hota,
kyunke exam khud "sahi option chuno" nahi, "kya karna chahiye, aur kyun" test karta hai.

*Grounded in [`01-domain-blueprint.md`](../../01-domain-blueprint.md)'s 3 heaviest domains — Output
Evaluation (21%), Workflow Integration (16%), Governance (15%), milke exam ka 52% — aur
[`03-how-to-prepare-and-sample-questions.md`](../../03-how-to-prepare-and-sample-questions.md)'s
3 official sample questions (Drills 1, 3, aur 6 seedha unhi se shaped hain).*

## Setup

Koi setup nahi chahiye. Bas:

1. [`worksheet.md`](worksheet.md) ko copy karo (ya isi repo mein edit karo agar sirf practice kar
   rahe ho).
2. Har drill ko top se neeche solve karo — apna jawab **aur** ek line reasoning likho.
3. [`reference-answers.md`](reference-answers.md) se compare karo.

## Done Jab (Self-Check)

- [ ] Sab 8 drills solve kiye, har ek mein jawab + reasoning likha (sirf option letter nahi)
- [ ] Reference answers se compare kiya — jahan reasoning alag tha, socha *kyun* alag tha
- [ ] Kam se kam 2 drills identify kar sakte ho jahan "obvious" jawab galat tha (jaise Drill 3's
      "best model = highest-cost model" assumption)
- [ ] Apne words mein bata sakte ho: CCAO-F "prompt likhna" test nahi karta, "judgment" test karta
      hai — aur woh judgment kis 3 domains mein sabse zyada concentrate hai
