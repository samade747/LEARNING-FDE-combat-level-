## Ek Line Mein Poori Cheez

> CCAO-F yeh test nahi karta ke aap kitne acche prompts likh sakte ho — yeh test karta hai ke aap
> Claude ke output ko **kab trust karna hai, kab verify karna hai, aur kab kisi Architect/Developer ko
> escalate karna hai**. Sab se bara domain (21%) Output Evaluation and Validation hai — is credential
> ka core judgment hai.
