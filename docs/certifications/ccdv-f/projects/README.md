# CCDV-F Projects

Unlike [CCAR-F's 4 numbered exercises](../../ccar-f/projects/README.md), the CCDV-F exam guide (Section 7)
doesn't define separate exercises — it recommends **one integration application** covering the API,
a tool, prompt/context engineering, and basic security + eval, then gives 3 illustrative sample
questions (Section 8, Domains 2/7/8). This folder's one scaffold is built directly around that.
