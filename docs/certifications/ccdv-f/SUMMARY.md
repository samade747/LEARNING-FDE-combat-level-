# CCDV-F — Summary

Claude Certified Developer – Foundations: production-grade Claude applications ship karne ki
credential, foundational level pe. $125, 53 questions, 120 min, Pearson VUE proctored, scaled pass
720/1000, 12-month validity. Panaversity-aligned free version: [PCDV-F](../pcdv-f/README.md).

## 00 — Quick Facts & Audience

- MQC: AI/ML engineers, technical leads, senior SWE — 1-5 saal SWE + 6+ months hands-on Claude/
  comparable LLM systems. Python/TypeScript + REST/CLI fluency + LLM/agent/context/MCP working
  understanding.
- Not intended for: non-technical/casual users, prompt-writing-only roles.
- Koi mandatory prerequisite nahi — credential sirf exam performance pe based hai.

## 01 — Domain Blueprint

- 8 domains, weights bohat uneven: Applications and Integration 33.1% (Claude Application Design
  8.6, Software Eng Foundations 7.4, Claude API Mechanics 6.8, Config Mgmt 4.1, Understanding
  Requirements 3.4, Systems Life Cycle 2.8) plus Model Selection and Optimization 16.8% (Technical
  Fundamentals 6.1, LLM Fundamentals 5.2, Cost/Token Mgmt 2.8, Model Selection/Tradeoffs 2.7) — top 2
  domains around 50% of exam.
- Agents and Workflows 14.7% (Agent Construction 5.3, Patterns/Frameworks 4.9, Architecture 4.5).
  Prompt/Context Eng 11.0%. Tools/MCPs 10.6% (Tool Implementation 4.4, Agentic Customization 4.1, MCP
  Server Dev 2.1). Security/Safety 8.1%. Claude Code sirf 3.1%. Eval/Testing/Debugging sirf 2.6%.

## 02 — Scope, Scoring & Gaps

- Koi explicit in/out-of-scope appendix nahi (CCAR-F jaisa) — scope Section 6 ke domain descriptions
  se implicit hai. Criterion-referenced scoring, cut score 720, domain-percentages report hote hain
  lekin pass/fail decide nahi karte.
- Book gap: Model Selection and Optimization (16.8%) sab se thin coverage — Opus/Sonnet/Haiku live
  tradeoffs, token/cost management, prompt-caching mechanics.

## 03 — How to Prepare + Sample Questions

- Official prep: blueprint self-assess, official docs review, kam se kam ek Claude app banao (API +
  1+ tool + prompt/context eng + security/eval basics), developer competencies practice.
- 3 full sample questions (pehle sirf 1 thi, ab teeno full transcribe): Domain 2 (batch API vs
  synchronous for overnight bulk job — Message Batches API sahi), Domain 7 (prompt injection via
  hidden text in scraped page — untrusted-input isolation + guardrails sahi), Domain 8 (reusable
  internal-API tool across apps — MCP server sahi).

## 04 — Policies, Resources & Doc Control

- Registration: Anthropic Partner Academy → Pearson VUE account → schedule. 24h+ free reschedule. ID
  must exactly match registration name. Retakes: max 4 per 12-months, 14/30/90-day waits. NDA
  required before exam starts (decline = no refund). Appeals within 14 days (standard-setting + item
  content not appealable). On-time renewal free; lapse = full exam again.
- Doc control: v1.0, initial publication, July 2026.
- Repo push: current target is PCAR-F/PCDV-F (Panaversity stage) before CCDV-F.
