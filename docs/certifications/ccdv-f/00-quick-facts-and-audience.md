## Kya Test Hota Hai — Purpose aur Value

Yeh credential validate karta hai ke koi individual **production-grade applications, agents, aur
workflows** bana, integrate, aur ship kar sakta hai Claude platform pe — foundational level pe.
Technical professionals ke liye hai jo Claude ki capabilities aur production-ready applications ke
beech bridge banate hain — technical requirements ko working systems mein translate karte hain
in cheezon ke zariye:

- Claude Agent SDK, agentic frameworks, aur custom agent loops se agents/workflows banana
- API, client SDKs, aur third-party integrations se Claude ko application code mein integrate karna —
  streaming, error handling, multi-format input sameet
- Claude Code ko interfaces ke across operate karna, Claude Skills author karna, CLAUDE.md /
  settings.json / plugins configure karna
- Prompts likhna aur context-engineering techniques apply karna — model behavior control karna,
  context drift rokna
- Evals design + run karna, trace analysis se failure modes debug karna, structured output validate
  karna, production quality monitor karna
- Claude model tiers select karna aur tokens/caching/batch processing manage karna — cost aur
  latency optimize karna
- Secure-by-design principles apply karna, hooks se guardrails implement karna — prompt injection
  aur destructive actions ke against
- Custom tools, function schemas, aur MCP servers banana — built-in tools, custom tools, Skills, aur
  MCPs ke tradeoffs weigh karte hue

## Intended Audience

Technical professionals jo production-grade AI solutions build/integrate/ship karte hain LLMs
(khaas kar Claude) use karke. Primarily: **AI/ML engineers, technical leads, senior software
engineers** jo business requirements aur technical implementation ke intersection pe kaam karte
hain.

**Not intended for:** non-technical/casual Claude users, ya hands-on software-development experience
ke bina individuals. Roles jo sirf prompt-writing ya isolated tasks tak limited hain (broader
application-development responsibility ke bina) bhi exclude hain.

## Minimally Qualified Candidate (MQC) Profile

MQC ek hands-on technical individual hai jo Claude-powered applications/agents/workflows
build/integrate/ship karta hai — Claude ki capabilities aur production-ready applications ke beech
translate karta hai. MQC ke paas:

- Claude Agent SDK + agentic frameworks se agents/workflows banane ki ability
- API + client SDKs se Claude integrate karna
- Claude Code operate karna codebase modernization ke liye
- Effective prompts likhna + context engineering apply karna
- Evals design + run karna
- Custom tools + MCP servers banana
- Model-selection tradeoffs (cost, latency, capability) aur tool-type tradeoffs (built-in, custom,
  Skills, MCPs) samajhna aur sahi pattern apply karna

**Recommended experience** (mandatory nahi):

- 1–5 saal software engineering
- **6+ months hands-on Claude ya comparable LLM-based systems**
- Python aur/ya TypeScript proficiency
- REST APIs + CLI tools fluency
- LLM fundamentals, agents, context management, aur MCP ki working understanding

**Prerequisites: koi mandatory nahi** — koi course ya prerequisite required nahi hai exam dene ke
liye. Upar wala experience recommended hai, required nahi. **Credential sirf exam performance pe
award hota hai.**
