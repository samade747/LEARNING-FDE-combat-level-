# CCAR-P — Summary

Claude Certified Architect – Professional: charon Anthropic credentials mein sab se senior/demanding
capstone — full solution lifecycle ownership (design, integration, evaluation, governance, stakeholder
communication), $175, 63 questions, 120 min, scaled pass 720/1000, criterion-referenced.

## 00 — Quick Facts, Purpose, aur Intended Audience

- 63 items (MCQ + multi-response), 120 min, Pearson VUE proctored, $175, 12-month validity
- Purpose: production-grade AI solutions design/build/deliver — model/architecture/API pattern
  selection, prompt+context engineering, enterprise integration, evaluation/monitoring/observability,
  security/compliance/governance, cross-functional stakeholder communication
- Audience: mid-to-senior solution architects/AI-ML engineers/tech leads — financial services,
  healthcare, retail, tech, education, government industries
- MQC: 3+ saal systems architecture/platform engineering, 6+ months Claude production mein,
  end-to-end delivery experience (discovery se deployment tak). Koi mandatory prerequisite nahi.

## 01 — Domain Blueprint

- 7 domains: Integration 19% (biggest), Solution Design and Architecture 17%, Evaluation Testing and
  Optimization 16%, Governance Safety and Risk 14%, Stakeholder Comm and Lifecycle 14%, Models
  Prompting and Context 13%, Dev Productivity and Enablement 7%
- Har domain ke full official objectives capture kiye — RAG pipeline design, MCP vs API/CLI vs
  agent-to-agent, GDPR/HIPAA/FedRAMP, A/B testing, prompt caching, business-value pillars
- CCAR-F se farq: CCAR-F ka Domain 1 (27%) hi "Solution Design" (17%) ban jata hai; 2 naye domains
  bilkul CCAR-F mein nahi thay — Governance/Safety/Risk aur Stakeholder Comm/Lifecycle, combined 28%
  of exam

## 02 — Book Coverage, Scope Note, aur Scoring

- CCAR-F ka poora book-mapping apply hota hai plus naye rows: stakeholder comm, operating model,
  lifecycle, governance, RAG pipeline — compliance (GDPR/HIPAA/FedRAMP) permanent gap hai
- Correction: CCAR-F guide mein explicit in-scope/out-of-scope appendix tha; CCAR-P guide mein koi
  dedicated appendix nahi hai — scope sirf 7 domains ke objectives se implicit define hoti hai
- Scoring: criterion-referenced, cut score 720 formal standard-setting study se, domain percentages
  sirf info ke liye hain — pass/fail total scaled score se decide hota hai

## 03 — How to Prepare + Sample Questions

- Koi required course nahi; blueprint self-assess karo, official docs review karo, 1+ end-to-end
  Claude solution banao (RAG+eval+observability sameet), architectural decision-making practice karo
- 3 sample questions, full text ab capture ho chuki hain:
  1. Least-privilege (refund/delete tools) — sahi jawab: tools config se poori tarah remove karo
     (logging/confirmation detective controls hain, removal nahi)
  2. 8K-token repeated system prompt, latency aur cost dono concern — sahi jawab: static content
     pehle rakho aur prompt caching enable karo
  3. RAG confident-but-wrong document-refresh ke baad — sahi jawab: retrieval/indexing stale ya
     irrelevant chunks return kar raha hai, check yahin se shuru karo

## 04 — Registration, Policies, Resources, aur Document Control

- Registration: Anthropic Partner Academy se Pearson VUE account, phir schedule (online proctored ya
  test center); 24h+ pehle free reschedule
- Policies: govt photo ID exact-match, retake 14/30/90-din waits max 4/12-months, no-show forfeits
  fee, NDA required (decline = session end, no refund), webcam + clear-workspace + no-communication
  rules
- Renewal: 12 months, free non-proctored assessment on-time, lapse hone par full exam dobara
- Appeals: 14 din window, Pearson VUE ke zariye — standard-setting outcome aur item content
  appeal-proof hain
- Doc control: v1.0, July 2026, initial publication
