# 00 — Overview: Do Stages, Ek Pathway

## Kyun Zaroori Hai — "Kya Aap Carry Karte Ho" Wali Baat

Pichla page (`what-you-carry-in`) yeh argument deta hai: companies ke darmiyan aap jo **carry** karte
ho — skills, apni library, apna judgment — wo us se zyada zaroori hai jo aap peeche chhor jate ho.

**Ek proctored certification is list ki sab se portable cheez hai.** Ek anjaan insaan ise seconds mein
verify kar sakta hai — na aapka code parhna parta hai, na aapki baat pe yaqeen karna parta hai.

Yeh is book ke target role ke liye khaas zaroori hai: **Vertical FDE** aksar kaam shuru hone se pehle
hire hota hai, kabhi kabhi kisi aise insaan se jo kaam ko seedha evaluate nahi kar sakta. **Ek
independent credential us conversation ka starting point badal deta hai.**

## Poora Recommended Path (gen 61, 1 September 2026)

```
PCAO-F → PCAR-F → FDE Internship Program → (optional) CCAO-F → CCAR-F
```

- **Stage One** — Panaversity ka apna qualification path: **pehle Associate (PCAO-F), phir Architect
  (PCAR-F)**. Yeh gate hai.
- **Stage Two** — Anthropic ka official certification program: **pehle CCAO-F, phir CCAR-F** (= $224).
  ⚠️ **Gen 61 pe explicitly OPTIONAL** — book: *"Sitting the Anthropic exams is optional, and the
  choice is yours. The Panaversity credentials and the internship stand on their own."* Internship
  participants ki registration mein Panaversity **assist** karta hai.

**Order jaan-boojh kar hai — "Associate pehle, Architect doosra":**

1. **PCAO-F/CCAO-F pehle** kyunki judgment foundation hai — effective prompting, output evaluation +
   validation, hallucination detection, workflow integration, model/product selection, governance +
   responsible use, aur "kab human review chahiye" — yeh sab specialize karne se pehle aani chahiye.
2. **PCAR-F/CCAR-F doosra** kyunki architecture usi judgment par bnti hai — agentic architecture,
   Claude Code config, prompt engineering, tool design + MCP, context management.

> Ek line mein: **use AI well → evaluate it correctly → govern it responsibly → design the system.**

**Purana path (PCAR-F → PCDV-F → ... → CCAR-F → CCDV-F) ab stale hai.** PCDV-F/CCDV-F ab FDE gate ka
hissa nahi — "additional technical credential" ban gaye, recommended pair ke baad ke liye.

## Access Requirement — Anthropic Exams Ke Liye (Aur Internship Yahan Help Karti Hai)

Claude certification registration **Anthropic Partner Academy** (anthropic-partners.skilljar.com) se
hoti hai aur ek **eligible organisational account** chahiye — **personal email accept nahi hota**,
aur abhi individual sign-up ka koi rasta nahi hai (Anthropic ki registration guide explicit hai).

**Panaversity Claude Partner Network ka member hai.** Is pathway mein:

- **PCAO-F aur PCAR-F dono pass karo** (usi order mein) → **Panaversity FDE Internship Program** ke
  liye qualify ho jate ho
- **Panaversity qualifying internship participants ki official-exam registration mein assist karta
  hai** (Partner Academy ke zariye)
- **Anthropic exams optional hain — choice aapki hai. Panaversity credentials aur internship khud
  apni jagah standalone value rakhte hain.** Agar aap Anthropic pair baithna choose karte ho, wahi
  order: CCAO-F pehle, CCAR-F baad.
