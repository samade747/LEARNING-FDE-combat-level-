# 05 — Registration, Retakes, Renewal, Costs, 6 Mistakes

## Registration

- **Panaversity exams** — Panaversity ke zariye register karo. Qualification requirements aur access
  route [01 — Stage One](01-stage-one-panaversity.md) mein hain.
- **Anthropic exams** — FDE Internship Program & partner access setup hone ke baad, eligible
  organisational account se **Anthropic Partner Academy** ke zariye register karo. Phir **CCAR-F aur
  CCDV-F** ke sath continue karo.

Exam page kholo, [guide download karo](06-sample-tests.md#official-exam-guides), register + pay karo,
phir **Pearson VUE** se OnVUE ya test-centre appointment schedule karo. **Partner-tier discounts
checkout pe apply hote hain.**

## Reschedule Aur Retakes

- **Rescheduling** — appointment se **24 ghante pehle tak free**. Us window ke andar, fee forfeit ho
  jaati hai.
- **Retakes** — **rolling 12 months mein same exam ke max 4 attempts.**
- Waits: **pehli failure ke baad 14 din**, **doosri ke baad 30 din**, **teesri ke baad 90 din**. Har
  attempt full fee leta hai. **Ek exam fail hona doosre exam ke liye register karne se nahi rokta.**

## Exam Day

- **Government photo ID** lao jo registration name se exactly match kare
- Online proctoring ke liye: webcam supervision, clear workspace, **koi phone, notes, ya second
  monitor nahi**
- Shuru karne se pehle **non-disclosure agreement accept karna zaroori hai** — decline karne se
  session bina refund khatam ho jaata hai

**Accommodations** Pearson VUE ke zariye request karo, aur **schedule karne se pehle approval lo.**

**Results** — Credly digital credential + score report jo domain-by-domain performance dikhata hai.

## Six Mistakes Worth Avoiding

1. **Eligible hone se pehle booking karna** — official Anthropic exams book karne se pehle Stage One
   complete karo.
2. **Har domain ko equal study time dena** — ek 2.6% domain ko 33.1% domain jitna time mat do.
3. **Course badge ko certification samajhna** — completion badge proctored Claude certification
   credential nahi hai.
4. **Bina banaye dekhna** — exams applied judgment test karte hain (batch vs real-time, workflow vs
   agent, MCP server vs custom tool). Yeh judgment **banane se** develop hoti hai.
5. **Real attempt ko practice ki tarah use karna** — exam attempt ya Anthropic fee kharch karne se
   pehle free sample tests use karo.
6. **Credential ko lapse hone dena** — pass hone par renewal date calendar mein daal do.

## An Honest Word On Value

Yeh credentials abhi naye hain. **Koi mature salary data nahi**, aur employers abhi "CCDV-F" ke liye
filter nahi karte jaisa kisi established cloud certification ke liye karte hain.

Jo milta hai wo hai **early-mover signal.** Exams proctored, criterion-referenced, aur independently
verifiable hain — isi liye signal meaningful hai, chahe market ne abhi tak isay price karne mein saal
na lagaye hon.

Claude Partner Network organisation ke liye value zyada concrete hai — certified-practitioner counts
partner tier standing ka ek input hain (deployed customers + public references ke sath). Aapka
qualifying certification isliye aap aur organisation, dono ke liye matter kar sakta hai.

**Vertical FDE** ke liye, value **trust** tak wapas aati hai. Hiring manager ke paas aapke baare mein
limited evidence ho sakta hai — proctored credential wo evidence hai jo aapke apne claims se nahi aaya.

**Limit bhi utni hi zaroori hai: certification skill demonstrate karta hai, skill ki jagah nahi leta.**
Agar abhi API-backed application build aur deploy nahi kar sakte, wahin se shuru karo. Exam capability
ke **baad** aana chahiye.
