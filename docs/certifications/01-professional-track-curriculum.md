# 01 — Professional Track Ki Poori Curriculum

## Program Overview

**Certified Agentic AI Architect** ek 5-course professional certification program hai, computer science practitioners aur AI engineers ke liye. Yeh AI-driven development ke fundamentals se shuru hokar Agent Factories ko cloud scale par build aur deploy karne tak le jata hai.

Program ek progressive 5-level certification structure follow karta hai. Har level corresponding course ke exams pass karke kamaya jata hai. Sare 5 levels mil kar **Certified Agentic AI Architect** credential banate hain.

### Optional Anthropic Certification: CCA-F

**Claude Certified Architect — Foundations (CCA-F)** Anthropic ka apna official, proctored, architecture-level certification hai — ek scenario-based exam jo test karta hai ke practitioner production-grade Claude applications enterprise scale par design aur ship kar sakta hai ya nahi.

- Yeh **optional aur external** hai — Anthropic isay set aur grade karta hai.
- Panaversity ka **Level 5 (AI-491)** CCA-F ke domains cover karta hai, is liye students isi doraan CCA-F exam parallel mein de sakte hain.
- Poora program complete karne se Panaversity ka **Certified Agentic AI Architect** milta hai — CCA-F nahi. Dono alag credentials hain.

## Five Courses, Five Levels

| Level | Course | Key Domains | Kya Kamate Ho |
| --- | --- | --- | --- |
| **1 · Use** | **AI-101** — General Agent Problem Solving | Claude Code, OpenCode, OpenClaw, Prompting | Level 1 |
| **2 · Code** | **AI-201** — Python Programming in the AI Era and Agentic AI Fundamentals | Python, uv, Async, OpenAI Agents SDK | Level 2 |
| **3 · Build** | **AI-251** — Building Digital FTEs | Agent Skills, SKILL.md, Memory, Inngest | Level 3 |
| **4 · Compose** | **AI-321** — Composing AI-Native Companies | Paperclip, OpenClaw, Identic AI, DeepEval | Level 4 |
| **5 · Ship** | **AI-491** — Shipping AI-Native Companies | Architecture, FastAPI, Cloud, Agent Commerce, CCA-F | Level 5 → Certified Agentic AI Architect |

### AI-101 — General Agent Problem Solving (Level 1 · Use)

Students yahan se **Claude Code aur OpenCode fluently drive karna**, real problems ko agentic execution ke liye decompose karna, aur token economics ko ek design constraint ki tarah reason karna seekh kar nikalte hain (afterthought ki tarah nahi). Isi course ka scope is repo ke apne **General Agents** group (docs/general-agents-web, docs/agentic-coding, etc.) se milta hai.

### AI-201 — Python Programming in the AI Era and Agentic AI Fundamentals (Level 2 · Code)

Students yahan se modern Python fluently likhna seekhte hain — syntax, tooling, aur general agents ke **sath** (unke khilaf nahi) coding karne ka workflow. Yahan likhe gaye Python utilities aage AI-251 mein pehli Agent Skills ke bundled scripts bante hain. Is repo ka `docs/python-crash-course` isi domain mein aata hai.

### AI-251 — Building Digital FTEs (Level 3 · Build)

Students yahan ek poora Digital FTE end-to-end build karna seekhte hain: agent runtime, tool surface, memory, portable Agent Skills, aur ek working nervous system jo production mein isay zinda rakhta hai. Is repo ke `docs/digital-fte-crash-course`, `docs/ai-agent-nervous-system-crash-course` yahin fit hote hain.

### AI-321 — Composing AI-Native Companies (Level 4 · Compose)

Students yahan multiple Digital FTEs ko ek working AI Workforce mein compose karna, Paperclip se manage karna, OpenClaw se identic banana, aur eval-driven development se "yeh kaam karta hai" prove karna seekhte hain. Is repo ke `docs/workforce-with-paperclip-crash-course`, `docs/identic-ai-crash-course`, `docs/eval-driven-development-crash-course` isi level ke corresponding hain.

### AI-491 — Shipping AI-Native Companies (Level 5 · Ship)

Students yahan apne L3/L4 mein banaye workforce ke liye sahi architectural pattern choose karna, production cloud infrastructure par deploy karna, agent commerce protocol stack mein apni jagah articulate karna, aur poore system ko adversarial questioning ke saamne defend karna seekhte hain. Is repo ke `docs/deploying-agents-crash-course`, `docs/choosing-agentic-architectures-crash-course`, `docs/payment-enabled-agents-crash-course` yahan aate hain.

## Certification Ladder

Panch progressive certification levels, har ek corresponding course ke exams pass karke kamaya jata hai. Sare panch mil kar Certified Agentic AI Architect credential banate hain.

1. General Agent Problem Solving — AI-101 — **2 Exams**
2. Python Programming in the AI Era and Agentic AI Fundamentals — AI-201 — **2 Exams**
3. Building Digital FTEs — AI-251 — **3 Exams**
4. Composing AI-Native Companies — AI-321 — **4 Exams**
5. Shipping AI-Native Companies — AI-491 — **4 Exams**

**Total: 15 internal exams, 5 courses → Certified Agentic AI Architect.**
