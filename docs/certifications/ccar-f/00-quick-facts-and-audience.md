## About This Certification — Kya Test Hota Hai

Yeh certification validate karta hai ke practitioner **real-world Claude solutions implement karte waqt
tradeoffs ke baare mein informed decisions** le sakta hai. Exam foundational knowledge test karta hai
Claude Code, Claude Agent SDK, Claude API, aur Model Context Protocol (MCP) ke across — yeh chaar
core technologies hain jo production-grade Claude applications banane ke liye use hoti hain.

Exam **realistic scenarios** pe based hai jo actual customer use cases se liye gaye: customer-support
agents banana, multi-agent research pipelines design karna, Claude Code ko CI/CD workflows mein
integrate karna, developer productivity tools banana, aur unstructured documents se structured data
extract karna. **Candidates ko sirf conceptual knowledge nahi, balke practical judgment bhi dikhani
hoti hai** — architecture, configuration, aur production deployments ke tradeoffs ke baare mein.

Yeh guide candidates ke liye authoritative reference hai — exam schedule karne se pehle poora parhna
chahiye.

## Intended Audience / Minimally Qualified Candidate (MQC)

Ideal candidate ek **solution architect** hai jo Claude ke sath production applications design aur
implement karta hai — hands-on experience ke sath:

- Claude Agent SDK se agentic applications banana — multi-agent orchestration, subagent delegation,
  tool integration, aur lifecycle hooks sameet
- Claude Code ko team workflows ke liye configure/customize karna — CLAUDE.md files, Agent Skills,
  MCP server integrations, aur plan mode ke zariye
- Model Context Protocol (MCP) tool aur resource interfaces design karna backend system
  integration ke liye
- Prompts engineer karna jo reliable structured output produce karein — JSON schemas, few-shot
  examples, aur extraction patterns leverage karte hue
- Context windows effectively manage karna — long documents, multi-turn conversations, aur
  multi-agent handoffs ke across
- Claude ko CI/CD pipelines mein integrate karna — automated code review, test generation, aur pull
  request feedback ke liye
- Sound escalation aur reliability decisions lena — error handling, human-in-the-loop workflows, aur
  self-evaluation patterns sameet

**Typical experience:** 6+ months practical experience Claude APIs, Agent SDK, Claude Code, aur MCP
ke sath building — production environments mein LLMs ki capabilities aur limitations dono samajhte
hue.
