## Poori Cheez Ek Line Mein

> CCAR-F recall test nahi karta — **judgment** test karta hai: jab agent 12% cases mein verification skip
> kare, jab tool descriptions overlap karein, jab review ek pass mein contradictory feedback de, sahi fix
> almost kabhi "prompt ko strict-er likho" nahi hota — sahi fix **programmatic enforcement** (hooks,
> prerequisites, focused passes, scoped tools) hota hai. Architect ka kaam probabilistic compliance ko
> deterministic guarantees mein badalna hai jahan galti ki cost zyada ho.
