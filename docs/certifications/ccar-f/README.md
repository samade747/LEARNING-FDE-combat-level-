**Study priority (weight ke hisaab se):** Agentic Architecture (27%) → Claude Code Config + Prompt
Engineering (20% + 20%) → Tool Design/MCP (18%) → Context Management (15%).

**Agentic Architecture is book ka sab se deeply covered area hai** — 4 alag courses ke zariye. Yeh
domain sab se pehle padho.

## Konsa Credential Yeh Hai (FDE Ke Liye)

FDE path ka recommended pair: **CCAR-F → CCDV-F.** CCAR-F architectural judgment validate karta hai:
agentic architecture, Claude Code configuration, prompt engineering, tool design + MCP, context
management. Isay pehle lo — architecture wo mental model deti hai jo poori application surface
implement karne se pehle chahiye.
