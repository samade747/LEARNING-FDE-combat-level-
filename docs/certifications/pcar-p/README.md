## Abhi Kya Pata Hai

Panaversity ke poore certification framework mein **4 proctored exams** planned hain. Launch pe sirf
2 Foundations exams (PCAR-F, PCDV-F) available thay — PCAR-P **Professional** tier hai, baad mein
aayega. Jab launch hoga, CCAR-P ke blueprint se align hoga.

Jab tak PCAR-P available na ho, [CCAR-P ki exam-area table](../ccar-p/README.md) seedha padho — same
blueprint hai.
