## Yeh Course Kis Baare Mein Hai

Zyada tar log AI mein ek vague request type karte hain aur wapis text ki lambi wall milti hai. Request
vague thi, is liye AI ko guess karna para aapka matlab kya tha. Jawab itna lamba hai ke aap skim karte
ho. Dono directions mein kuch lost ho jata hai: AI ne aapko kabhi waqai samjha nahi, aur aapne uska
jawab kabhi waqai parha nahi.

Yeh course dono directions fix karta hai — har direction ke liye ek language ke saath. **Markdown**
plain text hai kuch extra marks ke saath jo structure dikhate hain: heading se pehle `#`, list ke har
item se pehle `-`. **HTML** wo language hai jisse web pages bante hain. Koi bhi programming nahi hai —
dono ordinary text hain. Skill yeh jaanna hai ke kaunsi language kis direction mein use karni hai.

Power users conversation ko direction se split karte hain: **AI ko Markdown mein likhte hain**
(headings, lists, code blocks — structure guess ki gunjaish nahi chorta), aur **AI se HTML mein jawab
mangte hain** (diagrams, tables, color, interactivity — kyunke ek designed page hi wo lamba jawab hai
jo koi busy insaan actually parhta hai). Pehli language seekhne mein ek ghanta lagta hai. Doosri aap
kabhi khud nahi likhte — sirf uski demand karna seekhte ho.

Poora course ek sawal ke gird ghumta hai jo har format decision decide karta hai: **yeh cheez aakhir
mein kaun parhega?** Agar koi insaan browser mein parhega, HTML mango. Agar AI parhega (ya aap ise
baad mein kisi AI ko wapis khilaoge), Markdown mein rakho. Social feed mein ja raha hai, plain text.

## Sabse Zaroori Baat (One-Liner)

> **"Write Markdown precise enough for a machine; demand HTML rich enough for a human."**
> Yeh poore course ka ek sentence hai. Markdown likho jo itna precise ho ke machine ke liye guess ki
> koi gunjaish na ho; HTML demand karo jo itna rich ho ke ek human usko actually parhe.
