# Project 2 — Spin the Wheel

**Time:** 30 min · **Tool:** Claude.ai, ChatGPT, or Gemini (free account) · **Direction:** two-way —
tool jo tum operate karte ho, uska result wapas AI ki agli instruction ban jata hai.

## Setup

Koi install nahi — Project 1 ki tarah free chat account kaafi hai.

## Steps

1. **Basic wheel banwao:**
   > Build a single-page HTML spinning wheel. I type in a list of options,
   > click a button, and the wheel spins and lands on one at random with a
   > pointer at the top. Make it look fun and colourful.
2. **Feel add karo, ek wish per message:**
   > Add a ticking sound as it spins, a confetti burst when it lands, a few
   > one-tap preset lists like "what's for dinner," and a button to remove
   > the winner and spin again.
3. **Spin karo, result wapas AI ko do** — yehi is project ka core move hai:
   > The wheel picked "[X]" out of: [your list]. Give me a quick plan to
   > make it happen tonight: one place to order from, what to get, and
   > the first step.
4. **Ship karo** (Project 1 wali Netlify steps repeat karo: download → rename `index.html` → drag
   Netlify mein).
