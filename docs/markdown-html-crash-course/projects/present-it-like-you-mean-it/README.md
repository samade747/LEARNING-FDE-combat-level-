# Project 3 — Present It Like You Mean It

**Time:** 30-45 min · **Tool:** Claude.ai, ChatGPT, or Gemini (free account) · **Direction:** leaves
the browser — Project 2 ka tool deck banta hai, phir real `.pptx` file.

## Setup

Project 2 ka shipped wheel link chahiye (ya koi doosra HTML tool jo tumne banaya ho).

## Steps

1. **Apna real link de kar deck banwao:**
   > I built this spinning wheel and I have to present it to my class at
   > school, using my own link [paste your wheel's link]. You load your
   > own options, spin, and it picks one for you. Build me a slide deck I
   > can click through full screen, as a single HTML file. Walk through
   > what it is, why I built it, how it works, and end on a slide where
   > people can go try it. Make it fun and clean.
2. **Full-screen test karo** — arrow keys se slides change, **F** se fullscreen.
3. **Agar live fetch miss ho jaye** (deck plain dikhe): screenshot drag karo, kaho "match this," phir
   ek wish per message refine karo.
4. **Office file maango:**
   > Now give me this exact deck as a PowerPoint file I can download and
   > present from a school laptop. Same slides, same order.
5. **Ship karo (no Netlify):** downloaded `.pptx` ko Google Slides mein kholo (File → Open → Upload),
   Share "anyone with the link" set karo, link copy karo.
6. **Ek din pehle check karo** — school laptop par ek baar khol lo, font-swap issues pakadne ke liye.

## Done Jab

- [ ] Deck full-screen click-through hota hai
- [ ] Real `.pptx` file downloaded hai
- [ ] Koi dost link se deck khol sakta hai
