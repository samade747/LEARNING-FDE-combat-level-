# 04 — Practice Projects (6 Hands-On)

6 projects, easy se hard. Real lekin low-stakes kaam use karo — notes, plans, drafts, **kabhi regulated
data nahi** (Concept 10 practice pe bhi lagu hai).

---

### 1. 📱 The Closed-Lid Test
**Difficulty:** Easy · **Time:** 15 min · **Concept:** 2

Ek chhoti multi-step session shuru karo (3 pasted documents ko ek brief mein summarize karo). Beech
mein tab band karo. Phone se session dobara kholo.

**Done jab:** Aap ne wahi session doosri device pe chalte dekhi ho, aur ek sentence mein bata sako runtime
asal mein kahan hai.

---

### 2. 🗂️ The Three-Tier Audit
**Difficulty:** Easy · **Time:** 30 min · **Concept:** 5, 8

Ek real task chalao jo deliverable banaye. Poori Concept 8 brief use karo, closing line samet jo har
file + tier list kare.

**Done jab:** Aap har file ka tier bata sako, aur deliverable khud **Tier 3** mein exist kare — sirf
platform pe nahi.

---

### 3. 🔔 Ring the Gate on Purpose
**Difficulty:** Easy-Medium · **Time:** 20 min · **Concept:** 7

Ek task design karo jo ek approval mangay, phir computer se poori tarah chale jao. Safe, low-stakes
trigger use karo — jaise ek harmless test file connected test folder mein save karwana. Sending,
deleting, purchasing, account changes use mat karo.

**Done jab:** Approval phone tak pohanchi, aap ne wahan se clear ki, aur wapas ane pe finished kaam
wait kar raha tha. **Ek alarm jo aap ne kabhi nahi suna, ek afwah hai.**

---

### 4. ⏰ The First Reporting Schedule
**Difficulty:** Medium · **Time:** 30 min, phir 1 hafta · **Concept:** 9

Ek Monday-morning brief banao ek connector + ek file source se. 4 jawab pehle likho (kya, touch, reach,
kab), empty-case line + success signal shamil karo, metered arithmetic likh kar karo.

**Done jab:** Ye 2 dafa fire ho chuki ho koi device online hue bagair, aur har result mein success
signal ho, sirf completed run nahi.

---

### 5. 🔁 One Task, Two Vendors
**Difficulty:** Medium · **Time:** 45 min · **Concept:** 3 (optional — dono products chahiyen)

Wahi assignment Cowork web aur ChatGPT Work dono mein chalao. Concept 3 ki comparison table khuli
rakho aur test karo — har row abhi bhi hold karti hai, ya koi rollout/rename se badal gayi?

**Done jab:** Aapke paas ek page ka note ho (Tier 3 mein saved): kaunsi rows confirm hui, kaunsi drift
hui, aur kya sab 6 shared parts dono mein dikhe.

---

### 6. 🧳 The Exit Drill (Capstone)
**Difficulty:** Capstone · **Time:** 45 min · **Concept:** 5, 11

Farz karo platform is quarter gayab ho jata hai. **Sirf Tier 3 se** (Drive, email, records), apni
working state reconstruct karo: templates, standing briefs, deliverables.

**Done jab:** Jo cheezein aap **reconstruct nahi kar sake**, unki list likhi ho. Ye list aapka Tier-2
exposure hai, aur agle hafte ki saving discipline. (Leaving the Laptop mein ye drill engineering teeth
ke sath dobara milegi.)
