# 5. One Task, Two Vendors

**Type:** No-code, browser practice. **Difficulty:** Medium · **Time:** 45 min · **Concept:**
[3 — 2 Vendors, Ek Shape](../../00-overview.md#concept-3-2-vendors-ek-shape) (optional — dono products
ka access chahiye)

Book ka **6-part table** claim karta hai Claude Cowork aur ChatGPT Work same shape express karte hain —
Heartbeat, Connectors, Run-until-done loop, State spine, Human gate, Body. Yeh drill claim ko khud test
karti hai, apne haath se.

## Setup

Koi installation nahi. Dono products ka access chahiye: claude.ai (Cowork) aur chatgpt.com (Work).

## Steps

1. Ek chhota, well-scoped assignment chuno jo dono products handle kar sakein (jaise: "3 news articles
   se ek 1-page comparison summary banao").
2. Poori Concept 8 brief shape (Brief → Plan → Approve → Review) **dono jagah same** use karo.
3. Assignment **Cowork** mein chalao, poora complete hone do.
4. Wahi assignment, **wahi brief**, **ChatGPT Work** mein chalao.
5. 6-part table khuli rakho, har row test karo:

   | Book Part | Cowork | Work |
   | --- | --- | --- |
   | Heartbeat | ? | ? |
   | Connectors | ? | ? |
   | Run-until-done loop | ? | ? |
   | State spine | ? | ? |
   | Human gate | ? | ? |
   | Body | ? | ? |

6. Har row pe note karo: table ka mapping **hold** karta hai, ya kisi rollout/rename ne badal diya?

## Done Jab (Self-Check)

- [ ] Ek page ka note ban chuka hai (**Tier 3 mein saved** — Drive/download, sirf platform pe nahi)
      jo batata hai: kaunsi rows confirm hui, kaunsi drift hui
- [ ] Bata sakta hoon kya sab **6 shared parts** dono products mein dikhe — aur agar nahi, kaunsa nahi
      dikha
- [ ] Bata sakta hoon asal farq kahan hai (model, plan structure, connector naam) — aur yeh bhi ke
      OpenAI ka coding agent (Codex) Work ke andar hai, jabke Claude Code poori tarah alag surface hai
