# 1. The Closed-Lid Test

**Type:** No-code, browser practice — jaisa `ccao-f`'s `00-judgment-drills` (koi script/hook nahi, khud
apne hi Claude Cowork ya ChatGPT Work account pe karte ho). **Difficulty:** Easy · **Time:** 15 min ·
**Concept:** [2 — Remote Session](../../00-overview.md#concept-2-remote-session--tab-ek-window-hai-runtime-nahi)

Is drill ka poora point ek sentence hai: **"Agar main type karna band kar doon, kya kaam ruk jayega?"**
Chat box ke liye jawab "haan" hai. Agent surface ke liye "nahi" — aur is drill mein aap yeh khud apni
aankhon se dekhoge, kisi doc pe trust karke nahi.

## Setup

Koi installation nahi. Chahiye:
- Claude Cowork (claude.ai) ya ChatGPT Work (chatgpt.com) ka access — dono ka free/starter tier bhi
  kaam karta hai is drill ke liye
- Apna phone, same account se logged in

## Steps

1. **3 chhoti documents taiyar karo** — asli hon ya invented, koi regulated data nahi (kabhi bhi asli
   client/patient/financial data practice ke liye mat use karo). Teen chhote paragraphs kaafi hain.
2. Cowork/Work mein **naya session shuru karo**, teenon documents paste karo, poocho: "In teeno ko ek
   single brief mein summarize karo — har source ka ek key point."
3. Jaise hi session "kaam kar raha hai" dikhe (running/thinking state), **browser tab band karo**
   (poori window ya browser bhi band kar sakte ho).
4. 1-2 minute wait karo. Phir apne **phone se** wahi account kholo (app ya mobile browser) aur wahi
   session dhoondo.
5. Dekho: kya session **wahin se continue** hai jahan tab band karte waqt thi, ya **naya sirre se**
   shuru hui?

## Done Jab (Self-Check)

- [ ] Maine wahi session doosri device (phone) pe **chalte hue** dekhi hai — copy nahi, wahi
      in-progress ya complete kaam
- [ ] Ek sentence mein bata sakta hoon: runtime asal mein kahan hai (vendor ke servers pe, browser tab
      sirf ek **window** hai, **machine nahi**)
- [ ] Farq bata sakta hoon: agar yeh ek **desktop** agent hota (Cowork ka local mode, ya koi terminal
      agent), tab/laptop band karne se kya hota — aur kyun yahan alag hai
