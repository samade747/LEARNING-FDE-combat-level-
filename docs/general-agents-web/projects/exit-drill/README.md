# 6. The Exit Drill (Capstone)

**Type:** No-code, browser practice. **Difficulty:** Capstone · **Time:** 45 min · **Concept:**
[5 — 3 File Tiers](../../01-the-surface.md#concept-5-3-file-tiers--is-course-ka-sab-se-zaroori-concept),
[11 — Open Path](../../03-choosing-open-path.md#concept-11-open-path--koi-vendor-cloud-nahi)

**Farz karo platform is quarter gayab ho jata hai.** Is drill ka poora point ek hard test hai: chapter
ka thesis — *"kuch bhi zaroori sirf platform pe nahi rehta"* — sach hai ya sirf ek acha sounding rule?

## Setup

Koi installation nahi. Apna existing Cowork/Work account + apna Tier 3 (Drive, email, local files,
records) jo pichle 2-4 hafton mein use kiya ho.

## Steps

1. **Sirf Tier 3 se** (platform ko chhuye bagair) apni working state reconstruct karne ki koshish karo:
   - Templates jo tum reuse karte ho
   - Standing briefs (jo poora Concept 8 shape mein likhe the)
   - Pichle deliverables
2. Har cheez ke liye jo dhoondni ho, pehle **sirf apne Drive/email/local files** mein dekho — platform
   login mat karo is exercise ke dauran.
3. Jo bhi **nahi mil raha** — ruko, likh lo, aage badho. Yeh drill ka asal output hai.

## Done Jab (Self-Check)

- [ ] Ek list ban chuki hai un cheezon ki jo **reconstruct nahi ho sakin** sirf Tier 3 se
- [ ] Har item ke saamne likha hai: yeh Tier 1 mein thi (already lost by definition) ya Tier 2 mein
      (safe thi, lekin sirf platform ki custody mein — isi liye ab gayi)
- [ ] Bata sakta hoon yeh list mera **Tier-2 exposure** hai — aur agle hafte ki saving discipline (kaunsi
      cheezein ab se Tier 3 mein bhi save karni hain)
- [ ] Bata sakta hoon [Concept 11 — Open Path](../../03-choosing-open-path.md#concept-11-open-path--koi-vendor-cloud-nahi)
      ka trade-off kya hota agar yeh drill "har cheez open-path pe hoti" — custody + choice milta,
      lekin free spine/sync/phone-gate khud banani parti

> **Agla milna:** Yeh drill [Leaving the Laptop](../../../leaving-the-laptop/README.md) mein engineering
> teeth ke sath dobara aayegi.
