# 3. Ring the Gate on Purpose

**Type:** No-code, browser + phone practice. **Difficulty:** Easy-Medium · **Time:** 20 min ·
**Concept:** [7 — The Gate In Your Pocket](../../01-the-surface.md#concept-7-the-gate-in-your-pocket)

**"Ek alarm jo aap ne kabhi nahi suna, ek afwah hai."** Human gate wahi rehta hai jo Foundations mein
tha — jo badalta hai wo hai kahan milta hai: web pe, approval **phone** pe aati hai, kyunke aap screen pe
hote hi nahi jab kaam chal raha ho. Yeh drill isay theory se practice mein le aati hai — ek dafa, on
purpose.

## Setup

Koi installation nahi. Chahiye: Claude Cowork ya ChatGPT Work + notifications-enabled phone (same
account).

## Safety Note

**Sirf safe, low-stakes trigger use karo.** Sending, deleting, purchasing, ya account changes **kabhi
nahi** is drill ke liye — jaise chapter khud warn karti hai.

## Steps

1. Ek task design karo jo **guaranteed ek approval mange** — jaise: "ek connected test-folder connector
   use karo aur ek harmless test file (`test-note.txt`, ek line text) usmein save karo, mujhse confirm
   lene ke baad."
2. Task chalao, phir **poori tarah computer se chale jao** — doosre kamre mein jao, phone hi saath rakho.
3. Wait karo notification ke liye. **Confirm karo:** notification phone pe aayi, approval waheen se di.
4. Wapas computer pe aao, dekho **finished kaam wait kar raha tha** — waiting nahi rah gaya approval ke
   liye jo tumne miss kar di ho.

## Done Jab (Self-Check)

- [ ] Approval **phone tak pohanchi** — maine wahan se clear ki, screen ke bagair
- [ ] Wapas ane pe **finished kaam wait kar raha tha** — koi stuck/timed-out task nahi mila
- [ ] Ek sentence mein bata sakta hoon: gate move nahi hui, **doorbell ko move hona pada** — kyunke ab
      kaam wahan chalta hai jahan meri nazar nahi hoti
