## Yeh Course Kis Baare Mein Hai

**15 Concepts · Onyx, MCP, aur 4 Source Classes.** Pichle course mein aap ne **ek** Worker ko apna store
diya. Yeh course **poore workforce** ka corpus banata hai.

Ab ek customer ki building mein chalo. Unke 20 saal ke working papers SharePoint mein hain. Engagement
letters email mein hain. Faisla kyun hua yeh ek chat thread mein aur travel kar rahe manager ke zehan
mein hai. Current balances har ghante badalne wale system mein hain. **Yeh sab aapka store nahi hai. Yeh
sab kaam khatam karne ke liye zaroori hai.**

**Northstar Services 20% discount chahta hai, abhi invoice chahta hai, aur is quarter implementation
revenue recognize karwana chahta hai. Kya woh kar sakte hain?** Yeh ek sentence hai lekin ek sawal nahi
— yeh sales sawal hai, accounting sawal hai, live-state sawal hai, aur ek email mein hearsay ka piece
hai — aur sahi jawab dene ke liye char cheezein alag rehni chahiyen.

**Poore course ka click:** har cheez jo layer return kare, 3 sawalon ka jawab de:

> **Yeh kahan se aya? Kya yeh banda dekh sakta hai? Kya yeh abhi bhi lagu hota hai?**

## 8 Rules — Poore Course Ka Nichor

1. **Authority kabhi move nahi hoti.** Layer citation carry karta hai record tak, khud source nahi banta
2. **Relevance authority nahi hai.** Routing pehle decide hoti hai, kisi passage par rely karne se pehle
3. **Permission inherit hoti hai, invent nahi.** Model se pehle enforce hoti hai
4. **Freshness field-by-field decide hoti hai.** Working context index karo, governed knowledge discover
   karo, current truth live query karo
5. **Provenance har item ke saath travel karti hai**, compression usay kabhi strip nahi karta
6. **Conflict preserve aur escalate hota hai**, blend nahi hota
7. **Working context chupke se governing authority nahi banta.** Promotion authorship hai, reviewed
8. **Discovery confirmation nahi hai.** Search hit ek pointer hai, governing record confirm karta hai

+ Proving It + Serving/Operating) ka overview hai.*
