## Yeh Course Kis Baare Mein Hai

**16 Concepts, 80% of Real Use.** Yeh hands-on course hai — aap 3 cheezein banate ho: (1) custom agent
jo laptop par chalta hai aur yaad rakhta hai, (2) wahi agent, shell/file operations Cloudflare sandbox
ke andar chalti hui, files jo runs ke beech survive karti hain, (3) cost control — cheap, high-volume
turns ko chote model par bhejo, frontier model sirf jahan zaroori ho.

## Poore Course Ka Rule

> **Har agent bug ya state bug hai, ya trust bug.**

- **State** — agent kya yaad rakhta hai, aur woh memory kahan rehti hai. *"Agent bhool gaya maine kya
  bataya"* state bug hai.
- **Trust** — agent kya karne ki ijazat rakhta hai, aur limits kisne set kiye. *"Agent ne aisa kuch kiya
  jo expect nahi tha"* trust bug hai.

Loop, tools, sessions, streaming, guardrails, handoffs, tracing, human approval, sandboxes — har piece
SDK ka in do sawalon ka jawab hai.
