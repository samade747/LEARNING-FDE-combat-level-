# 05 — How It's Delivered: One Source, Four Channels

Ek source, chaar channels ko power deta hai. Jab source ko naya escalation protocol, refined
pattern, ya sharper definition milta hai, to har channel usay inherit karta hai. Models, harnesses,
languages badal sakte hain. **Source constant rehta hai.**

## Chaar Channels

**Channel 01 — 📘 The Book:** Har doosre channel ki authoritative knowledge base. Yeh
[Agent Factory System of Record](../ecosystem/system-of-record) ke tor par ship hoti hai aur MCP
par serve hoti hai, taake koi bhi AI agent ya worker isse ground ho sake.

**Channel 02 — 🎓 Zia Tutor AI:** Ek named AI teacher jo book mein grounded hai. Apne free Claude
mein ek connector add karo aur ek baar authorize karo. Kuch install nahi karna, aur har learner ko
serve karne ki koi additional cost nahi.

**Channel 03 — 🛠️ Zia Developer AI:** Ek AI building partner jo book mein grounded hai aur Claude
Code ya OpenCode mein plugin ke tor par install hoti hai. Yeh sahi architecture select karti hai aur
usi par build karti hai.

**Channel 04 — 📚 Derivative Books:** Book ke specialized editions — alag topics, ages, professions,
aur domains ke liye.

## Teen Delivery Modes

**Mode 1 · Read 📖 — Human Reading.** Traditional path. Chapters parho, frameworks study karo,
exercises complete karo, deployable artifacts banao.

**Mode 2 · Tutor 🎓 — Zia Tutor AI.** Aapka personal AI teacher: ek real teacher ka named digital
twin, faceless system nahi. Zia Tutor AI naam se greet karta hai, yaad rakhta hai aap kahan chhode
the, Zia ke method aur voice mein sikhata hai, understanding check karta hai, aur progress record
karta hai.

**Mode 3 · Build 🛠️ — Zia Developer AI.** Aapka AI building partner, Claude Code ya OpenCode mein
plugin ke tor par installed. Aap apni business requirements aur domain describe karte ho. Zia
Developer AI Mode 1 (Problem-Solving) aur Mode 2 (Manufacturing) mein se choose karta hai, phir
chosen architecture par build karta hai.

Chunke teeno modes ek hi knowledge base se draw karte hain, book mein koi correction tutor ki
teaching aur developer ki guidance dono tak ek sath pohanchta hai. Yeh **education ka 10-80-10**
pattern hai: book pehle 10% mein intent set karti hai (domain knowledge, frameworks, professional
standards); Zia Tutor AI aur Zia Developer AI beech ke 80% ko handle karte hain (personalized
teaching aur step-by-step building guidance); aap aakhri 10% dete ho — woh professional judgment jo
confirm karta hai ke agent sahi hai, deployment safe hai, aur knowledge sound hai.

## Do Tools, Ek Discipline

Claude Code aur OpenCode is book mein competitors nahi — yeh ek hi discipline ke do izhaar hain. Do
tools kyun, ek nahi? Kyunke yeh discipline kisi bhi specific tool se zyada zinda rehni chahiye. Iski
core practices — spec-driven design, skill-based architecture, human oversight — portable hain
apni design se. Method ko ek vendor se baandh dena is premise se contradict karega.

**Claude Code — Frontier-first.** Anthropic ka frontier coding agent. Sabse capable models,
polished developer experience. **Behtareen for:** complex multi-file refactors, production-critical
work.

**OpenCode — Open & model-agnostic.** Open-source alternative. Dazzon model providers se connect
hota hai (Claude, GPT, Gemini, DeepSeek, Qwen, aur Ollama ke through local models). **Behtareen for:**
daily coursework, learning, experimentation, vendor independence.

Ek `SKILL.md` jo Claude Code ke liye likha gaya ho, `.opencode/skills/` mein bina badle chal jata
hai. **Discipline portable hai.**

## System of Record for the Agent Era

Jensen Huang ne kaha hai ke AI agents system of record ki zaroorat khatam nahi karte — woh usay
**mazboot** karte hain. System of record woh authoritative single source of truth hai jise business
read aur write karta hai. Agents ko woh ground truth chahiye. Uske bina, agents hallucinate karte
hain. Uske sath, woh execute karte hain.

Huang isay enterprise ke liye solve kar raha hai. Lekin ek layer hai jo Huang solve nahi kar raha:
**human layer.** Lakhon developers, architects, aur domain professionals AI agents banane wale hain —
zyadatar ke paas koi canonical source nahi jahan se seekhein.

**The AI Agent Factory Book agentic AI education aur construction ke liye ek system of record hai.**
Yeh khud bhi ek ke tor par ship hoti hai:

- **Book** canonical source of truth hai — Agent Factory System of Record yeh knowledge har
  connected agent tak pohanchati hai.
- **Zia Tutor AI** teaching agent hai — book se parhta hai, open internet se nahi.
- **Claude Code aur OpenCode** building agents hain — Zia Developer AI ke sath, yeh verified
  specifications aur SKILL.md templates se Digital FTEs banate hain.
- **Human judgment** verification layer hai — students, instructors, developers, aur domain experts
  confirm karte hain ke teaching aur construction book ke intent se match karti hai.

Pattern education aur construction par nahi rukta — teesri lane derivative books ki hai, har ek
**topic** ya **audience** se specialized, lekin sabhi ek hi vocabulary, architecture, aur standards
inherit karti hain.

**Topic axis** — jaise *Learning Python in the AI Era*, *Critical Thinking in the AI Era*,
*Learning Agentic Primitives*. **Audience axis** — primary/secondary/high-school editions, aur
profession-specific editions (engineers, doctors, architects, lawyers, accountants, bankers).
Framework constant rehta hai; examples, priors, aur depth reader ke hisaab se badalte hain.

Aur ek deeper symmetry hai: yeh book na sirf ek system of record **use** karti hai — yeh aapko yeh
bhi sikhati hai ke aisi agents kaise banayein jo systems of record use karti hain, aur yeh unhi
building agents ko power deti hai (Claude Code aur OpenCode, Zia Developer AI ke sath) jo aapko
unhein construct karne mein madad karte hain. **Aap pattern experience karke seekhte ho. Aap
pattern use karke banate ho.**
