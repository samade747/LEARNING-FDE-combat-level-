> ko judge karo kab shuru hua se. 3 criteria (reversibility/stakes/accountability) ownership
> decide karte; 4 causes (under-specification/context overload/wrong feature/stale config) timing
> se alag hoti; fix rule/reference/procedure mein promote hota taki stick kare.
