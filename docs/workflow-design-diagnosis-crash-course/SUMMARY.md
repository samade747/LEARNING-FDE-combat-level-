# Workflow Design & Diagnosis — Summary

Sixth Foundations course (brand-new chapter, book-growth se mila) — kaunse steps AI ko dena, jab
kaam galat ho to kya karna, aur ise kaise describe karna. Fetched: Zia Tutor AI, 2 windows

## 00 — Overview
- 2-teams-same-tool kahani ("output verdict nahi"), 6-question map (design/map/build/diagnose/
  persist/communicate), 18-question preview table (CCAO-F D4/D7 mapped).

## 01 — Part 1: Design the Work (Concepts 1-4)
- Unit of value = step not session. Requirements extraction (task definition, 5 settled answers).
  "Compute it, never write it" rule (code execution). Window test + judgment steps (hiring-freeze
  example).

## 02 — Part 2: The Delegation Map (Concepts 5-8)
- Eligibility→Ownership→Implementation (3 layers, never backwards). 3 criteria (reversibility/
  stakes/accountability). Contract-review + onboarding worked maps. 3 mapping errors (over-
  delegation/halo delegation/unstaffed gate/mapping-the-tool — customer-complaint case). Map
  ownership + scheduled read.

## 03 — Part 3: Build It, Watch It (Concepts 9-10)
- Ideate/prototype/feedback/refine loop (dashboard-artifact 3-cycle example: written-not-computed
  totals). Escalation signal vs "solved 3 times" signal.

## 04 — Part 4: When It Misbehaves (Concepts 11-12)
- 4 causes by symptom timing (under-specification/context overload/wrong feature-or-model/stale
  configuration) + expectation mismatch. Diagnostic sequence (cheapest first).

## 05 — Part 5: Make the Fix Stick (Concepts 13-16)
- Reaction→instruction→lever. Rule/reference/procedure → standing instruction/knowledge/Skill.
  Friction signals (repetition/correction/variance). Baseline + parallel run + cost case.

## 06 — Part 6: Operate It, Explain It (Concepts 17-18) + Recap
- Incident-hour 4 decisions (stop/scope/tell/map-change). 3-audience description pattern (never
  drop the gate). Recap sentence.

## 08 — Leaves Out + Terms + Sources

  material + 4 book-original additions named).
