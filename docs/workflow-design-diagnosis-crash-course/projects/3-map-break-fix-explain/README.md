# Project 3 — Map, Break, Fix, and Explain (Capstone)

**Time:** ~1 hour · **Tool:** any free AI assistant

Ek workflow, poore 6 parts, ~1 ghanta.

## Steps

1. **Map it.** Real workflow lo, table banao: step, owner, reason. Har reason reversibility,
   stakes, ya accountability naam kare.
2. **Place the features.** Har AI step ke liye batao kya carry karta (Skill, knowledge, code
   execution, standing instruction). Har human step ke liye person+moment naam do.
3. **Run one step for real.** Sabse mechanical AI step pick karo, real input par chalao.
4. **Break it deliberately.** Ek figure prose mein maango jo compute hona chahiye thi. Right-
   lagta number aata dekho. **Fix karne se pehle Concept 11 se loud diagnose karo.**
5. **Promote one fix.** Step 3/4 mein jo correct kiya, usay sahi ghar mein daalo (rule→standing
   instruction, reference→knowledge, procedure→Skill).
6. **Measure the before.** 1 unchanged run: time, revision rounds, manual steps. Note karo ke
   tum estimate kar rahe ho, measure nahi — yehi cost hai pehle na karne ki.
7. **Fill in the one-page map** — [00-overview.md se linked template](../../07-map-template-prompts.md)
   use karo, owner + next review date + "if it goes wrong" 4 lines ke sath.
8. **Write the three descriptions.** Technical, executive, risk — har ek mein gate naam ho.

## Done

- [ ] 1 page jo koi doosra chala sake
- [ ] 1 working step
- [ ] 1 diagnosed failure
- [ ] 1 permanent fix (configuration mein promoted)
- [ ] 3 sentences jo meeting mein bol sako, teeno mein gate naam ho
