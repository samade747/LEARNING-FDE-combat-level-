## Ek Line Mein Poori Cheez

> Ye chatbots nahi hain — ye **action lete hain**: files parhte, edit karte, commands chalate, task
> khatam hone tak chalte rehte hain. **Poori course ek hi idea ke ird gird hai: context engineering** —
> jaan-boojh kar decide karna model **kya dekhe**, aur irrelevant cheezein bahar rakhna.

## 3 Zaroori Baatein (Karpathy Se)

1. **Ye ghost hai, insaan nahi** — koi ego, koi motivation nahi. Aap isay manage karte ho
2. **Iski intelligence jagged hai** — ek hi model kisi cheez mein superhuman, agli mein kamzor
3. **Utna hi trust karo jitna output check ho sake** — yehi is poori course ka core pattern hai
   (**verification loop**)
