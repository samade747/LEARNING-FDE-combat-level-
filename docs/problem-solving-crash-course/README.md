## Yeh Course Kis Baare Mein Hai

Pehle course (["Is This an Agent Problem?"](../is-this-an-agent-problem/README.md)) ne sikhaya **kya**
agent ko dena hai. Yeh course sikhata hai **kaise** actually solve karna hai — 4 tools (Claude Code,
OpenCode, Cowork, OpenWork) ke through, **7 Principles** ke zariye jo asal mein 80% real-world use
cover karte hain.

**Do students, same assignment:** 5 research papers parh kar ek comparison summary likhni hai. Student
A 25 minute mein clean, verified summary de deta hai. Student B 90 minute mein back-and-forth karta hai,
conversation cluttered ho jati hai, AI galtiyan karne lagta hai, dobara se shuru karna parta hai. **Same
tool. Same assignment. Farq: Student A ne 7 principles follow kiye. Student B ko woh pata hi nahi the.**

## 5 Bullets Mein Essence (60% Value)

1. **Action over talk.** Agent ki value **karne** mein hai — sirf paragraph mat mangwao, action ya artifact mangwao.
2. **Code/structure over prose.** Precision chahiye to schema, table, checklist mango — plain paragraph nahi.
3. **Verify, don't trust.** Har meaningful output ko ek verification step chahiye. "Looks right" hi failure mode hai.
4. **Small steps, atomic checkpoints.** Kaam ko chote reversible units mein todo, har unit ke baad save karo.
5. **Files are memory.** Conversation volatile hai; filesystem durable hai. Jo yaad rakhna hai, file mein likho.

Baqi do principles (Constraints, Observability) pehle 5 ko **scale par reliable** banate hain.
