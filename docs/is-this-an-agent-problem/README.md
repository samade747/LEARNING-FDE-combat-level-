## Yeh Course Kis Baare Mein Hai

Yeh course **General Agents** group ke baad, aur **Problem Solving with General Agents** se pehle aata hai.
Yani aap ne agent tools (Claude Code, OpenCode, Cowork, OpenWork) dekh liye hain, ab seekhna hai ke
**kaunsa kaam unko dena chahiye, aur kaunsa nahi.**

Poora course sirf **3 Gates** par khara hai — teen mental checks jo aap agent kholne se **pehle** apne
zehan mein chalate hain. Yeh gates kisi tool ka naam nahi lete (tools har kuch mahino mein badalte
rehte hain) — yeh sirf **kaam ki nature** decide karte hain.
