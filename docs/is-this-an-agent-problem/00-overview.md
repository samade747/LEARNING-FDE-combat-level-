# 00 — Overview: Ana vs Yusuf

## Ek Kahani, Do Tareeqe

Do log ek chota online shop chalate hain. Monday ko dono ko same kaam milta hai: 400 customer
messages ka dher jama ho chuka hai, unko groups mein sort karna hai (complaints, questions, orders,
other) aur Friday tak ek short summary likhni hai.

**Ana** kisi bhi tool kholne se **pehle** 10 minute rukti hai aur khud se teen simple sawal poochti
hai:

1. **Kya yeh AI ka kaam hai, ya app ka apna search/filter kaafi hai?** Groups banana judgment maangta
   hai ("complaint" kya count hota hai — yeh koi simple filter decide nahi kar sakta) — to haan, yeh
   AI job hai.
2. **Yeh kaam ek dafa karna hai, ya har hafte?** Har hafte. To woh note bana leti hai ke baad mein
   isko khud-chalne wala banayegi, aur abhi Friday ke liye jaldi se haath se kar leti hai.
3. **Finished kaam kaisa dikhna chahiye?** Ek spreadsheet — ek row per message — plus ek one-page
   summary. Ab woh AI tool kholti hai, pehle se pata hokey usay kya chahiye.

**Yusuf** seedha AI tool kholta hai aur type karta hai "help me with these customer messages." Tool
usse poochta hai kya chahiye. Usko khud clear nahi, to woh chalte chalte decide karta hai. Do ghante
baad uske paas ek summary hai jispe usay trust nahi, agle hafte dobara karne ka koi tareeqa nahi, aur
wahi dher agle Monday phir uska intezaar kar raha hoga.

**Same kaam. Same tool. Ana ne kaam ko teen gates se guzaara pehle kuch bhi type karne se pehle.
Yusuf seedha tool mein ghus gaya aur usay sawal poochne diya.**

## Yeh Course Kiske Liye Hai

Jinke paas in mein se koi tool hai (Claude Code, OpenCode, Cowork, OpenWork) aur real kaam ka dher —
lekin hamesha yaqeen nahi ke tool sahi jagah hai. Yeh course "beech" mein baithta hai: tools dekhne ke
**baad**, lekin unse real problems solve karna seekhne se **pehle**. Yeh decide karta hai **kya** dena
hai tool ko, aur **kahan** kaam jana chahiye.

> **Reminder — "Agent" kya hota hai?**
> Ek **general agent** sirf *baat* nahi karta — woh *kaam karta hai*. Files khol sakta hai, parh sakta
> hai, likh sakta hai, chote programs chala sakta hai, aur dusre apps use kar sakta hai. Yaad rakhne ka
> aasan tareeqa: chatbot **jawab deta hai**; agent **jaake kaam karta hai**.

## Rule in One Line

> **"The cheapest mistake to fix is the one you catch before you start."**

Plan mein galti ka koi cost nahi — bas mann badlo. Lekin agent ke ek ghanta ghalat kaam karne ke baad
pakdi gayi galti, poora ghanta wapis nahi ata. Isiliye effort ka sabse sahi jagah **shuru mein** hai.

Taqreeban har cheez jo agent ke saath ghalat hoti hai, wahin shuru mein ghalat hoti hai:

- Aap ne agent use kiya us kaam ke liye jo spreadsheet ek step mein karti hai
- Aap ne wahi kaam do mahine tak har hafte haath se kiya, jab aap kuch reusable bana sakte the
- Aap ne agent ko fuzzy idea ke sath khola, to usne neat kaam kiya — **ghalat cheez par**

Yeh koi "ghalat typing" ki wajah se nahi hota. Yeh **ghalat jagah se shuru karne** ki wajah se hota hai.
Koi bhi chalak wording isay theek nahi karti, kyunki ghalat sawal ka perfect jawab bhi ghalat hi hota
hai.

## Teen Gates (Overview Table)

| Gate | Sawal | Rokta Kaunsi Galti Hai |
| --- | --- | --- |
| 1 | **Kya isko agent chahiye bilkul?** | Bara tool chote kaam ke liye — ya chota tool bare kaam ke liye |
| 2 | **Ek dafa, ya har hafte?** | Ek-dafa kaam ke liye helper banana — ya repeat kaam hamesha haath se karna |
| 3 | **"Finished" kaisa dikhta hai?** | Neat kaam, lekin ghalat target par |

Gates **order mein** chalte hain. Gate 2 sirf tab matter karta hai jab Gate 1 "haan, agent" kahe. Gate
3 sirf tab matter karta hai jab Gate 2 "abhi karo" kahe. Ek gate skip karo, to uski galti hogi.

## Short Version (3 Bullets)

Sirf yeh teen yaad rahe, to zyada tar cheez aapke paas hai:

1. **Har kaam AI ka kaam nahi, aur har AI kaam ko agent nahi chahiye.** Agar spreadsheet, search box,
   ya 30 second ka khud ka kaam kaafi hai — wahi karo. Agar sirf **jawab** chahiye, woh chatbot hai.
   Agent us kaam ke liye hai jo fuzzy ho, mukhtalif tarah ki files mein phaila ho, aur tool ko waqai
   files/data/apps par **kuch karna** pare.
2. **Kitni baar karte ho — yehi sab kuch decide karta hai.** Ek dafa wala kaam → agent kholo, solve
   karo, khatam. Har hafte, same tareeqe wala kaam → haath se karna chhodo, ek helper banao. Sabse
   zyada waste hone wala kaam duniya mein woh hai jo "helper-banao" wala kaam ho, lekin haath se hota
   rahe.
3. **Agent kholne se pehle decide karo "finished" kaisa dikhta hai.** Teen cheezein naam do: kis se
   kaam kare, akhir mein kya chahiye, aur woh ek check jo bataye sahi hai. Clear target wala agent
   usay hit karta hai. Fuzzy target wala agent kuch neat aur ghalat banata hai.
