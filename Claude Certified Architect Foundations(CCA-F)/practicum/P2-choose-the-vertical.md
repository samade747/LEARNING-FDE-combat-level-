# P2 — Choose the Vertical

*Practicum week 2. Apply 5 screening criteria to the P1 shortlist, commit to one vertical, start the
source register.*

## The 5 criteria

| Criterion | Kya dekhna hai |
| --- | --- |
| **Knowledge intensity** | Rules dense hain? Exceptions? Yearly change? (Zyada = better SoR case) |
| **Regulatory weight** | Galat jawab ki cost? Regulator involved? (Zyada = customer pays for governance) |
| **Source availability** | Authoritative documents public + convertible to reviewed Markdown? |
| **Willingness to pay** | Is domain ke log/businesses consultants ko already pay karte hain? |
| **Personal access** | ⭐ Tumhare paas real practitioners (verify karne ke liye) + real source docs? |

Scoring: 1 (weak) – 5 (strong).
